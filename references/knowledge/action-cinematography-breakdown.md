# 华语动作电影拉片级分镜与运镜工程规范 (Action Cinematography & Shot Breakdown)

本指南深度解构《一代宗师》《师父》《杀破狼》《导火线》《九龙城寨之围城》等顶级华语动作神作的分镜视听语法，转化为扩散模型可直接执行的分镜规范。

---

## 一、 经典动作分镜五大核心法则

### 1. 景别阶梯跃迁呼吸法 (Shot-Scale Ladder)
* 景别按当前可见事件选择：允许连续相同景别；特写、中景、全景分别强调细节、攻防与空间，不强制阶梯轮换。
* 景别大幅变化须仍能辨认动作与空间；特写直接拉开或切至全景可用于揭示尺度，不一律禁止。

### 2. 视线落点连续性 (Eye-Trace Continuity)
* 镜头切接时，上一镜头打击的视觉焦点（如右上方拳面撞击点），下一镜头切入瞬间的核心信息点通常应落在屏幕右上区域或顺势沿动势滑向中心，防止观众眩晕找焦点。

### 3. 动势衔接 (Match on Action)
* 角色在上一镜头完成动作前半段（如大步蹬地挥拳过半），下一镜头切入时通常应从挥拳中段继续推进并击中目标，动作速度与轨迹严格对齐。

### 4. 同向加速运镜 (Camera Sync Velocity)
* 镜头移动方向通常应与攻击动作方向保持一致（如右勾拳向左轰出，镜头以同速度向左平移跟拍），速度感来源是“镜头与动作的同向合力”，而不是画面本身的乱晃。

### 5. 近景生理破坏与全景动势交代
* **中远景看动势与空间**：走位路线、身体腾空舒展、障碍破坏；
* **近景与特写看生理破坏**：骨骼受力凹陷、汗水血沫喷溅、肌肉撕扯、眼神杀意。

## 二、 fengfeng“三手法六式”镜头衔接体系

* **三手法**：
  1. 换机位（改变拍摄角度与视角，保持主体动作连续）；
  2. 切景别（特写切中景，中景切全景，由微观入宏观）；
  3. 跨段反应（攻击击出瞬间切受击方防御或受创表情）。
* **六式**：
  * ① 动作连续切（挥招前半段切命中后半段）；
  * ② 反应镜头切（攻方重击切守方瞳孔骤缩/咳血）；
  * ③ 景别跳切（长距离突进由全景跳入近景刺杀）；
  * ④ 视线引导切（主角转头看向右侧，顺视线切右侧出现的威胁）；
  * ⑤ 遮挡过渡切（前景立柱/人影掠过遮挡瞬间完成场景切换）；
  * ⑥ 动势匹配切（上一镜向右翻滚，下一镜向右滑步冲拳）。

## 三、 机位-动作语义绑定表（打斗镜头机位选择逻辑）

> 学自 2026-09-02 用户分享的 AI 打斗拆解（女帝战巨兽 26s）：机位不是随便选的，通常应与发力方向/受力点/体量绑定。**先定动作语义，再定机位**，应避免先有机位再填动作。

| 动作语义 | 机位选择 | 为什么对 |
|---|---|---|
| 贴地横扫 | 低机位贴地跟拍 | 看到剑芒水平切过群魔，高度差制造切割感 |
| 巨兽砸地 | 大仰角中景 | 体量压迫感拉满 |
| 风暴回旋 | FPV 第一人称旋转 | 代入旋转眩晕，主观感最强 |
| 千斤坠升空 | 俯拍起跳 → 仰拍升空 | 先压后升，力学过程可见 |
| 流星砸地 | 垂直俯视 Top-Down | 同心圆冲击波全景最清晰 |
| 360 辐射 | 极广角俯视 | 放射线全貌，力量向八方扩散可见 |
| 挑衅/神态 | 特写浅景深 | 表情记忆点，武戏中段人设锚 |
| 剑阵全爆 | 中景快速拉远 | 爆炸结果整体呈现 |
| 中场留白 | 仰拍背影 | ⚠️ 2026-09-02 禁用：静止段=呆立。改运动中换档（滑步后撤中蓄力/环境介质撑节奏） |
| 巨浪扑杀 | 仰视广角跟摇 | 水墙压迫感，跟摇保持动态 |
| 逆斩天柱 | 极近仰拍 | 由下至上完整见斩线 |
| 断海收尾 | 超远景中心构图 | 奇观全貌，终帧仪式感 |

* **使用经验规则**：写任何打斗镜头前，先问“这个动作的语义是什么（切割/碾压/眩晕/升空/爆炸/压迫）”，再查表选机位；应避免机位与动作语义错配（如贴地横扫用大仰角、流星砸地用平视）。

## 四、 拆解稿判型与重写（长运镜 ONER vs 多镜剪辑）

> ⚠️ 2026-09-02 实测翻车：把 Gemini 拆解稿（动作分解）当成剪辑点重组，逐镜写“换机位”，结果模型渲染成过山车运镜、画面发飘。**拆解稿≠剪辑点**，拿到通常应先判型。

### 1. 判型方法
* **长运镜（ONER）**：原片一个镜头从头跟到尾，动作连续发生，拆解稿只是“动作分解”；特征是运镜轨迹连续（贴地→抬升→环绕→拉远），无硬切。
* **多镜剪辑**：原片多个镜头拼接，拆解稿每个“镜头”是真实剪辑点；特征是有遮挡/白闪/硬切转场。
* **判据**：看拆解稿里是否有“转场/遮挡/切黑/白闪”等剪辑标记，有=多镜剪辑，无=长运镜。

### 2. 长运镜重写规则（散→聚）
* **一条时间轴=一条运镜轨迹**：应避免分镜号（[镜头1][镜头2]），写成一个连续运镜描述；
* **机位不切换，只“跟随动作自然运动”**：用“镜头随她踏地借力冲天而起的动作自然抬升、螺旋环绕上升”替代“俯拍起跳→仰拍升空”的分镜写法；
* **动作在轨迹上展开**：横扫→砸地→升空→剑阵，全部发生在同一镜头内，用“同一运镜内/同一镜头内”串接；
* **SFX 层层递进**：一个 `[SFX: ...]` 序列按动作顺序排列（重刃破空→山岳崩裂→风暴呼啸→破障→万剑蜂鸣）；
* **焦点时间分段**（fengfeng §4.6.7）：每段只保一个主角色算力重心，不贪多。
* **开场景别选择**：远景弧线冲近可表现尺度变化，中近景跟随可强化人物识别；按事件选择，不强制人物占比。
* **速度感**：人物位移、背景视差、前景遮挡、跟随运镜、拖尾和路径反馈共同提供；远景起手不是天然慢，中近景也不是唯一解。

### 3. 多镜剪辑重写规则
* 多镜剪辑按事件容量分配时间；镜头时长不等于生成片段时长，不将旧平台下限当成通用规则。

### 4. 连续长镜自查（仅选择长镜时）
- [ ] 若明确选择连续长镜，轨迹能否衔接？若选择多镜，事件与空间状态是否连续？
- [ ] 机位变化是否写成“镜头随动作自然运动”（抬升/环绕/拉远/跟摇）？
- [ ] 关键动作是否完整覆盖，观察角度改变后是否保持动作和状态衔接？
- [ ] SFX 是否按动作顺序递进，而非每段各一个？

### 5. 长运镜聚合标准范例（16:9 · 15s · 高密度节奏版）

> 下方范例为「女帝战巨兽」拆解稿的聚合重写版，单一连续运镜（低空掠过→随升空自然抬升→螺旋环绕→随剑雨俯冲），**结尾直接万剑齐发轰地，无蓄势定格**。写长运镜时直接套此骨架换皮。



* **范例拆解**：一条时间轴=一条运镜轨迹；动作（横扫→硬碰→升空→剑阵→轰地）全部发生在同一镜头内；机位变化写成“镜头随动作自然运动”（低空掠过→随升空抬升→螺旋环绕→随剑雨俯冲）；**无静止段**——蓄力在升空中完成，收尾直接万剑齐发轰地，不用“蓄势待发/悬空对峙”类定格。
