# 视频模型交付规则

## 双轨交付

完整或精简直投稿都执行[关键动作的画面写法](modules/compile.md#直投稿把关键动作写到画面上)：从本镜就能辨认谁动、往哪动、作用于哪里、造成什么变化，不让模型靠主稿解释补齐关键动作。

用户明确要精简版、短版或给出正文长度上限时，才缩写直投稿。有主特效需压缩时，按[特效编译保真](move-vfx-design.md#编译保真合并措辞不合并不同信息)取舍；普通无特效片段不为此加步骤。

先完成制片主稿，再从同一设计编译直投稿，不是两次自由创作。复制是交付方式，不是缩写授权。默认完整直投：项目参数、适用于本段的全局与资产、片段设定、逐镜时间轴都在同一复制区内。每镜画面、适用的台词之后单列【音效】，独占一行，动作层、特效层、环境层、同步节点、主次变化、跨镜承接各占一行。首镜写底声如何进入，末镜写收束或下段入口；短切、空镜、交接镜也不跳过。无对应声源写“本镜无新增×声”或有意静默，不虚构。可不再展示内容重复的第二份，但不能只贴精简稿。

1. **制片主稿按集装订。** 原模板从项目名称到场景与资产结束是全集共用页，只写一次；从片段设定起至逐镜时间轴结束是可重复的片段页。后续段落引用共用资产名，只记本段起止、状态变化和新增资产；新增稳定资产补入共用页，不回贴整页。单段独立项目也保留这两部分。逐镜保留摄影、表演、完整动作与特效链、原台词、分层音效、同步主次和跨镜关系。
2. **精简直投是例外。** 仅用户明确要求压缩才用以下写法；“单独复制”“直接投模型”或极速档均不算。完整模板与明确字数上限冲突时先指出，不擅删音效。 一次生成对应一份，不依赖其他稿、聊天或未上传的图。先定时长、画幅和画风，把人物、持物、光向、场景地标与起始状态写进首次出场句。照原切点写每镜新增的观看信息、动作的原因和结果、具体表情、特效如何带动环境及末态。保留台词原句、说话人、声源、关键声画同步和配乐转折；把混音操作译成听觉结果，如“铜铃碰响时鼓声停一拍”，不粘贴音轨表。400～700字可作15秒复杂段的参考，不是字数门槛；先删重复，不为凑字丢镜或删词。已启用的交接镜写成真实最后一镜，不附后期操作。
3. **脱稿验收。** 遮住共用页，只读该段直投稿：谁在何处、为何行动、接触点、关键变化、最后停在哪，能否从文字还原？再逐镜对照两稿的切点、时长、台词归属、视效转折和末态。不一致修派生稿；主稿变更后只重编受影响片段及确受影响的续接段。检查记录不进复制区。平台未指定时不假设支持同步音频或保证时码精度。

- 投喂正文与后台检查分离。动态元素复核与完成检查按[后台复核](prompt-backstage-checks.md)执行，不发送其栏目、检查表或检查结论。默认时间段内部按[编译工序](modules/compile.md#时间段内连续表达)融合摄影、动作、表演、特效、环境与衔接，保留按需的台词和音效，不逐专业分栏，不因移除栏目而丢掉必要内容；当前用户另有格式要求时优先。

- 区分项目总长、一次生成长度、内部排期和提示词中的对时要求。内部时段用于九宫取样、剪辑和容量复核，规划范围可以调整，不能机械均分后当成确定镜点。正文默认按主人提供的[提示词模板](video-prompt-template.txt)呈现逐镜与台词时段，事件内部仍按动作触发和相对节奏连续描述，不逐句加时码。当前用户明确指定无时码或其他格式时优先执行；全段显式时码稿须逐镜写出可读的起止秒数，并另记timing_nodes，与正文标题及数字逐项一致；计划总长已指定时末镜收在该点。无时码稿用相对先后，不强制提交排期；局部改稿不重建全段排期。字面秒数不保证模型精确对时。
- 正文中的“镜头 1”“同镜连续”“切到”可以表达观看顺序。内部事件、镜头和资产数据库 ID 留在交接数据。故事节拍、真实切镜和九宫观察状态分别处理。
- 确认平台、模型和任务模式后，查该入口支持的单次时长、参考素材、音频和画幅。超出单次能力时，在事件边界拆成可提交片段，保留每段首尾状态和必要对白。目标未指定时交付通用稿，生产兼容性标待确认。
- 文生时写足画面所需身份与空间。已有高匹配参考时，以实际上传后的类别和序号指代，说明只负责哪些内容，正文补运动、剧情状态与本次差异。只有实际使用的图、视频、音频能写成引用；同一主体称谓一致。参考图与用户确认的本场信息冲突时，先限定参考职责，仍影响辨识则标待确认。
- 使用具体可见的正向描述。一个镜头优先交代一项主运镜，后续变化与可见动作绑定。按目标模型处理禁项。Seedance 可简短写无字幕、无配乐等适用约束。Runway Gen-4 用正向表达，例如“固定机位”。不用风格词、器材词或约束清单重复同一个意思。

依据：[Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)、[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)、[方舟接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Runway Gen-4 指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)。不同产品入口以实际设置为准。字面时间标注不是逐帧执行保证。
