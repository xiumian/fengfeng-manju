# 视频模型交付规则

- 投喂正文与后台检查分离。动态元素复核与完成检查按[后台复核](prompt-backstage-checks.md)执行，不发送其栏目、检查表或检查结论。默认时间段内部按[编译工序](modules/compile.md#时间段内连续表达)融合摄影、动作、表演、特效、环境与衔接，保留按需的台词和音效，不逐专业分栏，不因移除栏目而丢掉必要内容；当前用户另有格式要求时优先。

- 区分项目总长、一次生成长度、内部排期和提示词中的对时要求。内部时段用于九宫取样、剪辑和容量复核，规划范围可以调整，不能机械均分后当成确定镜点。正文默认按主人提供的[提示词模板](video-prompt-template.txt)呈现逐镜与台词时段，事件内部仍按动作触发和相对节奏连续描述，不逐句加时码。当前用户明确指定无时码或其他格式时优先执行；正文时段和独立timing_nodes应一致，但字面秒数不保证模型精确对时。
- 正文中的“镜头 1”“同镜连续”“切到”可以表达观看顺序。内部事件、镜头和资产数据库 ID 留在交接数据。故事节拍、真实切镜和九宫观察状态分别处理。
- 确认平台、模型和任务模式后，查该入口支持的单次时长、参考素材、音频和画幅。超出单次能力时，在事件边界拆成可提交片段，保留每段首尾状态和必要对白。目标未指定时交付通用稿，生产兼容性标待确认。
- 文生时写足画面所需身份与空间。已有高匹配参考时，以实际上传后的类别和序号指代，说明只负责哪些内容，正文补运动、剧情状态与本次差异。只有实际使用的图、视频、音频能写成引用；同一主体称谓一致。参考图与用户确认的本场信息冲突时，先限定参考职责，仍影响辨识则标待确认。
- 使用具体可见的正向描述。一个镜头优先交代一项主运镜，后续变化与可见动作绑定。按目标模型处理禁项。Seedance 可简短写无字幕、无配乐等适用约束。Runway Gen-4 用正向表达，例如“固定机位”。不用风格词、器材词或约束清单重复同一个意思。

依据：[Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)、[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)、[方舟接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Runway Gen-4 指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)。不同产品入口以实际设置为准。字面时间标注不是逐帧执行保证。
