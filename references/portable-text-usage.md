# 纯文本版｜离线使用说明

这段是五文件发行包的入口。合并处的“相对路径”是同包中的章节名，不要求外部环境真的存在那些目录。**无需运行脚本**：没有本地工具时按下面的手工流程做，程序术语只用来理解交接，不建虚假回执，不声称跑了程序或已经看过未提供的媒体。完整投喂模板始终用 01，不把本页、来源说明或复核清单拼进提示词。

## 只收到这五个文件时，怎么做

1. **02 锁定输入与权限**：先按创作准备分清忠实改编、授权扩写或仅补拍法。列出固定剧情、原台词、参考图各自负责什么、时长画幅与段尾目标。关键决定先写触发、谁作判断、行动和结果；不明且决定结果的来源标待确认。只要扩写时不启动分镜。
2. **03／04／05 按需求设计**：先排事件和观看任务，选用需要的专业方法。05 的来源与资产工序核对原句和已提供素材；动作交接路径、支撑、受力和终态，表演交触发、可见反应与残留，特效交成形、传播、受力、余波和层间作用，声音交声源、先后、主次和延续。摄影据此定固定或移动、切点及新看点，既可用空镜接对白，也不为了凑镜数硬切。
3. **01 编译，05 后台复核**：按完整模板组织逐镜正文与台词、分层音效；后台逐项对照原文、专业交接与正文落点。显式时码稿手工留一张对应表，逐镜对照正文标题与起止秒数，首镜从 0 起，前镜结束接下一镜开始，已锁总长时末镜到达该总长。正文 0–2 秒不能登记为 0–15 秒，也不能省掉排期核对；明确要求无时码时保留相对顺序。这里的手工记录不是程序回执。
4. **只交用户选定的产物**：不能实际生成、看片、核听、抽帧或建九宫工程时，只交可完成的文字设计并标明限制。段尾交接镜只按模板适用条件写，下一段仅在真有参考帧时绑定它；否则文字补起始状态，不虚构上一帧。
