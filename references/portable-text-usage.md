# 纯文本版｜离线使用说明

这段是五文件发行包的入口。合并处的“相对路径”是同包中的章节名，不要求外部环境真的存在那些目录。**无需运行脚本**：没有本地工具时按下面的手工流程做，程序术语只用来理解交接，不建虚假回执，不声称跑了程序或已经看过未提供的媒体。完整投喂模板始终用 01，不把本页、来源说明或复核清单拼进提示词。

## 只收到这五个文件时，怎么做

1. **02 锁定输入与权限**：先按创作准备分清忠实改编、授权扩写或仅补拍法。列出固定剧情、原台词、参考图各自负责什么、时长画幅与段尾目标。关键决定先写触发、谁作判断、行动和结果；不明且决定结果的来源标待确认。只要扩写时不启动分镜。
2. **03／04／05 逐站完成**：先单独写完剧本的可拍底稿，场景资产接它；动作、表演、特效依需要依次拿实际成果延续。动作交支撑、受力和终态，表演交触发和反应、对白窗口，特效交接触后的可见变化。摄影拿这些成果先做[整场观看规划](scene-rhythm-planning.md#整场观看规划)，再排逐镜；声音接已定镜头补声源、同步、主次和声桥。做完一站才开始下一站，不把这些过程压成一次补写。缺一站退回负责项，不全篇重想。
3. **01 编译，05 后台复核**：按完整模板组织逐镜正文与台词、分层音效；后台逐项对照原文、专业交接与正文落点。只交分镜时不编译，按[分镜首稿复核](routing.md#分镜首稿复核)手工另读候选稿并修正后再交。显式时码稿手工留一张对应表，逐镜对照正文标题与起止秒数，首镜从 0 起，前镜结束接下一镜开始，已锁总长时末镜到达该总长。正文 0–2 秒不能登记为 0–15 秒，也不能省掉排期核对；明确要求无时码时保留相对顺序。这里的手工记录不是程序回执。
4. **复核通过才交用户选定的产物**：按[交付门槛](routing.md#完整提示词交付门槛)逐项对照确认稿、分镜和每份实际正文。光看画面段能否读出机位、景别、焦感、固定或运动从何开始到哪停，以及切点多给了什么？约六秒的长镜还要找到前后两处画面证据，证明留镜确有用处，不按对白时长均分。失败退回责任工序并保留上一确认稿；缺口未修复只报卡点，不交缺项稿。不能看片、核听或抽帧不声称已做。段尾交接镜只按模板适用条件写；下一段须有真实参考帧才绑定，否则用文字补起始状态。
