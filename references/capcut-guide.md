# 剪映/CapCut 操作指南

## 基础操作流程

### 1. 导入素材
- 打开剪映/CapCut
- 点击"开始创作"
- 选择需要剪辑的视频和图片素材
- 点击"添加"导入时间线

### 2. 基础剪辑
- **分割**：选中视频 → 移动播放头到分割点 → 点击"分割"
- **删除**：选中不需要的片段 → 点击"删除"
- **排序**：长按片段拖动调整顺序
- **变速**：选中片段 → 点击"变速" → 选择速度（0.25x-100x）

### 3. 音频处理
- **添加背景音乐**：点击"音频" → "音乐" → 选择合适的BGM
- **提取音乐**：点击"音频" → "提取音乐" → 从视频中提取
- **录音**：点击"音频" → "录音" → 录制配音
- **音效**：点击"音频" → "音效" → 添加转场音效、搞笑音效等

### 4. 文字字幕
- **自动识别字幕**：点击"文本" → "识别字幕" → 自动生成字幕
- **手动添加字幕**：点击"文本" → "新建文本" → 输入文字
- **字幕样式**：选中字幕 → 调整字体、颜色、大小、位置
- **字幕动画**：选中字幕 → "动画" → 选择入场/出场/循环动画

### 5. 转场效果
- 点击两段视频之间的白色方块
- 选择转场效果：
  - **基础**：叠化、黑场、白场
  - **特效**：运镜、特效、梦幻
  - **运镜**：推拉、旋转、缩放
- 调整转场时长（建议0.2-0.5秒）

### 6. 特效和滤镜
- **滤镜**：点击"滤镜" → 选择风格（清新、日系、复古等）
- **特效**：点击"特效" → 选择特效（动感、光影、复古等）
- **调节**：点击"调节" → 调整亮度、对比度、饱和度、锐度等

### 7. 贴纸和装饰
- 点击"贴纸" → 选择合适的贴纸
- 调整贴纸大小、位置、时长
- 添加动画效果

## 高级技巧

### 1. 关键帧动画
- 选中素材 → 点击"关键帧"图标
- 在不同时间点添加关键帧
- 调整位置、缩放、透明度等参数
- 创建移动、缩放、旋转等动画效果

### 2. 蒙版使用
- 点击"蒙版" → 选择形状（线性、镜面、圆形等）
- 调整蒙版位置和大小
- 创建画中画、分屏等效果

### 3. 画中画
- 点击"画中画" → "新增画中画"
- 导入第二段视频
- 调整大小、位置、混合模式
- 创建分屏、对比等效果

### 4. 倒放和定格
- **倒放**：选中片段 → 点击"倒放"
- **定格**：移动播放头到定格位置 → 点击"定格"
- **镜像**：选中片段 → 点击"镜像"

### 5. 绿色幕布（抠图）
- 点击"抠像" → "色度抠图"
- 选择绿色或蓝色背景
- 调整强度和阴影
- 替换背景

## 抖音风格特效推荐

### 1. 开头 Hook 特效
- 快速缩放（关键帧动画）
- 闪白/闪黑转场
- 音效配合："duang"、"whoosh"

### 2. 转场特效
- 运镜转场（模拟相机运动）
- 遮罩转场（用手、物体遮挡镜头）
- 匹配剪辑（相似动作衔接）

### 3. 结尾引导
- 关注引导动画
- 点赞动画特效
- 评论区互动贴纸

## 导出设置

### 推荐导出参数
- **分辨率**：1080P（1920x1080）或 4K
- **帧率**：30fps（常规）或 60fps（游戏/运动）
- **码率**：推荐（自动）或高（更清晰）
- **格式**：MP4
- **封面**：选择合适帧作为封面

## 常见问题

### 1. 视频卡顿
- 降低预览质量（设置 → 预览画质 → 流畅）
- 关闭其他应用
- 分段剪辑后合并

### 2. 导出失败
- 检查存储空间
- 降低导出分辨率
- 分段导出后合并

### 3. 音画不同步
- 重新导入素材
- 检查原视频帧率
- 使用"音频分离"后重新对齐

## 抖音热门效果模板

### 1. 卡点视频
- 导入音乐 → 根据节拍分割视频
- 每段视频配合一个节拍
- 添加闪黑/闪白转场
- 使用节奏感强的音乐

### 2. 变装视频
- 开头：素颜/旧装 → 定格
- 转场：遮挡镜头（用手/衣服）+ 快速切换
- 结尾：精致妆容/新装 → 展示
- 配合音乐高潮部分

### 3. 分屏对比
- 使用"画中画"功能
- 左侧：使用前/问题 → 右侧：使用后/解决方案
- 添加箭头、圆圈等标注
- 配合对比文案

### 4. 教程类视频
- 开头：展示成果（吸引点击）
- 中间：分步演示（可使用快进）
- 结尾：回顾要点 + 关注引导
- 添加文字说明和箭头标注
