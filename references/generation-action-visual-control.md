# 打斗与强视觉主方法

## 1. 设计顺序与时间预算
先锁定任务目标、时长、必须保留的剧情/动作/对白和结果，确定当前主看点，再分配观看时间并编排动作、特效/变身与摄影。预算与设计可往返调整，不先写招式清单再套时间。用户模糊时主动完成一个明确方案，具体时忠实落实；自由设计可补能力与执行细节，明确是本次设计，不冒称原文或资产事实。
把必须顺序完成的动作与可以并行的反馈分开：到达后才接触，破防后才利用机会；追击可伴随受者失衡，挥斩可伴随力量形成，尘屑、衣发余势可继续到下一动作。每段有主观看焦点，但一镜可以连续攻防，不限定招数。没有剧情意义的第三人守候、重复接挡和逐招回正不占时间。
秒数是成片观看时长；对白、慢放、停顿和必要摄影揭示计入。分配主要动作的进入、接触与结果时间，不要求各占独立阶段。容量不足先删自选重复动作、减少无作用展示或重排时间；必须事件仍放不下则说明冲突并提出延长/分段，不擅删用户剧情，不以无限速度或画外隐藏解决。

## 2. 连续攻防与力度
为双方选择不同运动语言：优势距离、攻击路线、力量/惯性和恢复方式。每组交锋有进攻、对方应对和局面影响，不要求每击反转或双方势均力敌。脱身、抢夺、保护等目标决定路线；对手依视距、能力和前一拍状态行动，不能站着等主角表演。
下一动作来自上一动作留下的武器位置、余势、失衡或破绽。恢复可以同时转向或反击，必要换撑和落地仍有因果；不默认“准备—展示命中—补步—站稳—下一招”。真实位移建立压力，接挡只是临时关系，不冻结在交叉兵器或举手守阵姿势。
关键打点用突然进入、实际接触和明显防线/运动变化产生力度，余势传到衣物、碎片或地形；重打点不必血腥，也不每击都打飞。强摄影和声音强调已有撞击，不替代身体动作。奇幻爆发按已设计驱动力成立，检查不能把超人动作改成普通匀速演示。

## 3. 速度坡道：用动作事件触发变速
本用户打斗项目在承担命中力度、破防或局势变化的关键打点落实快—慢—快。正文直接描述高速进入的动作、触发慢放的接触事件、慢放期间的连续受力，以及恢复正常速度的事件与紧接结果；不用孤立的“速度坡道”术语或倍率串替代动作。普通衔接保持利落，不逐招慢放；用户明确指定其他节奏时优先遵循。

优先写成：“攻击高速逼近；接触瞬间，画面迅速转入半速慢动作，持续约……秒，呈现……；当……发生时，立即恢复正常速度，人物沿原受力方向……。”倍率可作为补充，如“半速慢动作（×0.5）”；慢放观看时长按当前看点与总预算分配，×0.5和0.5秒不是所有攻击的固定参数。时间轴给出所在区间即可，不为同一变化叠加大量重复时码和内部控制标签。

慢放仍有运动：接触形变、头肩偏转、重心位移或护层压缩连续推进；恢复速度时继承这些运动，不先贴住目标停姿，再无因弹飞。人物“高速攻击／飞退”描述运动速度，“半速／恢复正常速度”描述画面时间；相机跟随速度另行表达。整镜慢放时人物、兵器、衣发及环境运动一起减速；局部时间特效须明确作用范围。

本项目编写示例：“重斧高速砸向墨豆胸口。接触瞬间，画面迅速转入半速慢动作（×0.5），持续约0.5秒：胸前护层受压凹陷，肩背后弓，双脚开始离地。护层炸裂时，画面立即恢复正常速度，墨豆沿撞击方向猛烈倒飞，撞断木栏。”此为结合官方表达原则编写的方案，不是官方原文或已验证成片。

慢放占成片观看时长，须计入动作与对白预算；半速观看0.5秒约对应原速动作0.25秒。交付前检查每个设计的坡道都有触发、慢放内容、观看时长、恢复节点和连续结果。纯文本中的倍率、秒数是生成意图，不能保证模型精确执行；连续播放成片后核验，严格数值要求可用后期变速实现。不能把文字或九宫检视当作速度效果通过。

表达依据：[Runway官方提示指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)强调直接的视觉与运动描述；[Seedance官方文档](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=en)示例使用具体事件触发慢动作并接续碎裂、飞溅。由此采用事件驱动表达；不将这些来源解释为对任意模型精确倍率／时间控制的保证。

## 4. 特效美感与变身
### 特效设计与正文表达
内部先确定特效的视觉主形、作用范围、材质、运动与节奏；投喂正文写可见变化，不堆模拟器参数或抽象专业术语。用“动作触发→主形怎样运动／变化→接触产生什么反馈→怎样衰减并留下结果”组织必要信息，阶段可以重叠，不强制每次完整分步展示。

- 主形与身份：同一能力保持可辨识的形状与运动性格。贴身护层、随刃弧光、贴地气浪各有不同来源、轮廓与作用方式；不全部生成泛光球，不借视觉升级新增能力。
- 节奏与力度：形成、受压、爆发和衰减有变化，峰值集中在关键事件。可按动作需要使用压缩、突然展开、余势拖尾等表现；普通接触短促，高潮才展开。不把每招都加长蓄力或慢放。
- 焦点与层次：每个打点先确定一个主效果，再按需要补少量辅助层。轮廓、明暗对比、色彩与遮挡服务当前焦点；不让粒子、闪光、烟雾同时满强度。接触或结果被短暂遮挡后，要及时恢复可读性。
- 接触与材料：效果从真实刃缘、身体或命中处产生，方向随发力和运动路径。木材可弯断、撕出木屑，石材可裂开、成块崩出；水花、灰尘、小碎屑属于由主撞击带出的附属反馈，按现场材料选择，不凭空附加。奇幻护层的受压和破碎遵循已设定能力，不当作真实材料模拟结论。
- 环境融合：发光在近处表面形成有距离与遮挡关系的短促反光；能量、实物碎片与水尘区分运动方式。碎片保留惯性、落地和回落，气浪用水膜、衣摆或尘屑的变化显现，不只写“震撼气浪”。
- 结果继承：能量可衰减，实体伤损、裂地、断栏和人物失衡继续影响后续动作。特效不能结束就把场景复原，也不让全局持续光效掩盖局势变化。

正文示例：“斧刃压中胸前，贴身白光向内凹陷，亮度集中到接触处；护层随即裂开，碎亮沿撞击方向甩出，在墨豆倒飞时迅速熄灭。”只在当前画面需要时补材质、照明或碎屑细节；不把上述设计清单逐镜复述。

交付前检查主形是否可辨、关键变化是否有动作触发、接触与反馈方向是否一致、辅助层是否抢焦点、衰减后结果是否继承。失败时先定位主形、运动或执行偏差，再改单项；不靠不断追加特效层修复。

方法来源：[GDC Artistic Principles for VFX讲义](https://media.gdcvault.com/gdc2017/Presentations/Chamberlin_Keyser_ArtisticPrinciplesVFX.pdf)的形状、范围、焦点、颜色及时序主题；[Michael Lyndon的GDC讲座介绍](https://www.gdcvault.com/play/1025301/Visual-Effects-Bootcamp-Zip-Thwack)的动画原则用于特效；[Mark Spevick的SideFX破坏教程](https://www.sidefx.com/tutorials/brick-wall-destruction/)及[Houdini破坏文档](https://www.sidefx.com/docs/houdini/destruction/overview.html)的撞击、弯曲、破碎与附属反馈；[Runway官方指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)的直接视觉运动表达。这里是针对本技能的综合提炼，游戏特效原则按电影写实需要转用；已查文档、讲义检索摘要与讲座介绍，不宣称完整观看课程或本模型效果已验证。

宏伟用人物/地标、传播、遮挡与受者应对证明，不能只写尺寸或让法相成为背景。源、路径、命中和结果在镜头链中可判断；允许有目的的瞬间满屏火焰、碎片或曝光冲击，随后恢复主体和结果可读。禁止长期用光团掩盖交锋，不要求每一瞬间脸、武器、脚底和接点同时可见。明确要求持续可见的接点仍按用户执行。
变身在用户要求、既有剧情或自由设计权限内展开：触发动作→有辨识度的变化机制/传播→新形态及其打法兑现。可以在挥斩、追逐、转身或升空中完成，不只套粒子再跳终态，也不只加背后法相当作所有变身。剧情需要停顿则保留；变化可以涉及衣装、武器或身体结构，明确哪些身份特征保持、哪些改变、变化后状态如何延续。没有授权时不新增能力或改人物身份。
具体招式按需查特效索引、调用规则和命中条目，采用候选而非固定生命周期时长。条目镜头、透明度、收势和禁项不能覆盖当前授权与主编排。

## 5. 摄影与正文编译
从关键动作反推位置、机位、进入路径和离开状态。镜头跟随进攻、受迫位移、方向改变或尺度揭示，允许有依据的快速跟随、掠镜、拉远、倾斜与回震；不整段固定侧景旁观，也不持续乱甩。相邻镜头按具体切点与动作阶段接续；运动允许改变轴线，转变须可读，不把空间稳定写成人物位置永远不变。
按用户固定模板编写自然连续事件。保留剧情、对白/OS、声音、关键接触、时间与接口；内部位置表、逐关节推演、全部特效字段与评分不混入正文。稳定事实放全局，实际变化放时间段。检查持手、数量、比例、衣发、环境继承所需信息在相应镜头落实，不反复复述全局或把检查词当动作。

## 6. 内部复核与验证边界
逐段连读/预演，核对：时间内哪些顺序发生、哪些真正并行；慢放与对白是否计入；重点能否兑现；上一终态是否支持下一动作；能力覆盖、位移、支撑、持物和力量方向是否一致；取景是否容纳需要看清的信息。发现具体缺口才改对应句段，不为通过检查增加站稳、等待或全局口号。
原文/用户必需事件逐项有正文位置；自选内容删减不会删掉必要连接。九宫只抽采样状态，未入格动作、对白、声音和转场仍保留，不从九格重写正文。
用户满意《万相焚墟-30s》的力度、特效和变身是候选方法的反馈，不是本项目已验证成功。文字/静态检查不能证明Seedance速度或声音。成片速度需连续播放，声音需核听；抽帧只辅助姿态、空间与结果。对照验证保留同资产、剧情目标、时长和生成设置，优先比较连续爆发表达与逐步展示，再分别研究摄影/特效，不一轮全改。未授权不提交收费生成任务，不给成功率或精确慢放参数保证。
