# Seedance 2.x / 即梦视频提示词规则

本文件保留旧文件名以兼容 v2.8 的加载路径。内容已更新为九宫格、表演和多模态工作流。

## 1. 版本边界

- 把模型能力和限制视为版本化事实。
- 未获得当前官方说明或平台界面证据时，不宣称固定字符上限、固定素材数量、保证 4K、像素级锁脸或确定性运镜。
- 用户指定 Seedance 2.5 但没有相应官方规范时，标注 `Seedance 2.5-compatible draft`，使用已验证的 Seedance 2.x 生成逻辑和用户界面确认的参数。
- 时长、画幅、分辨率、音频开关和素材上限放在平台/API参数中；提示词只描述创作意图和连续性。

## 2. 九宫格与视频提示的关系

九宫格格号是分镜来源，OG 是视频生成单元：

```text
G01-P01...G01-P09 -> SH001...SH009 -> OG01/OG02...
```

每个 OG 通常应注明：

- 来源九宫格范围
- 起始状态和结束状态
- 角色与参考素材映射
- 逐时段动作与表演
- 镜头与声音
- 针对性约束

不要把九宫格九个画面强行塞进一个短视频。按动作和表演完整性组合镜头。

## 3. 多模态参考映射

逐项写明参考目的：

```text
@图片1：只参考角色 A 的身份、脸、发型、服装和体型。
@图片2：只参考场景布局、固定道具和主光方向。
@图片3：只参考武器形态和尺寸。
@视频1：只参考动作路径、受力节奏或运镜时机，不复制人物身份。
@音频1：只参考节拍、环境声或声音风格。
@九宫格1：参考 G01-P01 至 G01-P09 的镜头顺序、构图和连续性。
```

说明“保持什么”和“允许改变什么”。不要让同一参考模糊控制所有属性。

## 4. 提示词顺序

使用自然语言，按以下顺序：

1. 模式、时长、画幅、风格
2. 参考素材映射
3. 连续性脊柱
4. 九宫格来源与镜头时间段
5. 角色走位和可见动作
6. 表演节拍
7. 镜头、构图和主光
8. 对白、呼吸、拟音、撞击、环境声和音乐
9. 结束状态
10. 短而具体的约束

## 5. 单镜规则

- 一镜 1–2 个主要动作。
- 一镜一种主运镜或固定。
- 动作通常应有起点、路径和结束状态。
- 表演通常应有触发、可见变化和终态。
- 微表情使用 MCU/CU，并让镜头保持稳定。
- 复杂身体接触使用 MS/FS，保证双方和受力方向可见。
- 切镜应由剧情、动作、台词、视线或表演变化触发。

## 6. 表演写法

```text
当[具体触发]发生时，[第一无意识信号]；短暂停顿后，[第二信号]，
同时[头部/身体限制]。角色试图[掩饰或控制]，结束时[可读终态]。
```

每个短节拍只使用 2–4 个通道。沉默听者给一个有限反应。

示例：

```text
听见桥后脚步时，A 的呼吸先停半拍；视线先向后侧移动，头部仍朝前。
约半秒后，下颌轻微收紧，握剑手指逐渐用力。A 压住恐惧，结束时保持
身体挡在 B 与脚步声之间。
```

## 7. 打斗写法

```text
A 先锁定 B 的右肩，右脚向前半步压低重心，双手持刀从画面左下斜劈
向右上。刀背在 B 胸前护臂处接触；B 沿同一受力方向后退两步，左脚
打滑，以刀尖触地重新稳住。双方结束位置和武器状态明确。
```

通常应写：

- 攻击与防守角色
- 屏幕方向
- 重心和发力路径
- 接触点
- 受力方向
- 恢复或失衡
- 环境接触反馈

## 8. 声音层

按需分开：

- 对白/人声
- 呼吸和发力声
- 拟音
- 撞击
- 环境声
- 音乐

关键声音通常应绑定可见事件。不要在剧本未要求时自动添加对白、旁白或音乐。

## 9. 九宫格来源的 OG 模板

```text
Seedance 2.x 视频提示词

模式：[文生视频/图生视频/多模态参考/首尾帧/续写/局部编辑]
输出：[时长]，[画幅]，[风格]。平台参数使用当前界面设置。
来源：九宫格 G01-P01 至 G01-P05。

参考映射：
- @图片1：[用途]
- @视频1：[用途]

连续性：
角色 A 从[位置/朝向/道具状态]开始；角色 B 从[位置]开始。
[场景锚点]和[主光方向]保持不变。战斗/对话轴线为[方向]。

0.0-X秒：
[基线、触发、微动作/微表情、镜头]

X-Y秒：
[动作起势、路径、接触、受力反应、镜头]

Y-Z秒：
[恢复、结果、表演终态、结束构图]

声音：
[对白/呼吸/拟音/撞击/环境/音乐的时间同步]

结束状态：
[人物位置、朝向、视线、道具、场景状态和光影]

约束：
[只列本段高风险问题]
```

## 10. 9:16 竖屏补充

- 把主要人物和关键接触点放在竖屏安全区域。
- 多人场景使用前、中、后三层，不把所有脸挤在同一平面。
- 特写优先眼睛和嘴部可读；动作镜通常应保留手臂、武器与接触点。
- 不要在提示词里宣称具体像素、绝对安全框百分比或镜头型号能保证输出质量。

## 11. 局部编辑

```text
只编辑[时间段/人物/区域/属性]。尽量保留原视频的镜头路径、节奏、
人物动作、面部表演、光线方向、背景、声音和目标区域之外的内容。
把[旧状态]改为[新状态]，从[事件]开始，在[事件]结束。
不得改变[受保护属性]。
```

## 12. 针对性约束

从实际风险中选择：

```text
不新增角色、台词或攻击；不复制武器；不交换左右位置；不改变视线目标；
不让受击反应逆着力线；不突然环绕；不在单镜头内跳切；不发生身份漂移、
面部形变、道具瞬移、背景闪烁或光源方向变化。
```

避免冗长、互相冲突的负面词库和无法保证的“AAA 完美品质”承诺。

## 13. 检查

- [ ] 九宫格来源明确
- [ ] 参考素材逐项分工
- [ ] 起止状态明确
- [ ] 每镜 1–2 个动作和一种主运镜
- [ ] 表演变化有触发
- [ ] 台词逐字
- [ ] 受力方向正确
- [ ] 身份、站位、视线、道具、场景和光影连续
- [ ] 声音与可见事件同步
- [ ] 约束短而具体
- [ ] 未把未确认的平台参数写成硬规则
