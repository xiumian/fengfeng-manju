# 文本表演与动作转换

## 1. 事实与转译

区分：

- `剧本确认`：原文明确写出的动作、表情、情绪、台词和反应。
- `素材确认`：角色图、场景图、动作视频中可见的事实。
- `表演转译`：为使抽象情绪可见而推导的克制微动作。
- `缺失决策`：不同选择会改变剧情、角色关系或镜头的内容。

表演转译只能使既有意图可见，不能新增剧情事件。

## 2. 六字段情绪节拍

| 字段 | 问题 |
|---|---|
| baseline | 触发前的可见状态是什么？ |
| inner_state | 人物真正感到什么、想要什么或隐藏什么？ |
| trigger | 哪个声音、动作、触碰、目光或关键词引起变化？ |
| leak | 隐藏状态最先从哪里短暂露出？ |
| mask | 人物如何压回、转移或控制它？ |
| end_state | 镜头结束时观众应该读到什么？ |

表达顺序：

```text
baseline -> trigger -> involuntary leak -> controlled response -> end state
```

## 3. 可见通道

每个短节拍选 2–4 个：

- 视线停住、移动、回避、迟回、锁定
- 眼睑轻颤、眨眼节奏短暂变化、下眼睑略紧
- 一侧眉毛轻抬、眉部短暂聚拢
- 嘴唇抿紧、微张、嘴角短暂变化、下颌收紧
- 呼吸停顿、浅吸气、受控呼气、吞咽
- 肩膀短暂僵硬、躯干后撤、姿态变静
- 手指收紧、握力改变、触碰道具后停住

描述变化，不写冻结标签。

## 4. 克制型转译表

| 内在状态 | 泄漏 | 控制/恢复 |
|---|---|---|
| 怀疑 | 视线停住；下眼睑略紧；一侧眉轻抬 | 眉部放松，目光仍固定 |
| 突然害怕 | 呼吸停止；嘴唇微张；肩膀短暂停住 | 受控呼气；下颌收紧 |
| 压住怒气 | 下颌收紧；鼻翼略张；目光锁定 | 身体变静；停顿后说话 |
| 受伤却装平静 | 笑意停住；吸气卡住；下巴微收 | 有意识眨眼；谨慎恢复中性 |
| 心虚/回避 | 视线离开；回答延迟；嘴唇轻抿 | 目光较晚返回；短暂礼貌掩饰 |
| 认出对方 | 眨眼停止；视线聚焦；眉毛轻抬 | 小幅吸气；状态随关系变软或变硬 |
| 暗自欣喜 | 眼神先柔和；一侧嘴角短暂上扬 | 压住笑意；面部回稳 |
| 疲倦转警觉 | 眼睑轻颤；眼睛先睁一线；视线先动 | 下颌收紧；头部稍后再转 |

使用最低可读强度：痕迹级、克制级、清晰级、外放级。默认克制级；外放级只在原文确认时使用。

## 5. 时间顺序

- 隐藏注意力：眼睛 → 停顿 → 头部
- 犹豫：吸气 → 停顿 → 台词
- 克制愤怒：目光锁定 → 下颌收紧 → 身体变静 → 台词
- 突然冲击：呼吸停止 → 眼神变化 → 姿态冻结 → 恢复
- 攻击决心：目光选定目标 → 重心转移 → 武器启动
- 受击疼痛：接触 → 呼气/闷哼 → 躯干反应 → 恢复平衡

## 6. 对话表演

给每段台词标注：

- 说话者和听话者
- 说话时是否移动
- 语速和停顿
- 强调词
- 呼吸位置
- 说话者终态
- 听话者一个有限反应

长台词按话题、情绪、权力、视线目标或走位变化拆分，不按平均字数机械切分。

## 7. 打斗表演

每次攻击：

```text
intent -> preparation -> launch path -> contact -> reaction -> recovery
```

攻击者：

- 视线选定目标
- 重心和髋肩准备
- 武器或肢体沿明确路径启动
- 接触后保持或回收视线
- 用呼吸、握力和姿态表现消耗

防守/受击者：

- 察觉来向
- 防御起手
- 沿同一力线反应
- 脚步失衡或重新稳定
- 更新伤损、道具和位置状态

旁观者只给一个有限反应，不抢占动作主线。

## 8. 镜头支持

- 痕迹级表演：CU/MCU，固定
- 克制表演：MCU/CU，固定或极缓推
- 清晰身体反应：MS
- 接触动作：MS/FS，稳定机位或单一跟拍
- 不在关键微表情期间使用快速摇镜、无动机环绕或强烈手持

## 9. 针对性约束

按实际风险选择：

```text
不保持冻结中性脸，不持续同一表情，不夸张瞪眼，不机械眨眼，
不突然甩头，不发生面部形变，不漂移身份，不瞬移道具，
不让受击反应逆着力线，不新增攻击或台词。
```
