# 标准分镜术语与镜头类型参考

## 一、景别详解

| 景别 | 英文 | 画幅范围 | 情感功能 | 典型用途 |
|------|------|---------|---------|---------|
| 大远景 | Extreme Wide Shot (EWS) | 人物极小，环境极大 | 渺小、史诗、地理感 | 开场建立、史诗段落 |
| 远景 | Wide Shot (WS) | 完整人物+大量环境 | 处境感、孤独 | 建立人物与环境关系 |
| 全景 | Full Shot (FS) | 完整人物头到脚 | 整体状态、行动意图 | 动作交代、人物登场 |
| 中景 | Medium Shot (MS) | 腰部以上 | 互动、交流 | 对话场景、动作场景 |
| 中近景 | Medium Close-Up (MCU) | 胸部以上 | 情绪沟通 | 对话、情感交流 |
| 近景 | Close-Up (CU) | 肩部以上，面部为主 | 情绪细节 | 情感高潮、心理状态 |
| 特写 | Extreme Close-Up (ECU) | 面部局部/手/道具 | 强调关键信息 | 关键道具、极度情绪 |

## 二、运镜详解

### 固定镜头
| 运镜 | 说明 | 情感效果 |
|------|------|---------|
| 静止固定 | 三脚架完全固定 | 冷静、客观、正式、压迫 |
| 轻微抖动 | 手持模拟轻微晃动 | 临场感、纪实感 |

### 平移镜头
| 运镜 | 说明 | 情感效果 |
|------|------|---------|
| 左摇 | 镜头向左旋转 | 揭示左侧内容，跟随向右移动的主体 |
| 右摇 | 镜头向右旋转 | 揭示右侧内容 |
| 上摇 | 镜头向上旋转 | 仰望、期待、宏大 |
| 下摇 | 镜头向下旋转 | 低落、下沉、审视 |
| 横移（左/右） | 镜头横向平移 | 跟随、追逐、环境扫描 |

### 纵深镜头
| 运镜 | 说明 | 情感效果 |
|------|------|---------|
| 推镜 | 镜头向主体推进 | 聚焦、压迫、揭示情绪 |
| 拉镜 | 镜头向后退出 | 孤独、揭示背景、解脱 |
| 变焦推（Zoom In） | 变焦而非物理推进 | 警觉、恐惧（希区柯克效果） |
| 升镜 | 镜头上升 | 揭示、伟大、神圣 |
| 降镜 | 镜头下降 | 压迫、沉重、审视 |

### 特殊运镜
| 运镜 | 说明 | 情感效果 |
|------|------|---------|
| 环绕360° | 镜头围绕主体旋转一圈 | 戏剧高潮、全景展示 |
| 斯坦尼康跟拍 | 稳定器跟随主体 | 临场感、沉浸感 |
| 手持跟拍 | 不稳定跟随 | 紧迫、混乱、真实 |
| 无人机俯拍 | 高空俯视 | 宏大、渺小、上帝视角 |
| 主观镜头（POV） | 代入角色视角 | 沉浸感、压迫感 |

## 三、构图进阶技法

### 人物多人构图
| 构图 | 说明 |
|------|------|
| 正反打 | 两角色交替近景，标准对话剪辑 |
| 过肩镜头 | 一人的肩膀作为前景，拍另一人 |
| 双人同框 | 两人同时在画面内，表现关系 |

### 空间深度构图
| 构图 | 说明 |
|------|------|
| 前中后三层 | 前景/中景/背景各有元素，空间纵深感强 |
| 前景遮挡 | 门框/植物/人物遮挡部分画面，神秘感 |
| 隧道构图 | 走廊/门洞形成框架，聚焦主体 |

## 四、分镜节奏参考

### 按剧情类型的推荐单镜时长

| 场景类型 | 建议时长 | 说明 |
|---------|---------|------|
| 建立空镜 | 4-8秒 | 充分展示环境 |
| 普通对话 | 3-5秒 | 标准正反打节奏 |
| 情绪特写 | 3-6秒 | 给观众充分感受情绪的时间 |
| 动作追逐 | 1-2秒 | 快切制造紧迫感 |
| 情绪高潮推镜 | 4-8秒 | 慢推延长情绪积累 |
| 结尾空镜 | 5-10秒 | 余韵 |

## 五、180度法则（重要！防穿帮）

```
场景示例：
  人物A ←→ 人物B
  摄像机只能在A-B连线的一侧（假想轴的同侧）进行拍摄
  
✅ 正确：A在左，B在右（两个镜头保持一致）
❌ 穿帮：一个镜头A在左，下一个镜头A在右（越轴穿帮）

越轴时需要使用过渡镜头：
- 拍摄正对轴线的镜头作为过渡
- 用运动镜头越过轴线
```
