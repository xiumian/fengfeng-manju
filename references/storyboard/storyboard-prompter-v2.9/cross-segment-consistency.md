# 跨段落一致性追踪参考

> storyboard-prompter v2.1 参考文档 — 确保多段落/多场景之间的状态连续性。

---

## 1. 什么是跨段落一致性

AI 视频生成的每个段落（Segment）是独立生成的，模型没有"上一段发生了什么"的记忆。跨段落一致性追踪就是在分镜脚本层面，提前标注每个段落的起止状态，确保——即使 AI 不记得上一段——提示词也会强制执行正确的起始状态。

**核心公式**：
```
Seg-N 末尾状态 = Seg-N+1 提示词中的起始状态
```

---

## 2. 五个检查维度

### 2.1 位置连续性

追踪每个角色在段落边界的空间位置。

**规则**：
- Seg-N 最后一镜人物站在哪里、面朝哪个方向 → Seg-N+1 第一镜通常应从同一位置/方向开始
- 不允许出现"上一段在门口，下一段突然在房间深处"的跳帧
- 如果确实需要跳位置，通常应在段落间插入过渡镜（如"切至3分钟后"的时间过渡）

**检查方法**：
```
人物-X 在 Seg-N 末尾：站于餐桌右侧，面朝门口
人物-X 在 Seg-N+1 开始：站于餐桌右侧，面朝门口  ← 通常应一致
```

### 2.2 环境状态连续性

追踪场景的"初始态"与"破坏后"状态。

**引用 film-asset-prompter 的场景多状态版本**：
- 初始态锁定标签：`S001_宴会厅_ArtDeco_初始态`
- 破坏后锁定标签：`S001_宴会厅_ArtDeco_破坏后_桌椅翻倒`

**规则**：
- 场景一旦在某段落被破坏，后续所有段落通常应使用破坏后版本标签
- 不允许"上一段桌椅翻倒，下一段又恢复整齐"（除非有明确的收拾/恢复镜头）
- 多个破坏事件有累积效应：
  - 事件1（翻桌）→ 使用 `_桌椅翻倒` 标签
  - 事件2（碎窗）→ 升级为 `_桌椅翻倒_玻璃碎裂` 标签

### 2.3 人物衣着累积变化

追踪服装的"损伤累积"。

| 事件 | 衣着状态变化 | 锁定标签更新 |
|------|-----------|------------|
| 被泼酒 | 胸前湿透 | `林知_绛红礼服_胸前湿痕` |
| 摔倒 | 裙摆破损 + 膝盖污渍 | `林知_绛红礼服_胸前湿痕_裙摆破损` |
| 被扯领口 | 领口撕裂 | `林知_绛红礼服_胸前湿痕_裙摆破损_领口撕裂` |

**规则**：
- 衣着一旦发生损伤，标签通常应即时更新
- 后续所有镜头使用更新后的标签
- OR 使用叠加标签：`[原始标签] + [损伤状态标签]` 的组合方式

### 2.4 道具因果链

追踪关键道具的完整生命周期。

```
道具出现 → 被谁持有 → 如何使用 → 是否转移 → 如何消失

示例：酒杯
镜5：林知手持酒杯（出现）
镜7：酒杯摔碎在地（消失/破坏）
镜8+：地面有酒杯碎片（残留物持续存在）
```

**规则**：
- 道具出现在某镜中→持有者通常应明确
- 道具被破坏/掉落→残留物通常应在后续镜头中体现
- 道具被角色A交给角色B→在B的后续镜头中通常应可见

### 2.5 场景版本对应

确保每个镜头引用正确的场景版本锁定标签。

**引用规则**：
- 初始段落：使用初始态场景标签
- 破坏事件后：自动切换为破坏后标签
- 不可恢复初始态标签除非有恢复镜头

## 4. 一致性修复流程

当发现跨段落不一致时，按以下优先级修复：

| 优先级 | 不一致类型 | 修复方式 |
|-------|---------|---------|
| P0 | 人物位置跳跃 | 插入过渡镜头，或在Seg-N+1起始镜中明确标注"从[位置]开始" |
| P0 | 场景版本错用 | 更正为正确的锁定标签（初始态→破坏后） |
| P1 | 衣着状态回退 | 更新锁定标签，加入损伤叠加 |
| P1 | 道具消失 | 补充残留意象或明确移除镜头 |
| P2 | 次要人物位置漂移 | 在全景过渡镜中隐含修正 |

## 5. 常见失败模式

| 失败模式 | 原因 | 解决方案 |
|---------|------|---------|
| 场景"自我修复" | 新段落未使用破坏后标签 | 强制检查场景版本对应 |
| 人物瞬移 | 两段落间位置未对齐 | 用位置连续性表逐镜验证 |
| 衣服"自动修复" | 损伤未累积到标签 | 每发生损伤即更新锁定标签 |
| 道具幽灵 | 破坏后没有残留物 | 道具因果链检查 |
| 光线时间跳跃 | 段落间未标注时间流逝 | 插入"3小时后"时间戳或光色过渡镜 |
