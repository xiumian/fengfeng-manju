本文件保留专项参考知识，不是主流程或视频输出模板。只在相关题材读取；当前SKILL.md与references/contracts.md优先。来源中的规则、效果断言和数值是创作经验，不是官方模型能力或预测保证；不机械套用于所有题材。

# 不同视频类型的创作要点

## 1. 教程类（How-to）

### 特点
- 实用价值高，完播率较好
- 容易涨粉（用户会收藏关注）
- 适合知识分享、技能教学

### 创作要点
- **开头**：展示成果（吸引点击）
  - "我用这个方法7天瘦了5斤"
  - "学会这个技巧，拍照好看10倍"

- **结构**：
  1. 引入问题（5秒）
  2. 分步演示（20-40秒）
  3. 成果展示（5秒）
  4. 关注引导（2秒）

- **技巧**：
  - 使用快进（1.5-2倍速）压缩冗长部分
  - 添加文字标注和箭头指示
  - 关键步骤慢放或定格
  - 背景音乐不要盖过讲解声

### 脚本模板
```
【开头】
画面：展示最终成果
文案：教你XXX，超简单！

【正文】
画面：分步操作
文案：
第一步：...
第二步：...
第三步：...

【结尾】
画面：再次展示成果
文案：学会了吗？关注我学更多
```

## 2. 种草类（Product Review）

### 特点
- 带货能力强
- 需要真实体验和诚意
- 避免过度营销

### 创作要点
- **开头**：痛点引入
  - "你是不是也为XXX烦恼？"
  - "之前用过很多XXX，直到遇到这个..."

- **结构**：
  1. 痛点描述（5秒）
  2. 产品介绍（15秒）
  3. 使用演示（20秒）
  4. 优缺点总结（10秒）
  5. 购买建议（5秒）

- **技巧**：
  - 真实使用场景（不要只是展示产品）
  - 突出1-2个核心卖点（不要罗列所有功能）
  - 提及缺点增加可信度
  - 对比使用前/后效果

### 脚本模板
```
【开头】
画面：问题场景
文案：XX问题困扰我好久了

【正文】
画面：产品展示 + 使用演示
文案：
这个XXX真的绝了
最大的优点是XXX
用起来很方便...

缺点也要说一下：XXX

【结尾】
画面：产品特写
文案：适合XXX人群，不适合XXX人群
```

## 3. 剧情类（Skits/Drama）

### 特点
- 娱乐性强，容易爆款
- 需要创意和表演能力
- 适合打造人设和IP

### 创作要点
- **开头**：直接进入冲突（3秒内）
  - 不要铺垫，直接开始对话/动作
  - 第一句话就要有张力

- **结构**：
  1. 设定场景（3秒）
  2. 冲突展开（15秒）
  3. 反转/高潮（10秒）
  4. 结尾金句/悬念（5秒）

- **技巧**：
  - 时长控制在15-30秒（一集一个笑点）
  - 固定人设和角色关系
  - 使用字幕强调金句
  - 背景音乐配合情绪

### 脚本模板
```
【场景】时间 + 地点 + 人物

【冲突】
A：...
B：...

【反转】
A：...（意想不到的回答）

【结尾】
金句/悬念/引导关注
```

## 4. Vlog类（Daily Vlog）

### 特点
- 真实感强，容易建立信任
- 适合打造个人IP
- 需要一定的剪辑审美

### 创作要点
- **开头**：精彩预告
  - 剪辑一天中最精彩的片段作为开头
  - 配上吸引人的文案

- **结构**：
  1. 开头预告（5秒）
  2. 时间线叙事（30-40秒）
  3. 亮点/感悟（10秒）
  4. 结尾引导（5秒）

- **技巧**：
  - 使用画中画展示多视角
  - 添加时间戳（"早上9点"、"下午3点"）
  - 背景音乐匹配情绪变化
  - 适当加速无聊片段

### 脚本模板
```
【开头】
画面：精彩片段合集
文案：今天发生了什么什么...

【正文】
画面：按时间线拍摄
文案/字幕：
09:00 起床...
12:00 午餐...
15:00 工作/学习...
19:00 晚餐/娱乐...

【结尾】
画面：感悟时刻/美照
文案：今天很充实，明天继续加油
```

## 5. 测评类（Testing/Challenge）

### 特点
- 好奇心驱动，点击率高
- 适合猎奇、美食、美妆领域
- 需要投入成本（购买测评物品）

### 创作要点
- **开头**：悬念设置
  - "网上很火的XXX，真的好用吗？"
  - "挑战用XX元搞定XXX"

- **结构**：
  1. 引入话题（5秒）
  2. 测评过程（30秒）
  3. 结果公布（10秒）
  4. 推荐指数（5秒）

- **技巧**：
  - 真实反应（不要演）
  - 对比多个产品
  - 给出明确结论
  - 使用分屏对比效果

### 脚本模板
```
【开头】
画面：展示测评物品
文案：买了网上很火的XXX，来试试好不好用

【正文】
画面：逐一测评
文案：
第一款：...
优点：...
缺点：...
评分：XX分

第二款：...
...

【结尾】
画面：总结
文案：最推荐XXX，性价比最高
```

## 6. 知识分享类（Knowledge Sharing）

### 特点
- 干货满满，收藏率高
- 适合专业领域（法律、金融、健康等）
- 需要专业度和表达力

### 创作要点
- **开头**：颠覆认知 or 直击痛点
  - "90%的人都不知道..."
  - "这件事你可能一直做错了"

- **结构**：
  1. 抛出观点（5秒）
  2. 解释原因（15秒）
  3. 给出方法（20秒）
  4. 总结升华（5秒）

- **技巧**：
  - 使用图表、动画辅助说明
  - 语言通俗易懂（避免专业术语）
  - 分段标题（"第一点"、"第二点"）
  - 引导收藏（"建议收藏慢慢看"）

### 脚本模板
```
【开头】
画面：真人出镜 or 文字标题
文案：关于XXX，你可能一直都错了

【正文】
画面：配合文字/图表讲解
文案：
其实原因是XXX
正确的做法应该是...
记住这3点：
1...
2...
3...

【结尾】
画面：总结
文案：你学会了吗？关注我学更多知识
```

## 7. 搞笑类（Comedy）

### 特点
- 传播性强，容易爆款
- 需要幽默感和创意
- 不适合所有领域（需符合人设）

### 创作要点
- **开头**：直接抛出笑点（不要铺垫）
- **结构**：铺垫 → 反转 → 笑点
- **技巧**：
  - 使用流行梗（但不要过度）
  - 夸张表演
  - 配合搞笑音效
  - 字幕强调笑点

---

## 8. 美食类（Food）

### 特点
- 受众广，完播率高
- 需要拍摄技巧（光线、构图）
- 适合种草、教程、探店

### 创作要点
- **拍摄技巧**：
  - 特写食物细节（滋滋声、拉丝效果）
  - 保证光线充足（自然光最佳）
  - 45度角 or 俯拍
  - 添加ASMR音效

- **剪辑技巧**：
  - 快节奏剪辑（0.5-1秒一个镜头）
  - 颜色鲜艳（提高饱和度）
  - 背景音乐轻快
  - 添加文字描述口感

## 通用创作技巧

### 提升完播率
1. 前3秒通常应吸引人
2. 节奏紧凑（每5秒一个信息点）
3. 时长适中（15-30秒最佳）
4. 结尾悬念（"下期告诉你..."）

### 提升互动率
1. 提问引导（"你们觉得呢？"）
2. 争议话题（适度）
3. 挑战互动（"你能做到吗？"）
4. 评论区抽奖

### 提升转发率
1. 实用干货（用户会分享给朋友）
2. 情感共鸣（"说出了我的心声"）
3. 社交货币（转发显得有品味/有趣）
4.  @朋友（"@你那个吃货朋友"）

### 提升关注率
1. 系列内容（"关注看下集"）
2. 固定更新时间
3. 明确价值（"关注我，每天学一个技巧"）
4. 人设魅力（让用户喜欢你）
