# 原自动检查规则迁移台账

当前正文为亡灵架构，仅Codex，H3排除。检查器保留确定结构错误阻断，启发式采用告警+人工核对，不伪装空间语义证明。

|原能力|当前处理|
|---|---|
|C1预算|连续时长与显式--max-duration，模型历史硬上限不默认启用|
|C2镜数|九格不是九切，原ceil(时长/3)强制规则不恢复；动作容量人工核对|
|C3时间轴|断档、重叠、倒挂与对白越界阻断|
|C5版本语法|不恢复未经核实版本词根禁令；默认统一亡灵架构|
|C6画幅|缺画幅告警，明确--aspect不匹配阻断|
|C7七段式|依主人选择改为亡灵正文；旧框架管理字段阻断|
|C8首尾限制|原旧参数不恢复，按当前工具/平台核实|
|C9平台呈现|保留专项知识，不承诺审核；非Codex平台已排除，不把词根列表当通用创作禁令|
|C10长节点|>6秒告警核对，不机械切镜|
|C11接续|状态字段/段缝人工核对，禁止旧【接续状态】混正文|
|C12规则词|否定结果/工作流词根告警，非自动删除原文|
|C13等时|高度雷同时长告警|
|C14画外声|OS/VO与开口词同段提示核对说话者；声源/口型实际由助手审核|
|C15凑时|无对白长静态/氛围告警，动作戏不直接当纯氛围|
|C16语气|语气位缺失、发声字数预算告警；强语气与闲适道具动作同段告警、裸情绪语气告警，具体人物/意图人工核对|
|C17人账|显式--characters检查正文缺人，提醒离画/未入镜例外；不从模糊描述猜人名|
|C18首镜/景别/姿态|显式人物首镜、特写空间冲突、起身后躺回告警；具体视线/材质仍人工核对|
|C19禁令|否定式与流程词告警，反光道具光路/映射触发词告警，具体光路/肌肉等复杂语义人工核对|
|C20具象化|悬空指代与抽象结果词告警；单主体等源特殊经验只在适用场景调用，不能一律禁止双人戏|

此表是每项处理去向，不是声称20项全部自动等价。需要语义或实际产物的检查有明确助手复审入口；被当前要求替换的硬规则不机械复活。新增检查改动必须带触发与例外测试，不能以告警数当质量分。
