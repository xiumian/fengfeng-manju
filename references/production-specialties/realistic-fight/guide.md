# 写实打斗专项｜让攻防与重量被看见

主责 action。用于写实感、实体接触、连续攻防或必须可信的受力；幻想打斗可借用接触、支撑和追踪方法，不把现实条件硬套到已确认的法术能力。这里写的是镜头和虚构演员／动画角色的表现，不提供现实实战、解除控制或致伤做法。

## 先排双方，不先选招式名称

1. 从原稿取行动者、目标、防守者可感知的威胁、初始站位及支撑、持物与已经锁定的结果。明确是落空、接挡、擦过、连续贴合还是离开接触；看不见某人不等于他停止动作。
2. 每次交换只追一项可读的局势变化：通道从封住到打开、距离从足够到被挤没、某一侧露出空隙、道具或支撑改变。**下一拍由对方实际应对留下的条件引起**，不是命中后两人回到初始姿势再轮流出招。
3. 时间关系逐条区分：同时发生、尚未结束时接入、必须先后成立。短镜不发明“站稳等下一拍”。按本场可读性与动作阶段确定容量，不照搬来源示例的镜数、回合数、节拍长度。
4. 起势到离开写出相对速度变化：何时接近、何处确实受阻、哪些东西还在靠惯性走、何时进入下一任务。双方的路线与节奏可以不同，但一方的拍点不能让另一方无因停顿。

## 让接触和材质拥有因果

先辨初始状态→实际触发→局部响应→连带响应→最后保留变化。不是每一项都写满：盾片硬，先偏角再传到握持者的肩线；衣角、尘尾可滞后；旧裂纹和道具归属必须承到下一镜。落空不添命中声，分开擦过、盾上接触与材料真破裂。若本拍仅改变距离，表现脚下位移与接近方向，不为重量感强补重击、顿帧或镜震。

[动作与受力方法](references/choreography.md)用来设计同屏接触、双方动作、受力转折和下一拍的位置；需要变化时，从[打斗编排库](../../打斗编排库/索引.md)按场景选组合，不照条目顺序排镜。

## 交到本 Skill 的工序

- action 要交：双方原相对关系、实际接触或落空位置、应对者怎么改变局面、这次变化使谁获得下一行动机会、动作留在什么状态。
- camera 要保住：足以读到接触及反作用的观察侧。需要切近时接同一动作相位，不重复接触；主镜可看清就不逐动作甩镜。sound 以可见事件区分掠过、接触和材料破坏，延续声不重启。
- compile 让角色、方向、作用点与结果进入可观测句；别将“重心明确”或“打击感强”当结果。validate 先暂时不看声光强调：能从画面读出谁改变了谁的动作/位置，再核对六项音效。验证未看片时只说文字符合。

**角色试例。** 阿岚的扇风仍顶着盾心，盾缘朝同一方向偏过去，执盾者仍维持手上承压；偏转露出原有裂口，阿岚先看见裂口才改扇向。失败稿“她又发一招，对手后退”看不出偏转、发现和改线的关系。这个例子只演示交接，不默认所有盾都裂、对手都退。
