# 表情专项｜选得对、拍得到、表演不重启

主责 performance。用于近景表情、情绪由一种行为转向另一种、嘴眼与手上任务不一致时的精细表演。已有 microexpression 负责一般细微迹象，本专项补**段内转折与近景起落**；普通说台词不强制调两套。首要依据是本角色的处境、当前目标和允许被看见的表达，不按表情诊断现实心理。

## 给一个可以演出来的变化

- 先交代角色正在做什么、什么时候接收到触发、最后改变哪个动作。她可以持续拿住东西、支撑、开口或闪避；不为眼睛特写让全体停下等反应。已经持续的眉眼、呼吸和握持不是新的串行动作。
- 用「原来的可见状态 → 哪一小处先改变 → 变化如何接到下一行动」短记。选一两处有效线索，不强填器官数。近景可读的细节，如目光从物件根部移到缺口、嘴角想维持但落下来；中景优先用可读的头部转向、手上动作和距离变化。
- 想掩饰、勉强笑或暂缓发作必须有剧情动机；不是每次演绎都要有额纹、下颌、嘴角和鼻翼联动。说话、跑动和情绪呼吸分别确认原因，只有确有相容窗口时才并行。
- 表演交触发、可见动作、维持中任务和持续到下镜的状态。摄影验证角度、占比、遮挡和时间；声音落实发声与气息，不反推新的心理；编译保留实际先后，不因切近让演员重新做已发生的转眼。

[可见线索选择](references/cue-selection.md)按眼神、呼吸、口部和正在进行的动作，挑观众真能从此机位读到的变化。不把专业词当中文直投里的解剖口令，也不认定同样的表情一定代表同一种情绪。

**动作戏的用法。** 阿岚扇势还在压盾中心；裂口刚露，她的眼睛先落到那里，持扇的手才转向。对手仍撑盾而不是等她演完。这个变化的作用是让观众看清她为何换招，不是要求她先露出惊讶脸。
