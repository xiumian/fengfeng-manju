# 特效形态速查：先区分行为，再加层

实际候选从现有招式库选；下表描述可见规律，不宣布任何效果是生成模型的隐藏选项。按已定剧情、空间和物质结果取用。

| 形态 | 成形与传播 | 接触及后续 |
|---|---|---|
| 风束与引流 | 从握持物、手或已有开口起，窄芯带动薄边。绕过阻挡时沿表面改线，细屑不独立抢方向 | 浅水先在前端分开，较重碎块等真正接触后才动；退流由远处慢慢回到原水面 |
| 冷电 | 单根短枝产生并陆续分岔，间隙能看见原物轮廓。电枝只走已经建立的表面或空气轨迹 | 局部高光掠过，不用满屏白。电流止于确定边沿，材质变化另由事件造成 |
| 晶层开裂 | 断线从受到变化的部位向相邻处延长；先看到两侧板块间出现真实错台，再允许实体离开 | 断面亮、外壳暗。飞块有体积和惯性，光退后缺口、落点还在；远处完整材质不跟着碎 |
| 透明受力前沿 | 正面看主要靠光线折射，斜侧看靠水线、衣摆或沙尘在经过时依次偏动 | 写形成点、主要去向、作用边界；前沿先到，轻雾迟一点，界外未被吹到的标识仍原样 |
| 湿雾与蒸汽 | 从接触的湿面或水层生成，近处厚、离源渐松；方向受风或上升过程决定 | 浓度高也要给接点或反应留一侧可见；退场分“停止补给”和“已在空气中的雾尚未散掉” |
| 热光与余火 | 亮核先在实际热源处形成，离开热源的光点逐渐变暗，影子受真实遮挡 | 余火贴附已有边缘，暗物或距离之外不同时发光；可让余火先退、真实焦痕后留 |
| 体量成形 | 先聚成能认出的主轮廓，再延伸相连部件；金鳞、尾丝或冰棱从主形带动，不各自无因出现 | 与支撑物或阻挡真正接触后才产生局部破坏。明确是主形停住、穿过去，还是按局部先后退散 |

**设计一处明确的边界。** 哪一条现有台沿、水沟或柱脚能证明传播到这里就衰了？同时找一件界外继续保持原状态的物件。不要同时增加无来由的第二爆点。压缩稿也留下“去掉效果名字后还剩哪些动作证据”。
