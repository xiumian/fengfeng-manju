# 换机位与跨风格：检查画面真的容得下

1. **先放现场，再放相机。** 记录必须持续有效的可达位置、朝向、视线与道具归属。换到另一侧时重新判断画面左右、前景遮挡和背后真会出现什么；不照抄旧图的左右或旧光向。
2. **同时要见两样时，先保其关系。** 人物的视线、被看的证据、另一端还在发生的动作，对目前故事分别属于必看、可听到还是只须持续。大空间关系不能只靠孤立的眼睛特写；窄小物证不能只写全景里的“她看清了字”。
3. **同镜能拍才留镜。** 原地转头与移焦并不改变被遮挡物的可见面。从另一个实在位置才可以露出来的东西，不靠一句机位固定却看到了背面解决。镜内移动写出可达路线，移过去再看一眼遮挡是否终于解除。
4. **只补缺失的信息。** 开头已拍到门关着，重新拍一次无变化的门没有收益。如果这一拍是插销从槽里滑出来，短镜只承接已形成的移动，并留辨认它的新位置的时间。
5. **媒介变化，事件关系不变。** 真实材质可用湿表面与反射说明木板转动；风格化三维或二维可用体块、阴影与凹痕做同样的证据。媒介和资产身份锁定后不默认改成真人，不因光线变更调换事件结果。

**给下一镜的证据。** 高位姿态图只能给当时能看见的站位；真的需要接相位、速度或说到哪个字，须由当前提供的可读视频、确证资料或当前方案说明。素材不足就标规划而不是实拍。
