# 跨风格分镜专项｜以可见变化选视点

主责 camera。适用于拍法选择、线索揭示、连续位移、多人动作、道具交接或混合媒介。附件是条件方法与示例，不继承原包的真人默认、镜首固定摄影字段、周期背景运动或独立交付格式。

## 按“可辨认的最小变化”选拍法

1. 先写这一拍观众必须看到哪个**状态差**，比如托盘从一人支撑变成两人承重，再到旧持有者松开。不是因为出现一只手就切手，也不因为一句台词结束就切脸。
2. 分开判断：角色此刻能不能得到线索、摄像机从此处能不能看见、观众在留给它的时间里能不能认出来。存在遮挡先换观察侧；已见但太小才缩紧取景；当前在移动且已快出框才跟。角色没有看见，不让他因观众看见的信息而提前行动。
3. 切换只为新增证据或改变理解。露底从揭示点倒查；反应前保住触发。相邻两镜重复看同一个未变道具时优先合并。正片有意留悬念可切向环境，用真正看到的迹象代替反复说明；涉及关键可见交接时，不以声响冒充动作。
4. 给同镜留空间：只要能同框看明白过程，固定观察或一次移焦就够。必须让观众比较的双方关系不能被过窄的特写吃掉。短切只承担已经有人物、对象和空间基础的一个实在变化。

[换机位重建](references/view-reconstruction.md)从世界位置推回画幅方位，核对视线、遮挡、物件状态和动作相位；既适合追逐、近身对峙，也适用于静留观察。在不同媒介或画风中改变的是可用拍法，不是这条连续性。

**同一场的两个解。** 已知主角握着摇晃灯杆，听者看见底座在滑才伸手：斜侧双人镜若能同时看见底座和听者的伸手，保持固定；若灯罩挡了底座，只切那一下底座真的离开原刻线，再接同一只手的到达。只把灯罩拍得更近却还是看不见底座，不是有效切镜。声桥维持同一声源，不重播滑动。
