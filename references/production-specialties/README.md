# 创作专项｜本地接入总览

这些专项是 fengfeng-manju 的**专业资料**，不是独立 Skill。沿用现行剧本、专业交接与完整模板，在适用事件加载专项；不得切换成其他入口、提示词格式或平台默认值。

| 专项 | 主责 | 创作入口 | 典型触发 |
|---|---|---|---|
| 写实打斗 | action | [写实打斗怎么设计](realistic-fight/guide.md) | 接触、位移与受力必须可读，双方交互要留下下一拍的条件 |
| 特效打斗 | vfx | [特效打斗怎么设计](vfx-fight/guide.md) | 大招、复合特效、爆发范围、质感差异、参考形态与余波 |
| 冲击帧 | vfx → camera | [冲击帧怎么设计](impact-frame/guide.md) | 需要从动作链取出一个命中、对撞、贯穿、压伏或碎裂的画面重音；单张冲击图也按需读 |
| 导演衔接 | source → camera → compile → validate | [拆戏前置](director-handoff/prepare.md)、[镜头续接](director-handoff/guide.md)、[编译交接](director-handoff/compile-bridge.md)、[后台复查](director-handoff/review.md) | 复杂续段或多人换位，关键可见决定要从剧本一路保到直投稿 |
| 跨风格分镜 | camera | [分镜导法](scene-storyboard/guide.md) | 泄露线索、道具交接、连续位移、拍法选择和跨媒介取景 |
| 表情控制 | performance | [表情导法](emotion-expression/guide.md) | 情绪起落、嘴眼与手上任务不一致、近景线索如何被看见和承接 |

- 原有打斗编排库和招式特效库负责提供既定类别与候选，这三个专项负责补导演方法、物理呈现、视觉构造与故障诊断。没有新增剧情权限、没有必跑的外部模型或工具。
- 随包的是本 Skill 自有的方法、附页与示例。六项专项不要求安装其他 Skill，也不依赖第三方原包、样图、来源表或完整词库。
- 专项是创作方法，不接管项目的导演权限、完整模板、镜头数量或平台配置。平台能力以当次实际配置和已核实资料为准。
- 写实动作只用于影视调度和可视化反馈。测试可核对文档与工序连接，不能代替成片验收。
