# 导演前置｜剧本交过来，拍完要交出什么

适用：有分段续戏、多人换位或关键转折容易在出稿时丢失；简单单段仍用现行创作准备。按本工作区既有权限和底稿约定核对，不代替编剧改结局，不硬凑多段、反转或台词。

## 先从片尾倒推必须发生的事

1. 写一条可被观众确认的收束，不用“矛盾升级”“气势更强”替代结果。比如“甲兽的前爪退出铸钟台，钟楼守卫不再挡在钟柱前”；另记下一场还必须成立的状态，不能为了本段好看把它赶在上段拍掉。
2. 逆推到行动改变的地方：角色在做什么、哪条现场条件让旧动作不再成立、谁先感到这个变化、随后换了什么行动。如果缺的是源文决定而非取景，不在分镜偷加原因；说明影响这一拍的具体缺口，其他可执行部分照常推进。
3. 给必须按顺序成立的变化留观看时间，同时记录可以并行的持续任务。不在排好镜长之后才把发现、回应和收尾挤进中间。三次变化可以在一个连续镜头里发生，不预设三镜。
4. 跨段先指明按哪份材料接。接受稿上的预计尾态、用户说明、真正采用的静帧和已观看的成片分开；没有见到的脚步、速度、对白进度和画外动作不记为已发生。只要照片供站位，就把授权限制在站位。

## 给专业端的最短交接

本段后台短记：固定事实与可补细节、最关键的变化、必须让观众亲眼见到的过程、已经确证的起点和必须到达的终点。已有项目用现行事件、需求和专业设计记录，不新增硬性数据字段；直出不要求另交导演表。

**案例**：阿岚的扇风正压盾面。正面不破与盾转露缝是对手的应对；“她看见裂口才改向”是必须可读的决定。只写“见破绽”“随后破盾”不够。若上段电影实际只做到盾开始转，下一段应从转动中接，不把“裂口已经完全露出”冒充已发生。交给[分镜与续接](guide.md)决定怎样看清，再由[编译交接](compile-bridge.md)形成正文。
