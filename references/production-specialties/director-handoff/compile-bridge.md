# 导演设计如何进入直投稿

使用当前完整模板与当前交付档位。多段的集稿可共用稳定资产页；每个独立直投稿仍须在自身建立必要的人物、位置、持物、地标、声源和本段动作前提。规划卡、证据标记、拍法选项和旧平台栏目不进正文。不增加第二套音效、对白或时轴格式。

## 四处最容易丢的内容

1. **开场已成立的事实。** 若上段已选素材证实门已开、右手拿信，在本段写明可见状态；若只是草稿设想则不能写“承接实拍”。别把新设定放进全局又从未在当前机位兑现。
2. **触发实际发生的一下。** 不把“流光从缺口钻进”压成“缺口里已经亮了”。按上游镜头接触阶段写，面对成稿可指出先发生什么、谁看见或承受、之后凭什么改变动作。预算不足时合并自选重复，不从真正的转折中偷时间。
3. **同镜动作与真正换镜。** 移焦、演员走动和同一观察点下的另一节拍不会自动成为新镜。真正切换时保住取舍理由对应的新增证据和动作接点；不重复动作起头，不为格式整齐改排期。
4. **生效后的持续状态。** 剩余碎片、相对方向、未完对白和尾音写入正确镜头；打点结束不代表物件回原位、声音重播、配乐重起。完整稿每镜六项音效保留；无对应声源可以无新增，不硬编。

例：坏句“承接上段，动静之后两人离开”既不独立，又看不见是什么促成选择。现场可拍句须包含当前可见握持／落点及当次实际反应；若上一段没有交代，先区分是剧情缺口还是编译省略，再按职责处理。只允许经授权的补拍法，不自行新造决定。
