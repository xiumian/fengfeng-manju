# 冲击画面：一瞬的力，后一拍的结果

先明确一件事：本段哪一下令关系或道具状态真的改变？不规定每场有冲击帧。建议先让接触可读，再加重奏，不拿套色遮掉动作。

| 要突出什么 | 画面怎么组织 |
|---|---|
| 接触落点 | 留两种轮廓和中间最亮的一小块位置，先看来源与受者的接合，再根据作用露出反向形变 |
| 擦掠、贯穿 | 以一条移动线贯通画面，但不给目标提前破口；尾迹的长度说明掠得快，不再发一次光柱 |
| 面状爆发 | 先定爆心和范围，视角留一条近远参照；空气线向外过，实体碎片去不同距离后落下 |
| 近身压迫 | 不一定要撞或亮：环境雾、衣角先被推弯，主体的幅度、地标尺度和局部出框负责分量 |
| 结构碎裂 | 从原先相合的两面开始，挤压或错位后第一片脱离。利落碎块、细屑和冷光各去各的方向 |

**强度怎么加。** 普通接挡先靠接点与支撑；重一下可加强材质与方向、用更靠近的视点读反作用；确定高潮再加短暂色值或透视变化。接点最亮不等于全屏最亮，放大体量也不能同时把两个人、碎块和效果都拉成同样粗的光。先试一个画面证据充分的镜内重音；没有新观看信息不必为它切镜。

**考一道前后题。** 强调之前，观众能指出哪个部位正在相接吗？强调恢复后，同一片铜是否还在飞、缺口与落点还在吗？若只有光，没有受力，先改接触与观察角度。精确帧级格数需在实际剪辑核定，写稿不把毫秒参数当画面。
