# 资产工序
输出design：事件ID→已核对资产及实际选图职责；不把候选清单冒充已上传。
# 逐幕资产分析与实际参考图匹配

用于有现有资产库的任务：主稿阶段核对会限制调度的资产事实；生图阶段执行逐板选图、实际上传和记录。纯文字设计不要求不存在的资产库或上传步骤。

### 生图提示词前：逐幕资产分析与匹配

有现有资产库时，先完成以下流程，再编写对应生图提示词：**分析这一幕 → 列所需资产 → 对比现有图及适用状态 → 明确缺项 → 确定实际上传参考图 → 写生图提示词。** 资产目录清单或主稿中的REF不能代替这一步。

- 按场次和本轮每张板的时间范围，列出实际出场人物（含配角、群演与数量）、场景及观察方向、关键道具、伤势／破损／服装等状态；同一板跨场时分别匹配。对白提到的人物不自动加入画面。
- 对照库内候选，实际查看准备使用的图，核对角色身份、武器形制、场景结构与机位、完好／破损状态和剧情时点。优先使用已有专属资产；不能只反复上传主角图，让模型自行补画已有配角、场景和关键道具。标有“勿用／待确定”或已被用户排除的资产不作正式参考。
- 保存逐幕／逐板匹配表：`场次或板号｜所需人物/场景/道具及状态｜候选路径与REF｜适配结论｜选用图及职责｜实际上传/未上传｜缺项或冲突`。区分“库内不存在”“有资产但状态不适配”“有适配资产但本次未上传”；存在但漏用不能报为缺少资产。
- 人物图负责身份与服装，场景图负责结构和空间，道具图负责形制，状态参考负责伤位与破损连续性。先定本板参考组合，再据此写提示词；REF与上传清单逐项对应，不声称未上传的图片已经锁定外观。
- 上传数量受工具限制时，按本板看点和连续性需求分配参考名额，选择适配的组合或拆分制作；记录未覆盖项及影响。不得无说明地省掉关键资产，也不要求把资产库全部上传。工具调用后保存实际参考路径及职责，不能只保存候选清单。
- 缺少或冲突影响人物身份、关键道具或空间关系时，在对应生图前直接说明；按已有授权标TMP继续可行部分，关键未定项仅暂停依赖它的部分。用户已允许临时设计时不重复询问。

资产需求在主稿调度前核对，九宫取样确定后再核对本板实际可见内容与上传组合；剧情、板范围或状态改变时更新受影响的匹配记录。
