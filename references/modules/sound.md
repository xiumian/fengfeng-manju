# 声音工序
明确要求配乐时，按同context的[配乐主题线](../layered-sound-design.md#配乐主题线主题变奏高潮让位)设计动机、变奏、高潮画面触发、让位/恢复与尾音；现有design分开记录音乐与现场声，不用配器清单代替一条从起到落的音乐。
按同context的对白关系方法区分原句、公开表达与可听回应，落实人物语言差异与潜台词的声音意图，但不另写对白内容。需要更长停顿或起声空间时协调节奏，而非吞句。
按同context的[分层音效方法](../layered-sound-design.md)设计并交接动作层/特效层/环境层，以及同步节点、主次变化、跨镜承接。每层按实际材料/机制写起声、持续与退场，不交一串声音名；不存在的声层不硬填。具体规则和多镜对照统一见共用方法，下文视点原则仍有效。
按同context的[情绪方法](../emotion-performance-design.md)承接表演声音意图；对白以外的呼吸、脚步、任务声与余响也参与情绪。起声/气息/重音服从既定台词与行动，不默认配乐或无因静音，保留有依据的声画反差。
输入对白、OS、VO 原句、角色、动作与空间。只为分配的事件写声源、发生时机、可听角色、距离与承接。
## 听觉视点与主次设计

先明确观众当前跟谁听：场面整体、贴近一人，或已授权的主观听觉。声音不只是画面每个动作都配一个大响；用主次让重要事件被听见，弱化不等于删掉必须保留的声音。音色/音高不是人物身份的万能替代，优先沿用已登记稳定音色。

1. **列出本时段真实声源**：谁发声、什么接触或机制产生声音、在何处和何时发生。普通底噪用一条持续描述，不每切镜重播一次。
2. **选当前主听点**：是对白的新信息、未见威胁、一次接触，还是人离开后留下的空场？按该点安排前后层与强弱，背景不必完全静音；连续危险中必要的警报/追击声不能无说明消失。
3. **把距离和遮挡写成可听变化**：门内外、靠近/远离、墙后或空旷场景，用清晰/闷、近/远、反射/尾响变化表现。不要仅因画面切近，就把远处声源变成贴耳；若转入主观听觉，写清进入和退出事件。
4. **用声音连接动作与空间**：预先听到来处可形成期待，反应后再揭示声源；动作切镜后声音可继续，尾响连接结果。声桥跨地点时明确声音来自上一场、下一场或已授权回忆，不伪装成当前角色真的听见。
5. **处理接触与余波**：声响顺序服从事件：接触前的破风、真实接触、材料反馈与余响不能错置；不把衣料、粒子和重物都写成同一种爆炸。声音峰值按看点分配，不固定每击先全场静音再巨响。

### 条件与代价
|需求|可选方法|代价/限制|
|---|---|---|
|对白重要且环境繁忙|让必要现场声留在背景，声音表现集中说话人|不能借清楚对白删除剧情必需警报；必要时回编排留容量|
|威胁尚未入画|先给有方向的声源及听者察觉，再交摄影揭示|过早解释会失去悬念；不能无声源依据凭空加恐吓音|
|空间或关系转变|用遮挡、距离或声桥连接变化|必须区分谁可听见，声音跨镜不等于角色跨地点|
|强调一次结果|在已存在层次中拉开主次，留下相应衰减与余响|不自动加配乐、低频轰鸣或抽空所有现场声|

### 对照与纠错
原创例：已知人物在门内听见来者脚步。写“紧张音效、重脚步、心跳同时炸响”没有主次；可先让门外脚步透过木门显闷，人物停下手中动作，门缝开启后脚步和衣料变清晰，室内底噪始终延续。要做主观压迫时可让其他声音相对退后，但明确何事使正常听觉恢复。是否加心跳须有当前授权，不是紧张场景自动配置。

纠错：每层都最响→先确定主听点；声音与接触错位→回事件时间而非堆拟声词；切镜底噪重启→延续同场声源；画外人声错归OS→先看是否同场实时说话；为声桥新增人物听觉→区分观众与角色的信息；对白不足时→退回容量编排，不吞句。

声音透视、声桥和同步概念参照[来源F3](../method-evidence.md)；主听点选择与例子为本技能综合设计，未进行本项目音频试听。需要精确声像、响度或毫秒同步时另行后期，不把纯文本意图当参数精度。

- 同期对白注明说话人，区分说话人此刻在画内或画外。同场画外对白仍是同期对白，听者不对口型。OS 是内心独白，VO 是旁白或有意安排的声音轨。两者都不让无关画面角色开口。
- 声音触发剧情时按“声源发生 → 谁先听见 → 反应 → 镜头或动作承接”记录。普通底噪简写，切镜不自动重新播放。跨地点声桥说明在何处进入、何时接到下一段。
- 保留说话人的原句、实际发声次数和彼此是否重叠。明确可读的停顿，容量不足时返回编排，不加速吞句。无明确配乐需求默认为无配乐。
