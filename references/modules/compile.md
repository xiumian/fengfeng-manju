# 正文编译
按[关键因果逐环取证](../move-vfx-design.md#关键因果逐环取证)保留不同因果环的各自正文落点，不用同一条胜负引文覆盖全链。有配乐时，按[配乐主题线](../layered-sound-design.md#配乐主题线主题变奏高潮让位)在全局保留主题身份，在逐镜音效写相应触发、让位和恢复。
按[可见变化链](../move-vfx-design.md#主特效的可见变化链)保留时序和层间因果：壳裂才生薄片、余屑已灭但实体仍在，不合并成“炸开后消散”。对应引句跟着镜头发生处走，不能只引全局或只引用峰值。
按需保留模板末尾的段尾交接镜，启用时填实际时码并移除模板编写说明。交接镜是真要生成的画面，进入投喂正文和 timing_nodes，计入本次生成时长、不计成片时长；例如固定生成15秒且已留预算时，主戏到14.8秒、交接镜14.8—15秒。若正片时长也已锁定，不静默压缩主戏或擅自加长生成时长；先协调排期。未启用时连栏目一起删，不把抽帧工作写成剧情。
六项前置设计按同context方法逐项兑现：任务因果、对白关系、造型结构、空间路径、媒介材质、光源变化。稳定内容放全局/资产，事件改变放发生处，不另列六个分析栏目；保留具体动作和先后，不能压成“感人对话/华丽3D/电影光”。关键需求分别给正文引句；缺设计返负责工序，不由编译临场补剧情。
音效是前台交付内容，按同context的[分层音效方法](../layered-sound-design.md)与当前模板保留动作层、特效层、环境层及同步/主次/承接，不缩成一段摘要；画面继续融合表达，音效独立分层。不存在的声层删除；台词不在音效中重复，检查结论留后台。
关键视觉需求分别给coverage引句，连读确认引句含真实先后/联动关系，不能用一句“施展剑海”覆盖展开、折入和分波受阻三件不同事。沿[拒收与保真](../move-vfx-design.md)检查：全局终态描述不代替逐镜变化；只删同义句，保留形成过程；上游缺过程要返修而非临场补招。
按同context的[情绪保真方法](../emotion-performance-design.md)保留触发、局部变化、并行任务与跨镜残留，不缩成神色一变；掩饰与混合情绪不抹平为单一标签，台词与声音原样按实际发声组织。
按同context的[编译保真方法](../move-vfx-design.md#编译保真合并措辞不合并不同信息)对照上游具体看点和正文落点：主形结构、层间运动、展开与接触变化不是同义修饰，不缩为“华丽特效”。缺设计返动作/特效，丢设计修本工序，拍不到返摄影；映射留后台，不新增投喂栏目。
按[单镜节奏](../shot-rhythm-planning.md)保留摄影已定切点和小数时段，不把0.5秒镜头取整、吞并为长镜或以“连续描述”取消切镜；完整模板不变。单镜长度不当作生成入口的单次时长，后台分析不混入投喂正文。
按[整场节奏规划](../scene-rhythm-planning.md)保留上游局势/策略变化、关键触发、并行关系与既定时间；不为模板整齐重新均分、合并转折或移动所有反应到段尾。节奏分析留后台，主人模板的全局/资产/片段/逐镜结构不因此缩写。
保留已选[关键决定](../narrative-event-design.md#排镜前先查关键决定再查能否接场)的触发、可见或可听的判断、行动与跨场结果，也保留[切镜收益](../shot-rhythm-planning.md#切镜收益上一镜已交代什么下一镜多给什么)在正文中的具体观看对象、变化节点和必要机位。不要把“听完才改路”编译成边听边改路，也不要用景别代替关键固定/移动指令；只把可拍可听的设计写进前台。
coverage逐项指向最终正文；每句对白按完整发声单元给utterances字符位置，不能用短句子字符串计数。正文与引用不一致时先修证据或正文，禁止绕过检查。
输入完整事件、当前设计及用户格式。输出text、event_ids、dialogue_ids、coverage及有对白时的utterances；scope内事件和对白必须覆盖，正文位置及因果需人工核对。
遵循[专业职责](../design-boundaries.md)：摄影结果是已交接的镜头方案，上游动作/表演等是要兑现的内容；两者冲突先返修，不在成稿时自行换方案。创作准备记录和专项ID留在后台，正文保留其实际设计，不把记录字段或方法名当作完成证据。
当前用户明确格式优先；没有另行指定格式时，按主人提供的[提示词模板](../video-prompt-template.txt)组织完整中文正文，保留项目、全局、场景资产、片段和逐镜时间轴结构，按模板注明的条件处理不适用项，不擅自缩成旧版栏目。用户模板的投喂部分保存在该文件，动态元素复核与完成检查独立存为[后台复核](../prompt-backstage-checks.md)，不输出到text或video_master_prompt，不附检查表或检查结论。必要的人物、道具、特效、环境、镜头与声音变化按后台规则融入对应正文，已经明确的不重复列举。逐镜与台词时段按已完成设计和容量填写，不机械均分；连续长镜头用同镜内时间段承接，不将每个时间段强制变成切镜。主人要求无时码或其他格式时按当前要求执行。稳定设定集中一次，逐段呈现具体可见/可听变化，关键接触与受力不能仅列结果。机位衔接直接写切到何处，内部 SHOT ID 留在交接数据，正文可写“镜头 1”表达顺序。对白原句放在有明确说话者和声源的发声位置，全文保留实际应出现的次数。
## 时间段内连续表达
### 融合执行方法：不把检查项写成前台表格

1. **先分不可改与可组织**：原事实、原句、明确顺序、必要结果及已定专业方案是要兑现的内容；句段长短、信息放在哪个自然段由编译组织，不能借“精炼”改剧情或摄影方案。
2. **选当前事件的主干**：人物正在做什么，导致谁/什么发生变化，哪条既有状态必须承接。先写因果主干，再将摄影观察和表演/特效/声音绑定在真实触发处；不是先粘摄影段再粘动作段。
3. **按时间关系归并**：同一事件中同时发生的转身、衣摆滞后和镜头侧跟可自然相连；必须先接触后破裂就保留先后。两个地点的同时事件只有已选择相应剪辑方案时才交替表达，不用“与此同时”让同一人同时出现在两地。
4. **消除同义重复，不删不同信息**：动作与摄影都说“从左逼近”，可合成一句；但“目标被逼向门口”和“镜头退到门外”不是重复，不能只保留一个。全局稳定外观集中写，事件中改变的伤损、持物和光源作用仍要写。
5. **冲突不靠文笔掩盖**：动作要求接触可辨而摄影一直背对接点，或专业结果给了互斥终态，退责任工序修方案；不把两条冲突同时写上，也不擅自删较难执行的一条。新事实要回底稿，不借补调生成原文没有的能力。
6. **回查每条必需设计的落点**：对照完整来源、coverage与专业结果，确认不仅事件名存在，路径、主反应、接触/结果、必要机位和接口也真实落在正文。程序coverage未给专业细项独立ID时仍需语义自查，不以ID齐全代替落实。

### 并行关系对照与纠错
原始设计为“甲一边护送乙退向门口，一边挡住来袭；摄影沿西侧后退，乙持续移动”。清单拼接会变成“摄影后退。甲格挡。乙走到门口。”，容易读成三件依次等待的事。连续表达可写“镜头沿西侧退向门口，甲跟着乙的撤离步伐侧移，将来袭兵器带向通道外侧；乙借这一空当跨过门槛，甲仍用原手持剑掩住身后”。新增具体动作必须已在上游设计中成立；这里仅演示如何组织既有设计，不授权编译临场编招。

纠错：删标题后仍是模块串贴→以同一事件的触发/并行关系重组；语句顺滑却只剩结果→恢复必要过程与观察关系；对白在各段重复→仅保留真实发声位置和跨镜延续；过载→先压缩同义句和自选描述，关键容量冲突回编排；检查结论泄漏→移回后台并检查信息已在正文，不能只删标题。

模型可用的直接描述与素材职责边界见[依据F12/F13](../method-evidence.md)；该融合流程是本技能综合设计，不把平台的简洁建议当成删薄主人正文的许可。

不按专业模块逐栏拼接，也不把景别、机位、运镜、构图、成像、主体动作、特效与衔接各写成一份填写表。沿当前事件实际发生的先后与并行关系，将各专业已交接设计融合成连续画面：摄影如何跟住运动或揭示信息，人物如何行动与回应，特效/环境如何随触发发生变化，末态怎样被下一时段继承。让这些关系在具体句子中成立，不只是把几个专业段落删标题后串在一起。
时间段保留标题、完整画面及按需的台词/音效；不强制每段“准备—运动—接触—反馈—结束”的固定句式，不机械补蓄力、站稳或收势，不因去掉栏目而删去已设计的机位、表情、特效路径和中间过程。描述可按复杂度自然分段，连续不等于长句堆砌或强制一镜到底；各时间段也不自动等于切镜。模板中的准备、接触、反馈与消散按已设计事件适用，不为填栏新增剧情或让持续特效提前消失。
台词在实际发声节点出现，保留原句、角色、情绪与声音表现、必要口型和跨镜延续；“画外音”须注明同场画外对白还是VO旁白，内心独白标OS，沿用声音工序的归属。对白使事件中途发生反应时，可在该发声位置前后续写画面，不把台词全部挪到段末造成时序错位。音效按实际事件与声桥承接，不强迫填满所有声层。后台复核不重复抄写台词，不伪称图片、声音或成片已经验收。
保留摄影已设计的人物反应、道具细节及环境/静物留镜，不能在编译时统一扩成双人中景。特写或空镜中的声音按既定说话人和现场声承接，不增加原文没有的发声。
[对白景物插镜](camera.md#对白中的景物插镜与空镜)按摄影的**实际切点**写进画面：从何处切到哪一景物、看清什么，何时回人物或接下一场；同镜移焦不写成切镜。台词按现有模板只保留一次**完整发声单元**和连续字符位置；跨镜处在画面或声音承接处注明原说话人的声音继续、回切时恢复画内或自然收尾，不拆成两次台词、不另给空镜造对白。背景里的动作需要接续时写实际进度，不写“返回原动作”让它重来。

把新增设计的来源留在工序记录。默认采用上述连续表达；仅主人当次明确要求分栏时再按指定格式组织，不自行恢复旧表格。“新增摄影设计”等制作标签、设计理由、评分、REF制作标签与检查表留在交接记录。按实际生成容量保留重要过程。实际上传的图、音频和视频按职责登记。“文字提示词权重”表示职责和冲突处理，只有明确的平台参数才写数值。纯文生不虚构素材。未入格事件同样进入主稿。英文版逐项对应，资产名称保留中文。
精确排期在 timing_nodes 结构中单独交付，标题与正文逐字对应。落盘后重新读取正式文件；JSON、查看页、合订稿与包从同一最终稿派生。独立行undefined/null/NaN及模板变量不能交付。需要具体例子时才读examples/video-prompt-v7.13.txt，不继承其参数。
