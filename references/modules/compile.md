# 正文编译
输入完整事件、当前设计及用户格式。输出text、event_ids、dialogue_ids；scope内事件和对白必须覆盖，正文位置及因果需人工核对。
当前格式优先；默认读[空白模板](../video-prompt-template.txt)。稳定设定集中一次，逐段呈现具体可见/可听变化，关键接触与受力不能仅列结果。机位衔接直接写切到何处，不输出内部SHOT编号；对白原句保留一次。
不把设计理由、评分、REF制作标签或检查表写进正文。不设统一字数或招数上限，不因精炼删薄重要过程。实际上传图按职责登记；纯文生不虚构图。未入格事件同样进入主稿。英文版逐项对应，资产名称保留中文。
落盘后重新读取正式文件；JSON、查看页、合订稿与包从同一最终稿派生。独立行undefined/null/NaN及模板变量不能交付。需要具体例子时才读examples/video-prompt-v7.13.txt，不继承其参数。
