# 表演工序
按同context的对白关系方法承接已锁原句的目的/策略/听者选择；表演写可见反应与行动，不能靠音量替代关系设计，不为情绪临时新增台词或隐藏关系。
全域情绪按[情绪与表情设计](../emotion-performance-design.md)先建跨镜轨迹，再落实眉眼/口角/下颌、身体任务与控制，不局限对白。细微面部选择按需读表情专项，不套固定部位数或克制默认。
近景的表情起落、转折和掩饰可用[表情专项](../production-specialties/emotion-expression/guide.md)，区分持续状态与新变化，给出可读的线索及其承接。中景优先能辨认的身体或动作，不把原资料的肌肉命令和情绪配方当默认正文。
输出为design：事件ID→具体设计文字，仅写本模块领域；不可修改source/events或其他模块设计。必要问题带回调度，不用站稳、等待或删对白回避冲突。
输入台词、角色目标、当前动作和预算。
## 意图与策略：从人物要做什么到可见表演

先读人物此时知道的信息与想从谁那里得到的结果，再看其公开表达与真实意图是否一致。表演不是给情绪词随机配眉眼，也不从一个动作推断现实心理诊断。题材可自然、夸张、喜剧或仪式化，沿用主人指定风格，不把克制当作唯一高级表演。

1. **将目标写成相互作用**：想让对方留下、停止追问、相信自己或赶快离开，会产生不同的注意对象、距离、动作和发声。目标无依据时不补人物关系；只在已有创作权限内设计。
2. **给当前策略与变化**：请求、试探、回避、安抚等不是情绪标签；选符合人物和处境的实际行为。对方接受、拒绝、沉默或外部事件发生后，策略可以改变，不能预演尚未收到的信息。
3. **选择可读线索，不凑部位数量**：从目光、呼吸、手势、姿态、语速等挑能承载变化的线索，写它何时开始、受什么触发、怎样延续。需要掩饰时，公开动作和短暂泄露可以不同；不每次都眼红、握拳、吞咽再微笑。
4. **让听者参与事件**：知道什么、注意谁、是否在同时做别的事，决定其反应。沉默也可产生回应，但不把所有配角同步抬头/惊恐，或让听者替说话者对口型。
5. **交接表演的可见条件**：把必须辨出的变化及必要观看时间交摄影，把音量/停顿/气息意图交声音协调；不直接锁定特写、背景虚化或切镜。

### 条件与取舍
|当前处境|表演选择|需要避免|
|---|---|---|
|努力掩饰已知情绪|让任务动作保持表面正常，关键刺激引起一次偏差后被控制|把掩饰演成始终僵住或固定“先眼神后嘴角”流程|
|信息刚改变判断|先有注意/识别，再让动作或语气改变|人物在消息到来前先哭，或没有留接收信息的时间|
|持续危险中说话|言语与既有行动并行，反应受身体任务限制|为完整展示表情让敌我停战等一句话|
|喜剧或外放题材|把预期、时差、动作幅度与后果连起来|无依据新增误会；将所有大动作判为过度表演|

### 同一句话的对照与纠错
仅在剧本已有依据时，角色说“没事”：若目的是结束追问，可在对方伸手前把杯子端走，话短而快，注意仍落在对方动作上；若目的是安慰对方，可等对方抬眼才答，放松握杯并留回应时间。不能仅凭这句台词认定其说谎，也不改原句。具体动作只是本次可选设计，不成为所有“没事”的默认模板。

纠错：只有情绪词→补目标、触发和可见变化；堆满微动作→保留主线索及真实作用；听者冻结→按其信息/任务补适用反应；同段情绪无理由跳变→核对触发与策略；只能靠特写才能理解→把观看需求交摄影，不私自改机位；无法从现有事实判断→说明缺口而非臆造关系。

场景意图与多种表演风格的有限依据见[来源F4/F7/F8/F12](../method-evidence.md)；策略步骤与对照均为本技能综合设计，未验证演员级控制或模型微表情准确性。

## 使用时机与判断限度
场景需要爽感、关系变化、悬念、威胁、喜剧或奇观表达，或外部事件需要人物反应时读取。处理当前戏的作用，不先给整部作品贴标签；同一段可包含多种效果，只选择当前主导任务。模糊创意按可观察的行为、触发和结果给出可执行方案，用户要求比较时再给建议；已确认方向直接执行，不重复选择，不输出独立长篇分析。
先确定：事件改变了什么；人物知道什么、想做什么；观众此刻应看见或暂时不知道什么。原文充分时直接设计，未定信息影响剧情时标为待确认；不自行补身份、关系、能力或事件结果。

## 反应与行动
### Seedance情绪与对白表达

人物情绪不只标“悲痛、愤怒、崩溃”，在必要转折处写具体事件触发、可见反应和下一行动。表情优先用描述性语句，减少成语和抽象感受；选对当前变化最有效的目光、动作、呼吸或声音线索，不逐项堆满微表情，不把一段始终演成同一种强情绪。

内部先核对人物当前目标、期待和收到的信息；生成正文直接呈现变化。例如：“他抱起师父，低头等回应；发现胸口没有起伏，目光停住，急促呼吸顿住，随后抱紧师父，眼泪涌出，仰头哭吼。”这是有原文依据时的项目写法，不授权给所有悲痛场景新增动作或固定阶段。停顿和反应计入观看时长，不机械延长每次情绪变化。

对白原文保持不变，差异化情绪可写成“角色台词（情绪／声音表现）：‘内容’”，如“墨甲台词（急切，带着等待师父回应的期待）：‘师父，我杀了它！’”。同一句只出现一次，不在后文重复台词词语再附语气、表情解释；动作与听者反馈在相邻正文自然连接，避免诱发重复发声或字幕。口型、声音归属明确，静默人物有必要反应但不替说话者对口型。

表演给出可见变化及其触发、时序和后续动作；摄影模块据此决定是否靠近、插反应特写、留双人关系或用环境镜承接。不要把重要的微小反应只写在宽画面里，也不因开口就自动切脸。景别与空镜的选择统一按摄影模块处理。

交付前核对：关键反应是否有可感知触发；人物是否回应新信息而非预演结果；声音、动作与情绪是否一致；听者回应或无回应是否推动下一行动；是否把理论、重复情绪词或过量微动作塞进正文。只修缺失或冲突，不为增加情绪擅改对白、事实和结果。

描述性表情与素材/声音职责的模型表达依据见[Seedance 2.5官方提示指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)及本地来源登记F12，本轮已核对相关正文。原句按实际次数放在发声处是本技能的编写约定；事件—反应—行动也是综合方法，不冒称官方固定模板或本项目成片已验证。

从角色正在进行的动作开始：原状态 → 可感知触发（声、影、光、接触或他人反应） → 察觉/识别 → 身体反应或主动控制 → 采取行动 → 新终态与后续承接。只选对当前戏必要的阶段，不每次机械凑齐。
人物反应服从性格、经验、关系、目标、已知信息及触发强度：熟悉者可以短暂关注后继续做事；未知者先寻找声源；受威胁者判断方向、距离和应对路线；克制者也可能短暂泄漏。沉着不等于无反应，害怕不等于所有人同样后退。
多人按各自位置、感知时间和关注对象安排先后，避免全员同步抬头。保护、触碰、拔武器、跪拜、落泪等改变关系或行为意义的动作，须有原文/确认依据；不要把常见类型套路当作授权。

## 按戏剧作用提出观看需求
| 当前作用 | 本模块的表演设计与交接信息 |
|---|---|
| 爽感、逆转、实力证明 | 保留既有压制或阻碍，依据真实结果选择镇定、意外或得意等反应；交接反应触发时刻和局面变化，不让旁人反应替代主角行动 |
| 感情、亲近、疏离、压抑 | 设计关注时机、距离、接近/回避、话语与行动差异；标出必须读清的眼神/手部变化、关系依据与必要停顿 |
| 威胁、悬疑、恐惧 | 沿角色实际可获取线索安排识别与应对；交接感知先后、危险方向、逃避/保护目标和不能提前泄露的信息 |
| 喜剧、尴尬、误会 | 表现既有预期与结果的错位、反应时差或掩饰失败；交接观众需要读到的反差，不新增误会事实或默认夸张表情 |
| 奇观、敬畏、日常经过 | 依据熟悉程度、尺度和距离安排反应强弱，记录注意力沿何处移动及何时继续/改变原事，不为奇观冻结人物 |

对应的景别、揭示顺序、切镜和“凤凰掠过”完整拍法例移至[摄影方法](../performance-camera-methods.md)，由摄影工序读取与决定；表演不另定镜头。主稿中的关键剧情反应不能因九格没有选中而删除。

## 与现有流程的连接
人物变化先写入本模块design，交接触发、反应时序、起终态及必须读清的线索；摄影承接观看需求并安排切点/不切镜、观察方向，声音承接可听变化，编译统一进入主稿。九格只选关键反应、关系或结果状态，未入格过程仍在正文中。
遇到运镜、实体接触、特效或声画问题，按主路由提交本包对应工序需求。单独安装的技能需要执行者实际调用并记录，不作为本模块的隐式能力。
最后简查：反应有触发且符合人物吗？事件的作用看得出吗？空间、视线、动作和声音接得上吗？是否凭类型新增了原文没有的剧情？
