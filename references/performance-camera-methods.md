# 人物反应的摄影方法与条件案例

本文件从表演模块迁入，由摄影工序读取。表演交接触发、可见变化、时序与观看需求；摄影据此决定景别、视点、揭示和切镜。方法不是独立流程或固定模板，沿用[摄影工序](modules/camera.md)的观看任务原则。

## 同一情境的方案取舍

以下为原创条件对照，不是待复刻的固定镜头库。先确认事实，再依据本次观看目标选一套；未选方案不需要输出给视频模型。

|同一既定事件|可选拍法及作用|代价与承接|
|---|---|---|
|人物尚未发现来袭|先把来袭放进人物后方可读空间，让观众比人物早知道|产生预期但减少突发感；接到人物察觉时不要让攻击已无故停在空中|
|同上，但跟随人物感受|先保留人物当前动作和画外声，随其注意揭示来袭|惊觉更集中，但需及时交代来袭方向，不能只有瞳孔放大而无空间|
|同上，重点是如何挡住|斜侧关系景保住人物、来袭路线及接点，再按需要靠近反应|反应可能不够细；若必须读微表情，先完成接触可读再靠近，或交动作调整观看时间|
|甲把证据递给乙|保持双人/手与面部关系，观察乙是否接取|信息与关系并存，但证据文字未必可读；关键内容须另有观看安排|
|同上，重点是乙的隐瞒|把注意留给乙接收后的变化，甲可在画外继续原句|不能让甲声源变成OS，也不能遗漏证据是否已换手|
|人物离开后留下空房|在去向已清楚、关键反应已兑现后留环境与声音|能留余味，但不能用空镜跳掉本该发生的决定或接触|

不预设“先大全景再特写再远景”；如果角色目标、观众知情关系或场景尺度不同，同一事件也应改变方案。摄影只有观看权，没有新增攻击、认主、秘密或关系的权限。

### 纠错路径
突发事件只有甩镜→先补被发现对象和方向；对白全拍说话者→检查信息真正落在谁身上，再按需给听者；特写切走关键手部→先保证接取/接触过程可判断；每次都反应—奇观—反应→删无作用往返，保留必要变化；大景丢情绪→调整占比或观看时间，不通过给演员乱加哭喊补救。

本表的观看选择是本技能综合设计，景别/焦点与连续性概念参照[依据F1/F2/F4](method-evidence.md)。不是来源影片的逐镜复刻，未做不同拍法的视频对比。

## 戏剧作用速查
| 当前作用 | 镜头和节奏依据 |
|---|---|
| 爽感、逆转、实力证明 | 先让目标/难度可读，关键动作与命中结果清楚，兑现后适当停留；反应镜头确认局面改变，不替代主角行动；不默认仰拍、环绕或慢动作 |
| 感情、亲近、疏离、压抑 | 双人景别保留关系，细节承载变化才用近景/特写；保留必要停顿，不每句对白切正反打，不默认煽情音乐 |
| 威胁、悬疑、恐惧 | 控制声源与威胁揭示时机，交代路径和掩体；可先声后画，但跨场声桥须有时空依据，不用抖动或闪切掩盖空间 |
| 喜剧、尴尬、误会 | 留足观众识别关系的时间，再落结果和必要反应；固定镜头可能更有效，不默认夸张表情、音效或快切 |
| 奇观、敬畏、日常经过 | 人物与奇观同框建立尺度，按需要揭示整体或局部，再回到人物行动；不让风景展示吞掉剧情 |

景别、视角和移动按信息需要选择。一个镜头可以兼顾角色与事件，就无需固定“人物特写→奇观全景→人物特写”。没有必要的反应镜头可省略，但主稿中的关键剧情反应不能因九格没有选中而删除。

## 凤凰掠过的条件示例
仅演示观察和调度，凤凰认主、攻击、唤起共同记忆等均不能由“凤凰飞过”一句擅自推断。
假定凤凰从人物左后方掠向右前方：
- 起点：中全景交代人物正在做什么、相对位置及行进方向。左后方翼声先到时，谁听见谁先偏眼/转头；不要无触发同时仰头。
- 揭示：按观看目的保持同框、上摇或切向视线目标，交代凤凰方向与距离。视线沿轨迹移动，机位保持方向一致；影子、气流、衣发和扬尘只有尺度、光源、距离及设定支持时才出现。
- 回接：若切了凤凰，在其飞远、角色辨认或注意转移的具体时刻切回，承接原站位、视线、手部动作和声音距离变化；以角色继续/改变原动作结束，连接下一事件。
如原文已确认凤凰证明身份，重点是行动结果与众人的关系变化；如确认唤起共同记忆，重点是一人看天、一人看对方等关系反应；如是威胁，重点是空间判断和行动路径；只是路过，允许短暂追视后继续原事。每种分配具体时间，不能为示例新增事件或固定镜头数量。

情绪观看的细项见同context的[全域方法](emotion-performance-design.md)：全景身体关系与近处面部各有作用，不把复杂情绪统一拍成特写，不让微小线索留在不可见位置。
