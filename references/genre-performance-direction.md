# 剧情类型、人物反应与镜头调度

## 使用时机与判断限度
场景需要爽感、关系变化、悬念、威胁、喜剧或奇观表达，或外部事件需要人物反应时读取。处理当前戏的作用，不先给整部作品贴标签；同一段可包含多种效果，只选择当前主导任务。模糊创意按visual-impact-design.md自主给一个完整可执行方案，用户要求比较时再给建议；已确认方向直接执行，不重复选择，不输出独立长篇分析。
先确定：事件改变了什么；人物知道什么、想做什么；观众此刻应看见或暂时不知道什么。原文充分时直接设计，未定信息影响剧情时标为待确认；不自行补身份、关系、能力或事件结果。

## 反应与行动
### Seedance情绪与对白表达

人物情绪不只标“悲痛、愤怒、崩溃”，在必要转折处写具体事件触发、可见反应和下一行动。表情优先用描述性语句，减少成语和抽象感受；选对当前变化最有效的目光、动作、呼吸或声音线索，不逐项堆满微表情，不把一段始终演成同一种强情绪。

内部先核对人物当前目标、期待和收到的信息；生成正文直接呈现变化。例如：“他抱起师父，低头等回应；发现胸口没有起伏，目光停住，急促呼吸顿住，随后抱紧师父，眼泪涌出，仰头哭吼。”这是有原文依据时的项目写法，不授权给所有悲痛场景新增动作或固定阶段。停顿和反应计入观看时长，不机械延长每次情绪变化。

对白原文保持不变，差异化情绪可写成“角色台词（情绪／声音表现）：‘内容’”，如“墨甲台词（急切，带着等待师父回应的期待）：‘师父，我杀了它！’”。同一句只出现一次，不在后文重复台词词语再附语气、表情解释；动作与听者反馈在相邻正文自然连接，避免诱发重复发声或字幕。口型、声音归属明确，静默人物有必要反应但不替说话者对口型。

情绪递进可沿连续动作和运镜完成，不因开口或出现情绪词就切脸。打斗对白保留压力与空间关系；普通对话可双人近景容纳回应；重要情绪转折才靠近或切特写。景深按信息任务选择，不统一背景强虚化。

交付前核对：关键反应是否有可感知触发；人物是否回应新信息而非预演结果；声音、动作与情绪是否一致；听者回应或无回应是否推动下一行动；是否把理论、重复情绪词或过量微动作塞进正文。只修缺失或冲突，不为增加情绪擅改对白、事实和结果。

资料依据：[Seedance 2.5官方提示指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)的描述性表情、台词差异化情绪格式及避免台词后复述诱发字幕建议；[Seedance 2.0官方提示指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh&redirect=1)的连续长镜头用于文戏与情绪递进。事件—反应—行动是本技能结合这些建议的编写方式，不冒称官方固定模板。依据可检索官方内容，页面全文受加载限制；尚未用本项目视频验证，不承诺生成表演准确率。

从角色正在进行的动作开始：原状态 → 可感知触发（声、影、光、接触或他人反应） → 察觉/识别 → 身体反应或主动控制 → 采取行动 → 新终态与后续承接。只选对当前戏必要的阶段，不每次机械凑齐。
人物反应服从性格、经验、关系、目标、已知信息及触发强度：熟悉者可以短暂关注后继续做事；未知者先寻找声源；受威胁者判断方向、距离和应对路线；克制者也可能短暂泄漏。沉着不等于无反应，害怕不等于所有人同样后退。
多人按各自位置、感知时间和关注对象安排先后，避免全员同步抬头。保护、触碰、拔武器、跪拜、落泪等改变关系或行为意义的动作，须有原文/确认依据；不要把常见类型套路当作授权。

## 按戏剧作用选择拍法
| 当前作用 | 表演与调度重点 | 镜头和节奏依据 |
|---|---|---|
| 爽感、逆转、实力证明 | 保留既有压制或阻碍，展示人物行动及真实结果，再选择必要的他人反应；镇定、意外或得意按人物依据设计 | 先让目标/难度可读，关键动作与命中结果清楚，兑现后适当停留；反应镜头确认局面改变，不替代主角行动；不默认仰拍、环绕或慢动作 |
| 感情、亲近、疏离、压抑 | 关注对方时机、距离、接近/回避、话语与动作的差异；眼神和手部细节有关系依据 | 双人景别保留关系，细节承载变化才用近景/特写；保留必要停顿，不每句对白切正反打，不默认煽情音乐 |
| 威胁、悬疑、恐惧 | 角色依可获取线索逐步识别，行动服从危险距离和逃避/保护目标 | 控制声源与威胁揭示时机，交代路径和掩体；可先声后画，但跨场声桥须有时空依据，不用抖动或闪切掩盖空间 |
| 喜剧、尴尬、误会 | 表现预期与结果的错位、反应时差或掩饰失败，不新增误会事实 | 留足观众识别关系的时间，再落结果和必要反应；固定镜头可能更有效，不默认夸张表情、音效或快切 |
| 奇观、敬畏、日常经过 | 区分首次见到与习以为常；尺度、距离与事件关联决定反应强弱 | 人物与奇观同框建立尺度，按需要揭示整体或局部，再回到人物行动；不让风景展示吞掉剧情 |

景别、视角和移动按信息需要选择。一个镜头可以兼顾角色与事件，就无需固定“人物特写→奇观全景→人物特写”。没有必要的反应镜头可省略，但主稿中的关键剧情反应不能因九格没有选中而删除。

## 凤凰掠过的条件示例
仅演示观察和调度，凤凰认主、攻击、唤起共同记忆等均不能由“凤凰飞过”一句擅自推断。
假定凤凰从人物左后方掠向右前方：
- 起点：中全景交代人物正在做什么、相对位置及行进方向。左后方翼声先到时，谁听见谁先偏眼/转头；不要无触发同时仰头。
- 揭示：按观看目的保持同框、上摇或切向视线目标，交代凤凰方向与距离。视线沿轨迹移动，机位保持方向一致；影子、气流、衣发和扬尘只有尺度、光源、距离及设定支持时才出现。
- 回接：若切了凤凰，在其飞远、角色辨认或注意转移的具体时刻切回，承接原站位、视线、手部动作和声音距离变化；以角色继续/改变原动作结束，连接下一事件。
如原文已确认凤凰证明身份，重点是行动结果与众人的关系变化；如确认唤起共同记忆，重点是一人看天、一人看对方等关系反应；如是威胁，重点是空间判断和行动路径；只是路过，允许短暂追视后继续原事。每种分配具体时间，不能为示例新增事件或固定镜头数量。

## 与现有流程的连接
人物与镜头设计先进入完整时间轴和视频主稿；每段明确切点/不切镜、观察方向、动作起终态和声音承接。九格只选关键反应、关系或结果状态，未入格过程仍在正文中。
需要进一步处理表演、运镜、实体接触、法术或OS/VO时按主路由调用本机对应专项技能，不为普通反应强行加载全部模块。用户固定视频正文结构保持不变。
最后简查：反应有触发且符合人物吗？事件的作用看得出吗？空间、视线、动作和声音接得上吗？是否凭类型新增了原文没有的剧情？
