# Fixed Shot Splitting Rules（固定镜头超时拆分规则）

> storyboard-prompter v2.4 更新（原 v2.2 新增）
> 适用场景：短剧风格（竖屏 9:16），固定镜头最大时长约束

> **v2.9 覆盖说明**：本文件的“固定镜头 ≤3 秒”仅作为快节奏竖屏短剧配置，不是 Seedance 或其他模型的通用硬上限。微表情、长对话或情绪连续性需要时，可使用 3–5 秒固定/极缓推镜头，并记录不拆分原因。拆分应由语义、表演、视线或走位变化驱动，不按秒数机械切割。

---

## 一、短剧风格固定镜头约束

### 核心约束

| 约束项 | 规则 | 适用范围 |
|--------|------|---------|
| 固定镜头最大时长 | **≤ 3 秒** | 所有固定机位镜头（含人物说话、静态场景） |
| 运镜镜头最大时长 | ≤ 5 秒 | 推镜/拉镜/横移/跟拍等非固定机位 |
| 强制建立镜头 | ≤ 8 秒 | 仅场景建立全景（LS/FS），每场最多 1 镜 |

> **配置规则**：启用“快节奏竖屏短剧”配置时，固定镜头超过 3 秒默认拆分；若拆分会破坏微表情、台词或动作连续性，则保留 3–5 秒并说明原因。

### 不适用此约束的例外

| 例外类型 | 说明 | 上限 |
|---------|------|------|
| 场景建立镜头（LS/ELS） | 用于交代空间的全景/大远景 | ≤ 8 秒 |
| 运镜镜头 | 推/拉/摇/移/跟/升/降/环绕，运镜本身提供视觉动感 | ≤ 5 秒 |
| 空镜/环境镜头 | 无人物，纯场景氛围 | ≤ 6 秒 |
| 慢动作/升格镜头 | 故意放慢的戏剧性镜头 | ≤ 5 秒 |

## 二、台词时长计算标准

### 基准公式

```
台词时长（秒）= 台词字数 / 语速系数

语速系数（字/秒）— 基准5字/秒（v2.4升级）：
  默认（正常/日常型）.............. 5 字/秒  ← v2.4 基准升级
  慢语速（沉稳施压/威胁）......... 3～3.5 字/秒
  极慢（颓废/悲伤/哽咽）.......... 2.5～3 字/秒
  快语速（活泼/急躁日常）......... 6 字/秒
  极快（暴怒/兴奋爆发）........... 7～8 字/秒
```

### 人物性格 × 情绪状态 → 语速双维度映射（★v2.4 升级★）

| 性格类型 | 情绪状态 | 语速系数 | 使用判断要点 |
|---------|---------|---------|------------|
| **安静/内敛型** | 平静/日常 | 3.5 字/秒 | 沉默寡言，说话偏慢 |
| **安静/内敛型** | 颓废/悲伤/失落 | 2.5～3 字/秒 | 情绪低落，停顿多 |
| **安静/内敛型** | 生气（控制型） | 4 字/秒 | 压抑式愤怒，语速略快但仍克制 |
| **沉稳/深谋型** | 平静/日常 | 4 字/秒 | 城府深，语速不急不缓 |
| **沉稳/深谋型** | 威胁/施压 | 3～3.5 字/秒 | 越威胁越慢，字字如刀 |
| **沉稳/深谋型** | 颓废/动摇 | 3 字/秒 | 遭受打击时语速明显放慢 |
| **正常/日常型** | 日常/普通对话 | **5 字/秒（默认基准）** | 无特殊标签时的默认值 |
| **正常/日常型** | 轻松/愉快 | 5～6 字/秒 | 心情好，放松状态 |
| **正常/日常型** | 颓废/悲伤 | 3.5～4 字/秒 | 情绪低落，带停顿 |
| **活泼/外向型** | 平静/日常 | 6 字/秒 | 话痨、反应快 |
| **活泼/外向型** | 兴奋/开心 | 7 字/秒 | 情绪高涨，语速飞快 |
| **活泼/外向型** | 颓废/委屈/哭泣 | 3～4 字/秒 | 骤降，落差感强 |
| **急躁/冲动型** | 平静/日常 | 6 字/秒 | 性格急，静止时也快 |
| **急躁/冲动型** | 生气/愤怒（爆发型） | 7～8 字/秒 | 急性子爆发，停顿短暂 |
| **急躁/冲动型** | 委屈/绝望 | 4 字/秒 | 崩溃时语速反降，哽咽停顿明显 |
| **威胁/反派型** | 施压/嘲讽 | 3～4 字/秒 | 阴冷型慢语速制造压迫感 |
| **威胁/反派型** | 暴怒/失控 | 6～7 字/秒 | 失控爆发，与平时慢速反差强烈 |

### 情绪调整规则（★v2.4升级★）

同一人物在不同情绪状态下，语速系数可变：

```
正常状态  → 性格基础系数（默认5字/秒）
颓废/悲伤 → 下调1～2档（严重哽咽再加0.5～1秒停顿/处）
激动/愤怒 → 上调1档
暴怒/崩溃 → 上调2档
OS/VO/旁白 → 不受性格影响，依内容情绪选3～5字/秒
系统提示音 → 固定5字/秒
```

## 三、拆分方法论

### 3.1 拆分判定流程

```
STEP 1: 计算台词时长
  台词字数 / 人物语速系数 = 预估秒数
  （基准：5字/秒，按性格×情绪双维度调整，见上方语速映射表）

STEP 2: 判断是否需要拆分
  ┌─ 预估秒数 ≤ 3秒 → 不拆分，1个固定镜头
  └─ 预估秒数 > 3秒 → 进行 STEP 3

  ⚠️ 拆分阈值随语速系数变化：
     默认5字/秒 → 阈值 = 15字（3s×5）
     3字/秒     → 阈值 = 9字（3s×3）
     7字/秒     → 阈值 = 21字（3s×7）

STEP 3: 确定拆分方案
  ┌─ 3-5秒 → 拆为 2 镜
  ├─ 5-7秒 → 拆为 3 镜
  ├─ 7-9秒 → 拆为 4 镜
  └─ 9秒+  → 拆为 N 镜（每镜≤3秒）
```

### 3.2 拆分结构模板

**2 镜拆分**（A→B）：
```
镜A: 说话者固定镜头（台词前半段）→ 时长约1.5-2.5秒
镜B: 说话者固定镜头（台词后半段）→ 时长约1.5-2.5秒
     OR 听话者反应镜头（台词后半段作为 OS）→ 时长约1.5-2.5秒
```

**3 镜拆分**（A→B→A）：
```
镜A: 说话者固定镜头（台词开篇）→ 时长约1.5-2秒
镜B: 听话者反应镜头（台词中段作为 OS，听话者身体语言）→ 时长约1-2秒
镜C: 回到说话者（台词收尾+情绪定格）→ 时长约1.5-2秒
```

**4 镜拆分**（A→B→A→C）：
```
镜A: 说话者固定镜头（台词开篇）→ 时长约1.5-2秒
镜B: 听话者反应镜头 → 时长约1-2秒
镜C: 回到说话者（台词推进，微变景别如 MCU→CU）→ 时长约1.5-2秒
镜D: 局部特写/道具/环境插入（台词收尾）→ 时长约1-2秒
```

### 3.3 对话段落拆分（多人对话）

当为对话场景时，拆分优先使用正反打结构：

```
说话者 A（镜1, 1.5-2.5s）→ 听话者 B 反应（镜2, 1-2s）→ 
说话者 A 继续（镜3, 1.5-2s）→ 听话者 C 反应（镜4, 1-2s）→ 
回到 A 收尾（镜5, 1-2s）
```

## 四、拆分一致性规则（★核心★）

### 4.1 站位一致性（Position Consistency）

拆分后所有子镜头中，人物在场景中的位置和朝向必须完全不变。

| 检查项 | 规则 |
|--------|------|
| 人物坐标 | 所有子镜头中人物位于画面的同一相对位置（左/中/右） |
| 人物朝向 | 所有子镜头中人物面向同一方向（正对镜头/侧身/背对） |
| 人物-场景关系 | 人物与背景元素（门/窗/家具）的相对关系不变 |
| 人物-人物关系 | 多人在场时，人物之间的空间关系不变（谁左谁右、前后关系） |
| 镜头角度 | 拆分后的同类型子镜头（A类说话者镜头）使用相同角度 |

**禁止行为**：
- ❌ 镜A 人物在画面左侧 → 镜B 同人物跳到右侧
- ❌ 镜A 人物正对镜头 → 镜B 同人物变成侧身
- ❌ 镜A 人物身后有窗户 → 镜B 窗户消失

### 4.2 动作一致性（Movement Consistency）

拆分后所有子镜头中，人物的姿态和微动作必须连续。

| 检查项 | 规则 |
|--------|------|
| 基础姿态 | 核心姿态（站/坐/靠）在所有子镜头中保持一致 |
| 手势分配 | 将原始镜头中的手势合理分配到各子镜，避免所有手势压在单镜 |
| 动作衔接 | 子镜 A 结束时的姿态 = 子镜 A+1 开始时的姿态 |
| 微表情 | 同一组拆分镜头中，人物面部微动（嘴唇开合/眼神微变）需与台词内容同步 |

**手势分配策略**：
```
原始镜头：人物在6秒内说了20字 + 2个手势
  ↓ 拆为3镜
镜1 (2s, 7字): 无手势，仅嘴唇微动 + 平静眼神
镜2 (2s, 7字): 第1个手势（如抬手强调），配合台词重点词
镜3 (2s, 6字): 第2个手势（如握拳），配合台词情绪高潮
```

### 4.3 光影一致性（Lighting Consistency）

拆分后所有子镜头的光源参数完全锁定。

| 检查项 | 规则 |
|--------|------|
| 光源类型 | 所有子镜使用相同的光源类型（室内灯/阳光/混合光） |
| 光源方向 | 主光源方向一致（如"右侧45°高位"→所有子镜右侧45°高位） |
| 光质 | 所有子镜使用相同的光质（硬光/柔光/漫反射） |
| 色温 | 所有子镜使用相同的色温（暖/冷/中性） |
| 对比度 | 所有子镜使用相同的光比（高对比/中对比/低对比） |
| 特殊光照 | 如有窗影/树影/烛光效果，所有子镜保持一致 |

**禁止行为**：
- ❌ 镜A 暖色光 → 镜B 冷色光（除非叙事需要且标注了灯光变化）
- ❌ 镜A 右侧主光 → 镜B 左侧主光（180°跳轴）
- ❌ 镜A 柔光 → 镜B 硬光

### 4.4 拆分一致性锁定标签

拆分组内所有子镜头共用以下锁定标签：

```
【拆分组一致性锁定标签】
├─ 人物站位锁定：{人物名}位于{位置描述}，朝向{方向}
├─ 人物姿态锁定：{姿态描述}
├─ 光影锁定：{光源类型}_{光源方向}_{色温}_{光质}
├─ 背景锁定：{背景元素描述}
└─ 180°轴线锁定：{轴线方向描述}
```

## 六、特殊场景处理

### 6.1 情绪高潮不拆

| 场景 | 处理方式 |
|------|---------|
| 人物情感爆发（崩溃/大哭/大笑） | 不做机械拆分，可保留一个 4-5 秒的运镜镜头（慢推+手持微晃） |
| 关键台词的高光时刻 | 可用 CU+固定 3 秒收尾，前段拆分 |
| 反转揭示 | 不做拆分，保留紧张感的连续镜头 |

**判断标准**：如果拆分会破坏情绪连续性 → 不拆，改用运镜镜头（如慢推至 CU）将镜头控制在 5 秒以内。

### 6.2 多人对话拆分

当多人对话场景中单个固定镜头超过 3 秒：

| 场景 | 拆分策略 |
|------|---------|
| A 对 B 说（B 在场） | A→B反应→A 正反打，每镜≤2.5秒 |
| A 对群体说 | A→群体反应全景→A特写，每镜≤2.5秒 |
| AB 吵架/交替说话 | 快切：A→B→A→B，每镜≤1.5秒 |

### 6.3 旁白/OS 处理

旁白/内心独白的固定镜头拆分：

```
旁白时长 ≤ 3秒 → 不拆分，画面+旁白OS叠
旁白时长 3-5秒 → 拆为2镜，画面微变（如景别从MS→CU）
旁白时长 5秒+ → 拆为3镜+，交替使用不同构图角度
```

## 八、与 blocking-diagram 数据桥接的兼容性

### 8.1 数据桥接表更新

在「走位步骤 + 情绪基调 → 镜头节奏翻译表」中，固定镜头的时长列需要更新：

| 走位步骤类型 | 更新后镜头时长 | 说明 |
|-------------|--------------|------|
| 开场定格/初始站位 | 5-8s（建立镜头，例外） | 不受 3s 约束 |
| 对话推进/位置微调 | ≤ 3s/镜（拆分后） | 需按本节规则拆分 |
| 步步紧逼/主动进攻 | 2-4s（运镜，非固定） | 推镜/跟拍，≤5s 约束 |
| 后退/退缩/受迫 | 2-4s（运镜，非固定） | 手持微晃/慢拉，≤5s 约束 |
| 关键调度节点 | 1-3s（强制 CU+推镜） | 无变化 |
| 反转完成/余波 | 4-7s（FS/MS 拉远，运镜） | 不限 3s |

### 8.2 走位步骤→镜头映射表中的拆分扩展

当走位步骤为"双人对话/对峙"且台词超 3 秒时，展开镜头数增加：

```
原规则：双人对话/对峙 → 2-4镜（成对）
新规则：双人对话/对峙 → 台词超3秒时按拆分规则扩展（见本文第三节）
         → 如需拆分为 3镜：A→B→A，每镜≤2.5s
         → 如需拆分为 4镜：A→B→A→C，每镜≤2s
```
