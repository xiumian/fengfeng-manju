# 文戏镜头切换规划参考

> storyboard-prompter v2.1 参考文档 — 文戏场景的镜头拆分方案与节奏控制。

---

## 1. 核心原则

文戏（对话驱动场景）的核心挑战是**在保持对话逻辑完整的前提下，打破视觉单调**。AI 视频生成尤其容易出现"两个人来回说话→画面僵化"的问题。

**三大拆解原则**：
1. **以台词时长驱动镜头数**：长对白必须拆分
2. **以听话者反应打破正反打死循环**：在关键词、情绪变化、权力变化或重要信息揭露后安排反应镜头，不机械要求每段台词都插入
3. **以运镜微调替代完全切换**：推镜/微摇可替代硬切

---

## 2. 台词时长 → 镜头数映射表

| 台词时长 | 镜头数 | 拆分方案 | 节奏效果 |
|---------|--------|---------|---------|
| 0-2秒 | 1镜 | 说话者全景/中景（固定） | 快节奏，信息型台词 |
| 2-4秒 | 1镜 | 说话者近景（微推） | 建立情绪基础 |
| 4-6秒 | 2镜 | 镜A：说话者近景 → 镜B：听话者反应 | 中等节奏，双向交流感 |
| 6-8秒 | 3镜 | 镜A：说话者近景 → 镜B：听话者反应 → 镜C：回说话者特写 | 情绪递进，揭示角色心理 |
| 8-12秒 | 4镜 | 镜A：说话者中景 → 镜B：听话者反应 → 镜C：说话者特写 → 镜D：双人关系镜 | 重要独白/告白类，节奏如音乐乐章 |
| 12秒+ | 5镜+ | 按情感节拍拆分，每3-4秒一组 | 史诗级独白，需标注情感节奏节点 |

## 3. 听话者反应类型指南

引用 `film-asset-prompter` 的「人物反应库」，按对话性质选择反应类型：

| 对话性质 | 推荐反应类型 | 身体语言示例 |
|---------|------------|------------|
| 日常交谈 | 倾听 | 微微点头、单手托腮、手中茶杯停顿 |
| 指责/控诉 | 激怒 | 肩膀收紧、手指攥拳、呼吸变快导致胸口起伏 |
| 秘密/真相揭示 | 思考 | 眼神移开、指关节敲击桌面、身体后退半步 |
| 告白/示爱 | 互动 | 靠近半步、手指触碰、眼眶微红（不描述表情） |
| 商谈/说服 | 倾听+思考交替 | 先点头后停顿、从靠背转为前倾 |

**统一规范（v2.9）**：
- 反应镜头优先使用身体语言；在 MCU/CU 且情绪可读性重要时，可加入 2–4 个克制的视线、眼睑、嘴角、下颌或呼吸信号。
- 原文明写的动作标记为 `剧本确认`；从上下文转化出的可见反应标记为 `表演转译`。
- 表演转译必须有具体触发，只能使既有情绪可见，不得新增剧情或心理结论。
- 同一角色的反应方式应随当前触发和情绪弧线变化，不能把单一“默认反应类型”机械套用全剧。
- 反应镜头通常 1.5–3 秒；需要完整读取克制变化时可延长到 3–5 秒。

## 4. 文戏镜头切换规划表模板

输出到 storyboard-prompter 的分镜文档中时，使用以下格式：

```
## 文戏镜头切换规划表

| 对话段 | 台词内容（摘要） | 总时长 | 说话者 | 听话者 | 镜头拆分 | 反应类型 |
|-------|---------------|--------|--------|--------|---------|---------|
| D1 | "你为什么要这么做？" | 3秒 | 林知 | 沈宴 | 1镜（林知MS微推） | — |
| D2 | "我别无选择..." | 7秒 | 沈宴 | 林知 | 3镜（沈宴CU→林知反应→沈宴ECU） | 倾听→思考 |
| D3 | "你说过永远不会骗我" | 5秒 | 林知 | 沈宴 | 2镜（林知MS→沈宴反应） | 激怒 |
```

## 5. 文戏运镜微调策略

当不希望硬切破坏情绪连续性时，使用以下 **微调替代方案**：

| 台词情绪变化 | 运镜微调 | 效果 |
|------------|---------|------|
| 平静→激动 | 固定→极缓推镜（0.5x速度） | 观众不自觉被吸入情绪 |
| 自信→动摇 | 固定→极缓拉镜 | 距离感拉开，暗示心理退缩 |
| 对峙僵持 | 固定→极缓横移（2-3cm/s） | 制造不安感 |
| 秘密揭示 | 缓推至面部特写（无明显加速） | 聚焦真相揭露瞬间 |

> **注意**：微调运镜仅适用于专业级 AI 视频平台（Runway Gen-4、Sora）。即梦/Seedance 平台建议使用固定机位+反应镜头硬切方案。

## 6. 长独白拆分范式

当角色有超过 12 秒的独白时，按以下结构拆分：

```
【独白开头】（建立情境）
  镜1: 说话者FS中景，环境交代 + 人物状态
  镜2: 听话者反应（倾听状态）

【独白核心】（情绪递进）
  镜3: 说话者CU近景，缓推至MCU
  镜4: 听话者反应（随情绪变化切换反应类型）
  镜5: 说话者ECU大特写，情绪最高点

【独白收尾】（释放/沉静）
  镜6: 双人镜头MS，景别拉回
  镜7: 空镜/环境，留白呼吸
```

## 7. 常见失败模式

| 失败模式 | 原因 | 解决方案 |
|---------|------|---------|
| 正反打死循环 | 没有插入反应镜头 | 每段台词强制配一个反应镜头 |
| 对话节奏扁平 | 所有镜头景别/运镜相同 | 按独白结构逐步推镜，变化景别 |
| 多人对话混淆 | 没明确每镜的说话者和听话者 | 每个镜头必须标注【在场人物】【配角反应】 |
| 情绪断裂 | 微调运镜速度与台词情绪不同步 | 运镜速度严格匹配台词情绪变化节点 |
