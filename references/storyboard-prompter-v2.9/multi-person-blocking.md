# 多人场景镜头分组调度参考

> storyboard-prompter v2.1 参考文档 — 3人以上场景的镜头分组与纵深构图方案。

---

## 1. AI 视频模型人数风险启发式

下表用于分镜风险控制，不是所有平台或版本的官方硬上限；如当前模型和参考素材能稳定支持更多人物，可在保持身份与肢体可辨识的前提下调整。

| 画面清晰人数 | 风险等级 | AI 生成可靠性 | 处理方式 |
|------------|---------|------------|---------|
| 1-2人 | ✅ 安全 | 高（面部稳定、肢体正常） | 正常流程 |
| 3人 | ⚠️ 注意 | 中（偶有面部混淆） | 轻量分组 |
| 4-5人 | 🔴 危险 | 低（面部克隆、肢体融合常见） | 标准分组：每镜头组≤3个清晰人物 |
| 6人+ | ❌ 禁止直接生成 | 极低（大概率生成失败） | 强制分组 + 纵深分层 + 群众虚化 |

> **核心原则**：清晰人物越多，身份混淆和肢体融合风险越高。优先分组呈现，不把所有角色挤在同一清晰平面。

## 2. 事件锚定法

**分组逻辑**：不是按"物理位置"分，而是按"剧情事件"分。

```
剧本结构：场景 → 剧情节点（事件）→ 核心冲突方
分组方法：每个剧情节点 → 一个镜头组 → 焦点人物 ≤ 3
```

### 示例：订婚典礼对峙场景

| 剧情节点 | 事件焦点 | 镜头组 | 焦点人物（≤3） | 其余人物处理 |
|---------|---------|--------|-------------|------------|
| 宾客到场 | 氛围建立 | 组A | 无（全景） | — |
| 家族寒暄 | Blackwell家族内关系 | 组B | Elena + Victor + Guest1 | Williams家族→后景虚化 |
| 秘密对话 | 两位家族代表私聊 | 组C | Elena + Marcus | 其余→后景 |
| 冲突爆发 | 全体卷入 | 组D | Elena + Marcus + Victor | 其余→围观群众 |
| 收场撤离 | 各方反应 | 组E | Victor + Williams长辈 | Elena→中景远离 |

**镜头组之间用全景/过渡镜头串联**，确保观众不丢失空间感。

## 3. 竖屏 9:16 纵深三层构图

**这是竖屏短剧多人场景的黄金法则。**

```
┌──────────────────────┐
│                      │
│  后景：围观群众      │  ← 大幅虚化，无面部细节
│  （虚化人影，色块）  │
│                      │
│  ┌──────────────┐    │
│  │ 中景：次要参与者│  │  ← 清晰但非焦点
│  │ （身体语言可见）│  │
│  └──────────────┘    │
│                      │
│  ┌──────────────────┐│
│  │前景：核心焦点人物 ││  ← 锐利清晰，主角
│  │（面部锐利）      ││      占画面 40-60%
│  └──────────────────┘│
│                      │
└──────────────────────┘
    9:16 竖屏比例
```

**各层规则**：

| 层级 | 画面占比 | 清晰度 | 人物处理 | 包含信息 |
|------|---------|--------|---------|---------|
| 前景 | 40-60% | 锐利 | 焦点人物(≤2)，完整连续性锁定 | 可写与剧情触发对应的克制微表情，不重复外观细节 |
| 中景 | 20-35% | 清晰但柔 | 次要角色(≤3)，简化锁定标签 | 身体轮廓、整体姿态、服装色调 |
| 后景 | 10-20% | 大幅虚化 | 围观群众，禁止锁定标签 | 仅模糊人影和色块 |

## 4. 围观群众处理规则

围观群众是 AI 视频生成中**最容易引发穿帮**的元素，必须严格管控：

```
## 围观群众三禁三准

### 禁止（❌）
1. 禁止使用人物锁定标签（旁观者也用标签会导致 AI 克隆主角面孔）
2. 禁止描述面部特征（"微笑""皱眉""注视"等均不可）
3. 禁止穿与核心角色相同色调的服装（防止 AI 混淆主角）

### 准许（✅）
1. 只描述为"模糊人影""虚化轮廓""背景人群"
2. 衣着只描述为色块，如"后景深蓝/灰色调的模糊人群"
3. 可描述整体身体姿态方向，如"人群朝入场方向看去"
```

## 5. 运镜多样性规则

避免多人场景的视觉僵化：

| 规则 | 说明 |
|------|------|
| **禁止连续重复** | 同一景别+运镜组合连续使用不超过2次 |
| **4-5镜插入非正面** | 每 4-5 个镜头插入一个侧拍/低角度/俯拍镜头 |
| **八种镜头类型轮换** | 见下方清单 |

### 八种镜头类型

| # | 类型 | 描述 | 适用场景 |
|---|------|------|---------|
| 1 | 纵深建立镜 | 正面超广角，纵深三层清晰 | 开场、新场景引入 |
| 2 | 双人中景 | 两人并列，紧凑构图 | 对话推进 |
| 3 | OTS过肩镜 | 从A肩后拍B | 对峙/谈判 |
| 4 | 单人特写 | CU/ECU，单人焦点 | 情绪高点 |
| 5 | 反应插入镜 | 1.5-3秒，配角反应 | 打破正反打 |
| 6 | 细节特写 | 手/物件/道具 | 暗示/伏笔 |
| 7 | 运动跟拍 | 人物走位跟拍 | 场景过渡 |
| 8 | 低/高角度 | 仰拍/俯拍权力关系 | 权力逆转 |

## 7. 常见失败模式

| 失败模式 | 原因 | 解决方案 |
|---------|------|---------|
| 主角面孔被克隆到配角 | 围观群众也用了锁定标签 | 围观者禁止任何锁定标签 |
| 多人画面混乱 | 单镜超过4个清晰人物 | 强制分组，每组≤3人 |
| 配角木偶化 | 只描述动作没描述反应 | 仅为剧情相关配角增加一个有限反应，不让所有人同时表演 |
| 服装混淆 | 核心角色和配角撞色 | 在分组表中标注每个角色的服装色调 |
| 正反打死循环 | 多人场景只拍两人对话 | 按8种镜头类型轮换穿插 |
| 空间感丢失 | 没有全景过渡镜头 | 每组之间插入1个广角建立镜头 |
