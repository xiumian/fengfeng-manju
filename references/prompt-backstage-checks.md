# 提示词后台复核：不进入投喂正文
六项前置设计的后台复核对照来源与需求：剧情因果/对白目的与听者回应/造型结构与状态/空间路径/媒介材质/光源变化是否真正进入正文。具体方法随compile/validate上下文提供，不新增前台六项检查栏目；“有写3D/暖光”不是充分证据。
音效按[分层音效方法](layered-sound-design.md)核对六项实际关系，层次和时序进入前台【音效】，本页判定与检查结论不进入前台；无关声层不填、同声源不重复。
招式表现力与编译保真按[联合设计方法](move-vfx-design.md)对照专业看点和最终引句，检查缺设计/丢设计/拍不到/容量冲突，记录责任工序。只在后台复核，不把六种设计关系或表现力结论塞进提示词模板。

以下两部分从主人提供的模板迁出，由编译与验证工序在后台执行；不进入投喂正文，也不在成稿末尾附“检查通过”等结论。投喂模板只保留场景、人物、动作、摄影、台词、音效及衔接等实际生成内容。需要交付检查报告时另存，不能拼进video_master_prompt或compile.text。

## 动态元素逐镜核对

保留原检查项：

【动态元素复核】
主体：[核心动作与表情变化]。
其他角色：[动作、反应与位置变化]。
道具：[运动、归属与状态变化]。
特效：[生成、传播、命中与消散]。
环境：[接触、扰动与破坏反馈]。
镜头：[运动、焦点与节奏变化]。

对照完整事件及已交接设计，逐镜找出必要而未写清的变化，将其融入对应时段的连续画面描述：人物/其他角色、道具、特效与环境变化围绕同一事件展开，机位/焦点/运镜与动作或信息变化绑定，末态自然承接下一时段；声源、时机与延续在相应发声节点的台词/音效中写清。这些是后台职责，不要求正文另设“摄影”“画面与动作”或“镜间衔接”栏目。已经写清的不重复抄一遍，不为填满检查项新增角色、动作、特效或每镜完整生命周期。跨镜对白保留真实发声次数，不在核对内容中再抄台词。

例如已有设计包含“落脚扰动浅水，水纹延续到下一镜”，应在连续正文写清落脚扰动，并在下一时段承接仍在扩散的水纹，而不是另列“环境复核：水纹连续”。检查发现专业设计本身缺失或冲突，按责任工序补调/返修，不由编译擅造设计。

## 连续表达的细项与反查

原逐镜表中的设计维度保留在后台，不作为每段必须输出的字段：
- 摄影：景别；机位高度、角度和相对主体位置；运镜方向、路径、速度与变化节点；构图的主体占比和前后景；景深、焦点、运动模糊，以及已由动作确定的慢放及恢复。
- 动作与表演：当前空间、目标、位移路径、真实支撑/接触、受力反应、表情变化、道具状态与环境反馈；仅核对本场实际需要项，不强制每段有准备、碰撞或消散。
- 台词与声音：说话人、画内/同场画外/OS/VO、情绪与意图、必要音量/语速/停顿/尾音、口型、跨镜时段与实际发声次数；动作/特效/环境声的声源、同步节点、强弱、收声和延续。
- 衔接：本时段结束的位置、姿态、方向、道具/环境及声音状态，下一时段怎样继承；选择同镜连续、动作/视线匹配、遮挡或声桥要有实际依据，不因时间段标题默认切镜。

融合后逐项对照原文与各专业已交接设计，给必需内容定位最终正文证据：检查是否只剩动作结果而丢掉中间关系，是否保留具体摄影与可读反应，是否把本来并行的动作写成依次等待，或为了短而删掉敌方压力、特效路径和后续状态。发现损失修对应句段；不通过重贴整份专业清单、删证据或重复台词补救。不要求每个空镜都有动作/特效，也不把此检查压成固定句式。后台字段齐全、规则装入或文字连贯都不能证明语义已完整落实。

## 完成检查

保留原检查项：

时间：各镜覆盖总时长；对白、慢动作与动作所需时间相容。
空间：人物位置、朝向、运动轨迹及镜头方位连续。
动作：发动、运动、接触、反馈和结束状态完整。
资产：人物外形、服装、道具归属及状态保持一致。
视听：台词与音效对齐画面事件，关键动作与表情可辨。
规则：全局与局部要求一致，删除互相冲突及不适用的指令。

编译在后台逐项核对，发现缺口就修对应正文或返回责任模块；验证在现有evidence、coverage、requirement_reviews及limitations中记录具体证据、问题和局限，不新增投喂栏目，也不把“时间已检查、空间一致”等验收语言当作生成指令。模板占位符只用于填写，正式稿不得留空占位。

最后连读投喂稿，确认必要变化已融入且没有复核栏目、清单或检查结论泄漏。规则加载和结构测试只能证明文件交接，不能证明模型语义落实、图像接受或成片效果。

后台按[情绪复核](emotion-performance-design.md)给具体正文引句：感知触发、局部变化、身体/声音关系、取景可读及跨镜残留；不新增投喂情绪表或检查结论。
