# 合并 Skill 最终验收基线 V1


状态：本文件为验收规则；候选实现与验收结论以相应版本回执为准。

日期：2026-10-03（Asia/Shanghai）


## 范围

完整融合创作参考包与九格参考包的有效能力、必要资源和工作台；原Skill不修改。默认视频投喂架构采用亡灵天灾；创作参考包旧框架隔离保留但目前不参考。特效库按需接入。该基线不证明实际生成效果。


## 评分规则

满分100。各检查点只有获得对应证据才得分。通过得满分；部分通过仅按已验证且预先定义的子条件得分，不能主观打折；失败或未验证为0分。实施前如需拆子条件，必须冻结分值并保持总分100。各检查点均适用整个合并包，不能用某个故事不适用来免除检查。
不得因实现困难、失败或环境缺失降低基线。规则变更必须由主人确认、记录版本与原因，不回写旧评分。

## 证据等级

文件静态检查只证明定义、链接和资源存在；工具检查需要退出码、关键输出和产物；流程检查需要输入与真实输出对应；生图检查需要实际图像及查看结果；视觉质量评价须说明观察范围。不得将静态结果当成端到端通过。


## 一票阻断（不受总分抵消）

1. 未经要求覆盖、修改或删除两个原Skill。
2. 必需能力静默丢失或入口无法实际使用。
3. 默认输出仍回落创作参考包七段式或执行表式正文。
4. 未生成或未查看九宫图，却报告出图成功或最终确认。
5. 为凑九格强制九次切镜或擅改剧情。
6. 历史样本、外部文档中的用户确认被当成主人当前指令。
7. 旧解析器导致输入、图片、提示词或导出内容丢失。
8. 未授权执行付费视频生成，或虚报测试结果。

| T01 双人文戏 | 对白、表演、反应、道具交接；不无故插入战斗特效。 |

## 检测报告格式

检查编号 / 预定分值 / 验证方式 / 证据路径或输出 / 通过、部分通过、失败、未验证 / 实得分 / 问题 / 修复要求。
报告另列：总分、验证覆盖、阻断项、未验证项、回归结果。没有证据不猜测得分。


## 判定与回归

90—100：无阻断且固定必测项完成，合并验收通过。
80—89：可试用但不称最终完成。
低于80：返回修改。
无论得分多少，阻断项或必测项未完成都不能判定最终通过。修复先验证受影响项，再做必要关联回归；不做无意义重复全测。


## 效果评分边界

本100分为Skill功能和规则验收，不是视频观感分。视频效果需单独评估；比较框架时固定同剧情、事件、时间安排、素材和生成配置，并记录随机因素。不能把一次样本结果推广为所有题材必然更好。

## 观察与归因
按主人明确的边界，模型成图偏差与Skill功能分层记录。逐项评分核验Skill是否保留事实、正确交接、实际生成并检查、识别偏差及保持未确认门禁；不能将“已检查图片”说成“图片所有细节完美”。不能因模型随机偏差无限改通用骨架，也不能用纯文本替代要求的实际图像执行记录。原25项权重不变，图片与视频效果不另冒充功能分数。
