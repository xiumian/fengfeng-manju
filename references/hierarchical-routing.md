# 当前任务调用
以SKILL.md的任务选择为准，不建立第二套设计顺序。

1. 小说/剧本：完整来源与覆盖→按需动作/表演/摄影设计→用户格式主稿。创意/资产：已有要求和资产事实→授权设计→用户格式主稿。已有提示词：版本与保留项→局部修改及接口复核。
2. 打斗主方法仅generation-action-visual-control.md；它统一看点、时间、速度、特效和编译。combat-choice-and-speed.md只用于方案比较；visual-impact-design.md只补专项材质/尺度。镜头接口、类型反应、特定招式按需读取对应资料。
3. 有现有资产库读asset-matching.md；主稿阶段核对约束调度的事实，生图阶段核对逐板实际参考图。纯文生不要求补齐图。
4. 用户要求九宫时，从完整主稿取样并按nine-grid-workflow.md验证；局部修图按原坐标单格回填。不要求每项任务走九宫，不由九格反推主稿。
5. 只在需要专项方法且本机技能可用时调用表演、运镜、实体战斗、法术或OS/VO技能，不把其格式和固定参数替换用户模板。连续性疑难按production-modules.md内部检查，不整套字段输出到正文。
6. 静态和文本检查与成片效果分别记录；缺少连续视频/音频就明确动态/声音待验。历史工作台数据迁移与代码修复不由此路由自动完成。
