# 战斗特效选择库 — fengfeng

使用前读 contracts.md 的特效边界：不是整段复制库，不要求每个技能写全链；持续特效不强制本段消散，小技能不强制地裂，雾和护盾不必高速翻涌。其固定分项骨架仅用于后台构思，转成连续画面正文。不把写作模板当官方模型语法。

## 本轮试用：视觉展开规则（v0.3.15）
从主人提供的《万相焚墟-30s》学习描写方法；未吸收独立xuanhuan-combat-director。不是新输出模板，不固定节点数、变身、清场、满屏爆炸或真人风格。只在要求高燃/突出粒子的大招及相关角色启用；文戏和小技能仍按需精简。

### 稳定定义进入全局
为实际需要的主体或武器定义常驻特效：从何处产生（纹样/刃口/法器）→附着范围→材质及主色→如何流动。与节点动作区别：常驻纹路可以持续，而释放、命中和破坏只在事件发生时出现。形态变化属于剧情选择，不自动给角色变身或新增身份。

### 当前变化进入节点
用连续画面句展开有用环节，不把下列字段名作为新的分项表送模型：
1. 触发与源头：由谁、哪只手或法器、哪个动作触发，从哪个具体位置产生。
2. 构造与成形：需要时写核心/中层/边缘，材质、轮廓、先后生长关系；不强制每次三层、旋转或蓄力。
3. 运动：路径、方向、层次和速度变化；拖尾随主体或攻击运动，不到处均匀飘散。
4. 规模：用画框区域、人物位置及既有环境参照证明大小；不为炫技改设定数值或强制越框。
5. 接触与反馈：写清哪个边缘/部位先接触，接触后目标怎样形变或位移，环境哪里发生变化。
6. 末态：攻击留下什么，特效如何回落或继续，人物和道具在哪里；下一节点继承。
按事件容量分配篇幅，复杂变化可分相邻节点，不能给两秒塞完整多招；删重复形容词，不删决定画面的因果。持续技能不强制本段消散。

### 粒子分工和视觉层次
附着粒子表达属性；轨迹粒子表达速度/方向；聚合粒子构成技能；接触爆散表达命中；余波表达结果。只选当前需要的职责。可写近景碎片掠过、中景主体成形、远景尾流稀疏，但不强制所有镜头都有三层。
短暂满屏冲击可用于明确的高潮或遮罩衔接，爆发后及时显出主体、命中结果与必要地标；不能把每一击都写成铺屏爆炸，也不能把画面清晰误写成禁止任何大范围特效。特效展开展示尽可能随追击、位移或变招发生；剧情确需悬停/蓄力时交代可见变化，不机械禁止停顿。

### 正文、摘要与声音一致
正文展开过程；动态元素只重申已写出的关键变化；音效对应实际动作、特效和环境，不新增事件。优先用可见构造替代“高级、震撼、海量、超强”等孤立评价词。完整描述不等于字数越多越好，也不承诺模型逐项实现。

### 写法对照（仅示例，不固定剧情）
概括：剑修反撩释放青色剑气，切开法阵，击飞对手。
展开：剑修双手握剑向上反撩，贴着剑脊的白色晶流沿挥动方向展开；前缘收紧成锐白刃线，中层青蓝流体翻卷，后缘甩出银白晶尘。刃面越过前方断柱，柱顶被齐斜切开；同一条刃线继续穿入敌方环体的下缘，黑金碎片沿切线抛出。刃面从缺口撞中对手胸甲，甲片向两侧崩开，对手上身后折、双脚离地，沿攻击方向倒飞；下一节点继续交代落点，不用爆闪或烟团替代受力结果。
示例需要足够时间；可将释放/破阵与命中/落点分别安排，不照抄进任意短节点。

Seedance 战斗特效提示词库 v1.0

文件用途：
本文件独立收录并整理从《君临天下-15s》《亡灵天灾-30秒》两份参考提示词中提取出的特效表达方式、特效结构、运行逻辑与可复用模板。
用途不是固定具体题材，而是作为 Seedance 战斗提示词 Skill 的“特效选择库”。
调用原则：按剧情、角色、武器、风格选择相关模块；禁止无理由全部堆叠。

==================================================
一、特效总原则
==================================================

1. 特效必须服从人物动作。
任何技能必须先有明确动作来源，再建立能量，再释放特效。
禁止人物尚未完成动作，特效已经凭空出现。

2. 特效必须具备完整链条：
来源 → 建立 → 释放 → 运行轨迹 → 命中 → 环境反馈 → 消散。

3. 特效必须有明确空间轨迹。
不能只写“出现一道剑气”“释放大量粒子”。
必须说明：
- 从哪里产生
- 朝哪个方向运动
- 是否弧形、直线、S形、旋转、扩张、下压
- 是否朝镜头逼近
- 是否绕行
- 是否沿地面、天空或人物运动路径推进
- 是否与主体保持短暂能量连接

4. 特效内部必须保持动态。
粒子、火焰、雷电、能量流、符文、拖尾必须持续高速流动、翻涌、旋转、扩散、压缩或碎裂。
禁止静止贴图感、固定光板感、团状死光。

5. 特效必须与环境产生物理反馈。
包括但不限于：
地裂、石板凹陷、碎石飞溅、尘浪、烟雾被推开、建筑震动、瓦片掉落、地层掀飞、空气压缩波、敌人倒飞、连锁撞击。

6. 特效必须有作用范围。
明确：
- 谁被特效影响
- 谁不被影响
- 主角是否保持原色
- 敌人是否转为剪影
- 背景是否进入水墨/红黑状态
- 特效是否只出现在武器、攻击路径、命中点或局部区域

7. 特效必须有结束方式。
可使用：
逐渐变薄、粒子碎裂、能量丝断裂、光芒熄灭、烟尘扩散、符文消散、拖尾衰减。
禁止技能突然消失无过渡。

==================================================
二、能量建立方式
==================================================

【武器能量汇聚】
能量从持武器手部、剑柄、法杖核心、符文或武器表面开始建立；
沿武器结构高速向攻击端汇聚；
形成灵纹、刃膜、火焰层、雷弧层或粒子覆盖层；
达到动作峰值后释放。

示例结构：
手部能量启动 → 武器纹路依次点亮 → 能量沿武器向前汇聚 → 攻击端压缩形成高亮核心 → 动作达到峰值 → 特效释放。

【身体能量覆盖】
适用于神性、亡灵、元素体、强化状态：
人物周身持续环绕流动雾气、粒子、火焰、雷电或碎片；
特效必须随身体运动产生惯性与拖尾；
不能独立漂浮在人物周围。

【召唤类建立】
适用于法阵、亡灵书、符文、空间术：
先出现召唤媒介；
媒介激活、翻页、旋转或亮起；
粒子、符文、光晕向中心汇聚；
随后生成完整技能实体或大型法阵。

==================================================
三、剑气 / 斩击类特效
==================================================

【标准剑气】
剑气必须从真实剑锋前缘脱离；
运行方向必须与长剑实际挥动方向一致；
主体呈薄锐月牙形、弧形或宽幅切割能量刃；
内部保持高速能量流动；
外缘带高亮切边；
尾部保留短距离拖尾。

【短距离近战剑光】
近身闪击阶段不生成巨大剑气；
每次挥剑只保留短窄光轨；
光轨精确记录剑锋真实运动弧线；
不以全身残影代替速度。

【剑气连接】
剑气刚脱离剑锋时，可在极短时间内通过能量丝、粒子链、雷弧与剑锋保持连接；
随后高速拉断并碎裂消散。

【剑气追镜】
剑气沿弧形或直线高速朝镜头逼近；
镜头同步后拉；
形成“攻击追逐镜头”的空间压迫感。

【大范围终结剑气】
剑锋能量快速压缩；
斩出瞬间从真实刃口脱离；
初始体积较小；
飞行过程中迅速扩张；
横跨街道、战场或大范围空间；
命中后产生地裂、碎石、尘浪、敌人分层受力；
尾部逐渐碎裂为细小粒子。

==================================================
四、粒子火焰 / 混沌能量
==================================================

【黑白红混沌粒子火焰】
黑、白、红三色不是三条独立光带；
三种颜色必须在同一能量主体内部交融、翻卷、混合流动；
整体表现为法术粒子流 + 火焰形态 + 高速能量尾迹的混合体。

【弧形绕行轨迹】
法杖或手部释放后：
特效先向左侧划弧；
再绕回右侧；
随后朝镜头高速逼近；
飞行过程中逐渐变大；
尾端与施法媒介保持能量连接。

【粒子链路】
攻击主体飞出后，尾部仍与法杖、手部、书本或武器保持短暂特效链路连接；
连接表现为：
能量丝、粒子流、雷弧、符文线；
随后被速度拉断并自然消散。

==================================================
五、爆炸 / 冲击波
==================================================

【完整爆炸链】
攻击命中地面或目标后：
1. 接触点首先形成能量压缩核心；
2. 核心瞬间炸开；
3. 生成高强度能量浪；
4. 环形冲击波贴地向外扩散；
5. 碎石向四周高速迸射；
6. 烟尘被冲击波向外推开；
7. 附近敌人倒飞、粉化或湮灭；
8. 冲击波持续向镜头或周边推进；
9. 粒子、尘烟与碎石逐渐衰减。

【空气压缩音爆】
适用于高速冲刺、闪身、重击：
人物爆发位移瞬间产生空气压缩；
形成环形气浪；
气浪向外猛烈荡开；
地面同步开裂、凹陷；
碎石向四周喷射。

【大型环形冲击波】
从命中点或技能核心向外扩散；
必须有明确圆形或环形传播过程；
不能只用一团光表现冲击。

==================================================
六、雷电类特效
==================================================

【游走雷】
雷电持续贴附武器、身体、法阵或攻击路径表面；
雷弧不断跳跃；
不形成静止闪电贴图。

【蓄雷】
能量先沿身体或武器聚集；
细小雷弧逐渐增加；
核心亮度提升；
达到峰值后爆发。

【落雷】
天空形成能量汇聚点；
雷柱自上而下高速贯穿；
接触地面后产生爆炸、地裂、碎石和残余电弧；
雷柱不是持续静止光柱。

==================================================
七、雾气 / 火焰 / 雷 / 碎片多层叠加
==================================================

适用于高阶角色、神性角色、BOSS状态：

底层：
白金双色雾气或其他基础能量雾气，持续翻涌。

中层：
金红双色焰或其他属性火焰，贴近人物或技能根部持续流动。

表层：
黑金雷或其他高频电弧在表面游走。

边缘层：
黑金红白等多色小碎片粒子沿人物轮廓与运动方向飞散。

原则：
不同层必须有明确层级；
不能混成一团无结构光效；
所有层都必须随人物运动发生拖尾、甩动和惯性变化。

==================================================
八、亡灵 / 召唤类特效
==================================================

【亡灵之书】
凭空幻化生成漆黑法术书；
书周围持续冒出混合粒子；
书页高速翻动；
粒子光从书页持续逸散；
施法者手掌按压书页后触发更高等级技能。

【召唤亡灵军团】
地面先震动；
碎石摆动；
烟尘升腾；
地表破裂；
亡灵战士从地下破土而出；
前景单位必须明确完成“破土 → 起身”；
远景可表现海量军团快速形成。

【粒子斗篷】
亡灵单位身体披覆半透明粒子斗篷；
斗篷由黑白红等混合流动粒子组成；
粒子持续翻涌；
随奔跑、挥砍产生惯性和拖尾；
可半遮盖脸部。

==================================================
九、法阵类特效
==================================================

【巨型符文法阵】
法阵由通透符文、光晕、环形结构组成；
在高空或指定空间位置向外展开；
符文持续旋转；
光晕向外扩散；
法阵不断荡开一层层冲击波。

【法阵下压】
巨大法阵从高空向地面轰然压落；
接触地面后：
地面整体碎裂；
大块岩层向上掀飞；
大量粒子、烟尘、碎石同时爆发；
地面单位受到压制、碾碎或掀飞；
镜头产生剧烈震动。

==================================================
十、水墨 / 黑白闪帧 / 冲击帧
==================================================

【黑白闪帧】
仅用于攻击峰值、命中瞬间、大招终结或转场；
持续极短；
用于强化冲击，不长时间占据主体画面。

【黑白水墨剪影】
可将敌人转换为黑色剪影；
血液或攻击痕迹可使用单一红色剪影；
背景转换为黑灰动态水墨；
主角可保持原有真实色彩；
必须明确写出“谁水墨化、谁保持原色”。

【暗红水墨背景】
适用于压迫、巨大化、束缚、大招终局；
背景转换为暗红水墨；
敌群可变成黑色剪影；
角色是否水墨化必须明确指定。

【毛笔动态粒子字】
技能触发后生成巨大毛笔字；
文字由动态粒子构成；
粒子内部持续翻涌；
可作为大招终结后的视觉标点或转场屏障。
仅在剧情明确需要文字型技能时调用。

==================================================
十一、红线 / 锁链 / 束缚类
==================================================

【红色细线锁链】
由手指、掌心或指定法术核心延伸；
大量纤细红线连接敌人；
红线必须绷紧、有方向性；
可将敌人悬吊于半空；
敌人身体存在真实挣扎和重力下坠反馈。

【群体束缚】
部分敌人被悬吊；
部分敌人仍留在地面；
避免所有单位以完全相同姿势悬浮；
红线空间关系必须清晰可读。

==================================================
十二、空间撕裂 / 粒子化
==================================================

【撕裂空间】
角色双手抓住前方空间；
向左右猛力撕开；
空间表面产生裂缝、扭曲、黑暗边缘或能量断层；
裂口扩大后用于角色消散、转场或空间技能。

【人物粒子化】
身体从指定区域开始逐渐转化为粒子；
粒子沿明确方向升空、扩散或被吸入裂缝；
禁止人物瞬间凭空消失。

==================================================
十三、高速闪击特效
==================================================

【位移与特效分离】
人物高速穿行时：
人物本体必须保持连续真实运动；
速度感主要由脚下尘线、碎石、衣摆、剑光、局部气流和短拖尾表现；
禁止全身残影、复制体、透明分身。

【S形 / 折线穿行】
高速移动轨迹由大幅 S 形、折线、弧线组成；
每次变向必须有脚步、侧蹬、身体倾斜、腰胯重新定向；
剑光或粒子尾迹记录运动路径。

【位移即攻击】
移动过程中同步完成横斩、反手斩、斜挑、贴身切割；
不能先跑到位置后再停下攻击。

==================================================
十四、受击反馈特效
==================================================

【斩击受力】
敌人按照剑锋运动方向受力；
横斩向侧后方翻飞；
斜斩沿斜轴旋转倒下；
挑斩产生向上抛起趋势。

【钝击 / 掌击】
接触点产生局部能量爆发；
躯体受力向后；
可引发倒飞；
倒飞敌人撞击后方单位产生连锁撞击。

【群体受击】
前排先受击；
中排稍后；
后排最后；
抛飞高度、方向、距离具有差异；
禁止完全同步。

==================================================
十五、地形交互特效
==================================================

【冲刺】
脚下石板边缘崩裂；
碎石向人物运动反方向喷射；
尘土被鞋底卷起。

【高速变向】
鞋底与地面摩擦形成弧形尘线；
局部碎石横向甩出；
身体与衣摆产生相反惯性。

【重击】
地面形成放射状裂纹；
中心局部凹陷；
碎石向外抛出。

【大型剑气经过】
地面出现连续切痕或裂缝；
两侧石块被压力掀开；
尘浪沿攻击方向向两边分流。

【建筑反馈】
冲击可造成：
建筑震动、灰尘落下、瓦片飞落、局部破损；
除非剧情要求，禁止整栋建筑无理由全部坍塌。

==================================================
十六、镜头与特效联动
==================================================

【特效追镜】
攻击高速朝镜头飞来；
摄影机同步后拉；
特效持续放大；
形成压迫感。

【特效擦镜】
剑气、武器、敌人、粒子、火焰快速掠过镜头；
利用短暂遮挡完成自然转场。

【爆炸追镜】
爆炸产生的冲击浪向镜头推进；
摄影机极速后撤；
碎石与粒子追逐镜头。

【特效引导视线】
利用弧形火焰、剑气轨迹、雷电、法阵扩张等将观众视线从人物引向下一动作区域。

==================================================
十七、特效作用域规则
==================================================

1. 特效必须明确作用对象。
2. 主角、敌人、背景可以采用不同特效规则。
3. 局部水墨化时，明确谁保持原色。
4. 粒子不能无差别铺满全画面。
5. 大招可以短时间占据大面积画面，但必须恢复主体可读性。
6. 普通近战不使用终结技等级特效。
7. 高级特效必须与剧情等级匹配。

==================================================
十八、特效时间隔离规则
==================================================

只在指定时间段出现的高等级特效，必须明确限制提前出现。

例如：
- 巨大化只能在终局出现；
- 红线锁链只能在终结技能出现；
- 巨型法阵只在大招阶段出现；
- 大范围剑气只在终结斩出现；
- 水墨剪影只在命中峰值出现。

写法：
“在 XX 秒以前禁止出现该特效。”
“该特效仅在终结阶段激活。”
“前半段仅保留低等级剑锋光效。”

==================================================
十九、特效负面约束
==================================================

禁止：
- 无来源光团
- 团状静止特效
- 特效颜色随机变化
- 粒子无方向漂浮
- 全身残影表现速度
- 重复人物
- 特效长期遮挡关键动作与命中结果
- 技能尚未动作完成便提前释放
- 剑气运行方向与剑锋不一致
- 雷电静止贴图
- 爆炸无地形反馈
- 冲击波无扩散过程
- 烟尘长期完全遮挡主体
- 所有敌人同步受击
- 无目的或持续的粒子堆满全屏（明确高潮的短暂铺屏按试用规则处理）
- 过度泛光
- 过曝
- 游戏 UI
- 技能图标
- 血条
- 无剧情需求的文字特效

==================================================
二十、通用特效写作骨架
==================================================

【技能名称 / 特效类型】

动作来源：
描述人物脚步、腰胯、肩部、手臂、手腕或法术动作。

能量建立：
描述能量从哪里出现、如何聚集、压缩、点亮或覆盖。

释放：
描述动作达到峰值后，特效从真实来源位置释放。

运行轨迹：
描述直线、弧形、S形、旋转、扩张、下压、追镜等运动。

拖尾与连接：
描述粒子尾迹、能量丝、雷弧、符文链、空气扰流。

命中：
描述特效与敌人、地面、建筑或其他技能接触的瞬间。

受击反馈：
描述敌人受力、倒飞、旋转、粉化、湮灭、连锁撞击。

环境反馈：
描述地裂、碎石、尘浪、烟雾、建筑震动、冲击波。

消散：
描述特效如何变薄、碎裂、熄灭、断裂、扩散并最终消失。

==================================================
二十一、调用原则
==================================================

1. 本文件是特效“选择库”，不是整段复制库。
2. 每场戏只调用与当前剧情直接相关的特效。
3. 普通攻击使用低等级特效。
4. 大招使用高等级特效。
5. 同一场戏保持统一主色和统一特效语言。
6. 特效必须服从人物动作和镜头空间。
7. 最终提示词使用确定性命令，不写“可以、建议、尽量、可插入”等讨论语气。
8. 未明确要求 BGM 时，默认无 BGM，仅保留同期动作声、特效声、环境声与人声。
