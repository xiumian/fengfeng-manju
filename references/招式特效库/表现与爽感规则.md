# 特效表现与爽感执行规则

## 定位与调用
本文件由用户提供的《小说战斗与宏大画面爽感执行规则 V1.0》提炼，应用于视频主稿、分镜及招式设计。源文完整存于[来源资料](来源资料/小说战斗与宏大画面爽感执行规则_V1.0.md)，只供追溯，不把其中小说精修口令、自动调用指令或其他技能依赖当成当前工作流。
选定招式条目后按本规则组织表现；没有特定招式的觉醒、变身、神兽、结界或宏大登场也可按需使用。规则是判断依据，不要求每段额外输出分析表。遵循原文、用户已确认设定和当前指定视频格式，不扩大角色能力、伤害、破坏范围或剧情结果。

## 五层画面判断
- 信息：谁从何处释放什么，攻击谁，结果是什么；角色、源头与路径在镜头链中可判断，瞬间冲击遮挡后恢复结果可读。
- 冲击：接触、格挡、穿透或落空要可辨，随后给对应受力。格挡不等于刺穿，稳住不退也可呈现力量。
- 空间：一个现有参照物、一组前后/上下关系、一段可见运动，使路径和尺度成立。
- 速度：用同一时间里的动作完成差、路径和旁物反应表现快慢；不能以模糊或瞬移替代过程。
- 氛围：通过确定的光源、材质、雾和余效形成记忆，不靠泛光或形容词。
普通攻击突出最重要的两三层；关键打点突出接触与反馈；大招、首次宏大登场再展开更多层。不能为凑齐五层增加动作或剪辑。

## 战斗与特效因果
组织为意图 → 起势/发力 → 路径 → 接触或落空 → 对象反应 → 环境余波 → 局势改变，作为完整性检查，不机械分成七镜。
瞬发招式不额外强加长蓄力；已存在的能量或法相不重复召唤。发力、释放、运行、接触、反馈与消散仍按当前时间轴展开。轻击不必打飞、重击不必追杀、对撞不必爆炸，结果依力量关系和人物目标选择。
拳脚保留支撑、重心和腰肩传力，兵器保留持手、接触部位及回收；多目标先建立位置，再聚焦主要交锋。其他角色不因镜头聚焦而停止行动，但不新增未经授权的参战者。

## 材质与物理条件
金属刃口反光不是剑气；短尾迹不是分身；视觉上追不上不代表时间停止。普通碰撞火花须由材料与接触条件支持，不让刃碰毛发、布料或水就自动炸火星。
气流、尘叶、水波、衣发按路径响应；泥脊来自压地，切痕来自擦切，石屑来自实际破损，没有来源就不用。角色衣服主色不决定功法颜色。
高重力不等于空气密度增加，也不让碎石自动悬浮。折射须对应温度、压力或已确认能量机制；悬浮须有升力/法术依据；音爆须有速度或世界规则依据。用法术解释时明确该机制，不能冒称现实物理。
火的上卷与热扰动、冰的棱面与脆裂、水的折光与回流、雷的短促分叉、金属的反光与鸣响各有差异。辅助反馈不自动赋予燃烧、冻结、麻痹或腐蚀能力。

## 宏伟画面与尺度
从已有环境选尺度参照，例如掌缘遮住断楼上部、指间仍露出楼体；先建立角色与落点，再展示能量或生物如何穿过这一空间。参照物不能切镜后换位置或变大小。
宏大事件必须影响角色视线、行动或局势：循声、追视、抬头、寻找路线或改变防守，按人物性格选择；不统一震惊跪拜。
法相按已定机制形成轮廓与体积，交代本体方位及动作联系；对撞需有双方接触部位、相向路径与交汇点，先压缩/抵持/裂开，再表现波及与谁退谁稳。不能只拍天空炸亮。
破坏由近处接触扩展到确认边界，再回角色结果；建筑损毁、伤亡、地形改变须有剧情依据，后镜继承。识海、幻境或演示明确不是现实力量升级；水墨外观不自动变二维或新增墨系能力。

## 速度、节奏与粒子
高速可通过同源碎片仍下落而下一动作已完成表现，但确保时间和位移可实现；夸张速度使用已确认世界规则。远处声响延迟按距离安排，不把视觉与声音延迟随意套在贴身接触。
一个打点选择一个主效果，少量辅助响应。粒子按来源分层：能量细粒沿流向衰减，尘叶被气流卷起后落下，碎片由破坏产生后保持惯性和重力；数量与亮度不长期掩盖接触与结果；短暂爆发按主编排处理。
普通交锋利落，关键接触可短暂强调但不给每击慢镜头；形成、尺度揭示和结果留必要时间。快剪比例、慢动作次数、流体/粒子比例都不是硬指标，不保证加术语会改善模型效果。

## 收势与主稿核查
以持续后果结束效果：碎屑下落、盾鸣衰减、云隙尚未合拢、对手重新支撑；随即回到角色选择、关系或下一行动。保留呼吸、衣发、持手和环境，不静止炫技。
效果完整过程先写入视频主稿，再从中抽九宫状态；未入格过程、对白和声音不能删。只用当前用户指定模板，不把小说句法、章末钩子、点星刺人物事实、固定BGM或参考图要求迁入视频。
交付前按需简查：源与路径可辨吗？材质/力度反馈匹配吗？速度未偷换瞬移吗？尺度与破坏有依据吗？伤损和余效继承吗？效果遮住结果了吗？角色下一步接上了吗？只修实际缺口，不添加独立长报告。
