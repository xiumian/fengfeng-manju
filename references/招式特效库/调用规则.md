# 招式特效库调用规则

## 查找与选择
用户要求某招式时先读索引，按媒介、形态、属性和运动检索，如“剑气”进入剑气类，“龙拳”先选贴拳龙形而不是远程龙息。不默认一次列出全库；用户要看选择时给若干差异明确的候选及简介，确认方向后展开详细设计。用户已说明效果则直接选条目并调整，不反复询问。
库中条目是通用视觉备选，不是角色能力设定，也不是实际效果视频/图片素材。中文名称和关键词便于检索，ID稳定；按需加载条目所在类，不每次读所有文件。

## 表现检查
特效编排优先遵循[打斗与强视觉主方法第4节](../generation-action-visual-control.md)的主形、节奏、接触反馈和精炼正文规则；下面的条目字段用于内部选择，正文仅展开当前看点所需信息，不机械逐项填满。
选定条目后按[表现与爽感规则](表现与爽感规则.md)检查五层画面、材质条件、速度参照和尺度关系；普通攻击只突出必要层次，不强加蓄力、慢镜头或额外破坏。宏大登场没有攻击招式时也按需使用。

## 展开程度
简介只用于检索。正式视频主稿展开：真实动作/法器触发 → 形态形成 → 释放与源的关系 → 连续路径/速度 → 接触或未命中 → 受力与环境 → 衰减 → 人物和环境终态。因果阶段按当前时间轴连接，可并行或短促发生，不逐阶段新增等待；不能贴名称或一行“炫酷剑气”结束。
颜色、尺度以人物身高或场景物体作参照；实体与能量形态分清，写清厚度、透景、亮暗分层、边缘和内部流动。示例不是固定秒数，按动作与对白安排；命中不等于破坏，条目可改成格挡、失败、擦过或无攻击展示。
环境反馈按距离、材质与世界规则发生；没有实物来源不增加灰尘碎石。能量消散不删除实物损伤。关键接触与身体关系在镜头链中可判断，允许冲击瞬间遮挡并随即交代结果；不长期以全屏泛光掩盖因果，不要求所有部位每瞬同时可见。

## 镜头与声音
形成阶段交代源与人物动作，运行阶段交代源—路径—目标，接触阶段保留接点与因果，结束回接收势和下一事件。条目镜头是候选，不强制每阶段切镜；遵循当前导演调度。音效有来源和先后，生物声需对应生物或已设计的能量拟声机制；不自动新增对白、OS或配乐。

## 组合
选一个主形态，最多按需要补少量材质/属性层；例如月牙剑气可借雷纹作为刃缘层，但不能继承连锁雷击能力。多个效果避免互相遮挡，写清先后；若材料机制矛盾，采用一种或显式确认转换。相同招式跨镜继承数量、尺度、颜色、路径、伤损与余效，不每镜变招。

## 与主稿/九宫连接
效果先写进完整主稿和全事件时间轴，再选九格代表状态。未入格的形成、运行、反馈、声音和消散仍保留。九宫画错只改目标格；不从九格重建特效过程。生成视频后核对实际形态与因果，资料库文本尚不等于效果经过实测。

视觉效果按[自主视觉设计](../visual-impact-design.md)综合处理。透明薄膜/低粒子只是条目候选，可依当前目标调整主体厚度、流动及辉光；保持形态与接触可读，不将克制约束变成所有大招的弱化模板。

## v7.7生成表达补充
按完整主稿保留所有事件，内部可以详细推演，投喂正文只保留必要关键控制与自然因果，避免逐肢体说明和重复约束。执行详见references/generation-action-visual-control.md（相对技能根目录），不强加另一种栏目格式。
