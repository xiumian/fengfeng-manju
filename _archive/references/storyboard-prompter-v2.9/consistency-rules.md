# 跨镜头一致性检查清单

## 使用说明
在生成完一场戏的全部分镜提示词后，逐项对照本清单进行自查。
发现问题时，直接修改对应镜头的提示词描述。

---

## 一、人物一致性检查

### 1.1 服装连戏（v2.8-stable：通过状态ID维护，不在【画面】中描述）
```
v2.8-stable 检查逻辑：
服装只作为资产/状态连续性信息维护，不在【画面】字段中描述颜色/款式/材质。
检查方式：验证"服装状态ID"是否连续，而非复述服装细节。

✅ 正确（v2.8-stable）：
  - 锁定标签池中记录：林晚秋_服装状态 = 初始态 / 胸前湿痕 / 裙摆破损
  - 【画面】字段中：不出现任何服装描述
  - 如需换装或损伤：在剧情驱动镜头后更新服装状态ID

❌ 穿帮：
  - 【画面】字段中出现"穿着黑色西装"等服装描述 → 违反v2.7禁止规则
  - 某镜头服装状态ID与前序不一致，且无换装/损伤剧情镜头

检查动作：
□ 锁定标签池中已为每位主要人物建立服装状态ID
□ 【画面】字段中无任何服装颜色/款式/材质描述（仅功能性动作可提及，如"解开外套"）
□ 如有换装/损伤剧情，前后状态ID已更新，且有剧情镜头支撑
```

### 1.2 道具连戏
```
检查逻辑：
人物手持或佩戴的道具在连续镜头中必须一致。

✅ 正确：密码本在S002始终出现在林晚秋右手
❌ 穿帮：某镜头密码本消失，下一镜头突然出现

检查动作：
□ 人物手持道具在近景/特写后，回到中景时仍在原位置
□ 道具的使用状态（打开/关闭/损坏程度）在连续镜头中一致
```

### 1.3 180度法则
```
检查逻辑：
多人对话场景，人物的左右位置在连续镜头中必须保持一致。

✅ 正确：正打A在左，反打B在右，双人全景A仍在左
❌ 穿帮：正打A在左，切到双人景A突然在右

检查动作：
□ 建立第一个镜头时已确定"想象轴"（人物间的连线）
□ 所有正反打镜头均在轴线同侧拍摄
□ 如有越轴，已设计过渡镜头
```

### 1.4 人物情绪连贯性
```
检查逻辑：
情绪变化需要有依据，不能无故跳变。

✅ 正确：林晚秋从"凝重表情"到"微微松动"，中间有一个"看到信号"的反应镜头
❌ 穿帮：林晚秋上一秒极度紧张，下一秒突然放松，无任何过渡

检查动作：
□ 情绪发生显著变化时，前序已有触发该变化的事件镜头
```

## 二、场景一致性检查

### 2.1 光源方向统一
```
检查逻辑：
同一场景（同一时间）的所有镜头，光线主方向必须一致。

确定光源规则（开始拍第一镜时确定，全场沿用）：
├─ 室内场景：以最主要的光源（窗/灯）方向为基准
├─ 室外日景：以太阳位置为基准（morning = 东方低角度，noon = 顶光，afternoon = 西方）
└─ 室外夜景：以月亮/路灯/建筑灯光为基准

✅ 正确：S001光源设定为"左侧窗透入冷月光"，全场所有镜头阴影朝右
❌ 穿帮：第3镜阴影突然变成朝左

检查动作：
□ 已在场景提示词卡片中明确光源方向
□ 全场所有镜头的光影描述与场景设定一致
□ 人物轮廓光方向与主光源一致
```

### 2.2 固定陈设一致
```
检查逻辑：
场景中固定的家具、道具的位置在所有镜头中不能移动。

✅ 正确：S002桌子始终在画面右侧，全场所有镜头保持
❌ 穿帮：某镜头桌子消失，另一镜头桌子换了位置

检查动作：
□ 场景中有明确提及的固定道具（桌椅/床/门窗）位置一致
□ 背景远处的标志性建筑/元素在宽景镜头中保持一致
```

### 2.3 时间线自洽
```
检查逻辑：
连续场景中时间不能倒流。天色变化需要有叙事依据。

✅ 正确：S001是夜晚，S002紧接其后仍是夜晚
✅ 正确：S003开头有"天色渐亮"的空镜，S004变为清晨
❌ 穿帮：S001夜晚，S002突然变成正午，无任何说明

检查动作：
□ 时间跳跃前已设计时间流逝的空镜/字幕提示
□ 连续场景的天色、光线强度符合物理时间逻辑
```

## 三、视觉美感检查

### 3.1 构图多样性
```
检查动作：
□ 同一场戏不连续出现超过3个相同景别
□ 重要情绪时刻已分配近景/特写镜头
□ 已有至少一个建立全景
```

### 3.2 视觉层次
```
检查动作：
□ 重要场景已设计前景/中景/背景三层构图
□ 注意：v2.8 禁止在【画面】中描述场景装饰细节，视觉层次通过景别选择体现，而非背景文字堆砌
```

### 3.3 节奏变化
```
检查动作：
□ 镜头时长有变化（不全是相同秒数）
□ 高潮段落已设计短镜快切
□ 情绪积累段落已设计长镜慢推
```

## 四、最终审查

完成上述所有检查后，用一句话总结每场戏的一致性状态：

```
S001：✅ 光源（左侧月光）、服装（锁定标签引用）、道具（密码本右手）均通过检查。
S002：⚠️ 第3镜道具未引用锁定标签，已修正。
```
