## 1. 九宫格定位

九宫格是 3×3 的分镜规划页，不是九个互不相关的图片提示。

每格表示一个可拍摄镜头或一个关键帧节点，并必须关联：

- 剧情单元 `U`
- 台词单元 `D`，如有
- 表演节拍 `P`，如有
- 动作节拍 `A`，如有
- 起止状态快照 `T`
- 后续视频镜头 `SH`

九宫格用于：

- 审查剧情覆盖
- 锁定角色和空间连续性
- 批量生成分镜图
- 把分镜图作为后续视频参考
- 映射 OG 和 Seedance 提示词

## 2. 分页算法

### 2.1 顺序

按场景、剧情单元和事件顺序生成镜头候选，然后按阅读顺序填入：

```text
P01 P02 P03
P04 P05 P06
P07 P08 P09
```

### 2.2 场景边界

- 默认一页只容纳一个场景。
- 场景切换时优先结束当前页并新开页。
- 当前页剩余格可用于同场的合法建立、反应、细节或转场镜头。
- 若没有合法镜头，使用 `RESERVED`，不得把下一场景塞入空格。
- 用户明确要求跨场拼页时，必须在跨场格上标注场景 ID 和不连续边界。

### 2.3 镜头不足九个

按以下优先级补充，前提是不改变剧情：

1. 已存在空间信息的建立镜
2. 剧情相关的听者/旁观者反应
3. 已存在关键道具的细节镜
4. 动作接触或表演变化的关键帧
5. 时间/场景过渡镜
6. `RESERVED`

不得新增台词、攻击、角色、道具用途、关系变化或事件结果。

### 2.4 镜头超过九个

- 保持顺序分页。
- 不在动作接触前后随意分页。
- 不在一句未完成的关键台词中间分页；无法避免时，下一页首格重复空间和表演终止态。
- 每页末格和下一页首格必须通过状态等式。

## 3. 单格数据契约

每格使用：

```yaml
grid_id: G01-P01
scene_id: S01
shot_id: SH001
source_ids: [U001, P001]
shot_purpose: establish|action|reaction|dialogue|detail|transition|reserved
start_state: T00
end_state: T01
duration_hint: 3.0s
shot_size: MCU
angle: eye-level
camera_move: static
characters:
  A:
    position: frame-left
    facing: frame-right
    eyeline: B
    prop_state: sword_in_right_hand
visible_action: ...
performance:
  provenance: script_confirmed|performance_translation
  sequence: baseline -> trigger -> leak -> control -> end
dialogue_audio: ...
lighting: ...
continuity: ...
constraints: ...
```

不需要输出 YAML 时，也必须保留同等信息。

## 4. 页面连续性

### 4.1 页内

检查：

- 人物 ID 和视觉锚点
- 屏幕左右与 180° 轴线
- 视线目标
- 道具归属和状态
- 服装/伤损状态 ID
- 场景破坏状态
- 主光方向
- 动作起止姿态

### 4.2 跨页

```text
G01-P09.end_state = G02-P01.start_state
```

若 `P09` 是 RESERVED，则使用最后一个有效格的结束状态。

跨页摘要：

| 道具 |  |  |  |

| 场景状态 |  |  |  |

## 5. 文本到九宫格的转换

### 5.1 分析账本

先建立：

| ID | 原文 | 类型 | 角色 | 触发/因果 | 状态变化 |
|---|---|---|---|---|---|

### 5.2 镜头候选

每个剧情单元至少映射一次。一个镜头可覆盖多个单元，但必须逐项明确，不能用含糊情绪词替代具体动作。

### 5.3 表演映射

将 `P` 节拍写入最能读到表演的格：

- 触发与泄漏可在同格
- 控制与终态可在后续格
- 一个短格只用 2–4 个表演通道
- 微表情格优先 MCU/CU 和固定/缓推

### 5.4 打斗映射

复杂动作至少分成：

1. 起势/目标选择
2. 发力路径
3. 接触
4. 受力反应
5. 恢复/失衡

若一次攻击能在一个稳定镜头中清楚完成，可合并为一格，但仍需写全起止状态。

## 6. 输出模板

### 6.1 九格总览

| 格号 | 来源 | 功能 | 景别/运镜 | 核心画面 | 起止状态 |
|---|---|---|---|---|---|
| G01-P01 | U001 | 建立 | WS/固定 |  | T00→T00 |
| G01-P02 | U002,P001 | 触发 | MCU/缓推 |  | T00→T01 |
| ... | ... | ... | ... | ... | ... |

### 6.2 逐格提示

```text
【格号】G01-P01 | SH001 | 来源 U001,P001 | 起始 T00 → 结束 T01
【功能】反应镜
【景别·角度·主运镜】MCU | 平视 | 固定
【在场与空间】A 位于画面左侧，面向右；B 在画外右侧；A 的视线目标为 B
【画面】当 B 说出关键词时，A 的呼吸停半拍，视线在 B 身上停住；头部不动，
下颌轻微收紧，随后恢复克制。结束时 A 仍保持原站位。
【台词/声音】B 的原文台词作为 OS；环境声保持不变
【连续性】A 的道具仍在右手；主光来自左后方；轴线不变
【约束】不让 A 突然转头，不新增台词，不改变道具和左右位置
```

### 6.3 九宫图总提示

用于一次生成整张 3×3 分镜图时：

```text
生成一张严格 3×3、九格等尺寸、按左上到右下阅读的电影分镜板。
每格保留清楚边框和格号 G01-P01 至 G01-P09。所有格保持同一角色身份、
服装状态、场景布局、道具状态和主光方向；不得交换人物左右位置。

P01：[关键画面]
P02：[关键画面]
...
P09：[关键画面或 RESERVED]

这是分镜板而非连环漫画；不添加对白气泡、标题、水印或额外格子。
```

九宫图总提示不能替代逐格数据；逐格数据是连续性和后续视频转换的权威来源。

## 7. 校验

- [ ] 每页正好 9 个格号或明确 RESERVED
- [ ] 格号按 P01 到 P09 排列
- [ ] 每个有效格有来源 ID
- [ ] 剧情覆盖率 100%
- [ ] 没有为了填格新增剧情
- [ ] 页面内身份、轴线、道具、状态和光影连续
- [ ] 跨页状态相等
- [ ] 表演变化有触发且可见
- [ ] 动作受力方向正确
- [ ] 每格一种主运镜、1–2 个主要动作
- [ ] 九宫格与 OG 映射可追溯
