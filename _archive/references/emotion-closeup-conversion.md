# 情绪细节与特写镜头转换逻辑

目标是让特写承担明确的情绪信息：把剧本中的微表情、微动作和注意力转移变成可见焦点。特写不是装饰，也不是每逢情绪词就自动切近。

## 1. 提取情绪节拍

对每个事件状态记录：

`基线状态 → 触发 → 无意识泄漏 → 主动掩饰/控制 → 可读终态`

从眼神、眼睑、眉部、唇角/下颌、呼吸/吞咽、手指/肩颈/姿态中只选2–4个可见通道。抽象的“紧张、悲伤、愤怒”必须转换为变化，不写成冻结表情。

## 2. 判断是否需要特写

满足下列至少两项时提高特写优先级：

- 情绪转折主要发生在眼神、嘴角、下颌、呼吸或手指；
- 角色试图掩饰，信息只从短暂泄漏中可见；
- 关键判断、怀疑、克制、认出、受伤或关系变化没有大动作；
- 观众必须先看见一个局部细节，才能理解下一动作或台词；
- 静默听者的有限反应比说话者继续讲话更重要。

以下情况不自动切特写：空间建立、多人走位、动作路径、武器接触、特效尺度或环境结果尚未交代清楚；用户明确指定远景/一镜到底；特写会破坏轴线或遮掉必要道具。

## 3. 景别与焦点选择

- 面部两种以上细微变化：近景或特写，50–85mm自然肖像透视，眼睛优先清楚。
- 手指收紧、握柄、触碰、道具细节承担转折：手部特写，但需保留归属线索。
- 面部变化与身体控制同等重要：中近景，保留肩颈、呼吸和手部。
- 只需引导注意力而不切镜：保持原景别，使用受控焦点/构图转移。

特写段保持镜头稳定；最多一个简单运动。避免快速摇移、环绕、强手持或在关键表情发生时切走。

## 4. 九宫格覆盖

每个SEG通常保留：至少一个空间/关系建立状态、至少一个动作或关系变化状态、必要时1–3个情绪细节状态。不得连续用同一张脸的相同表情凑格，也不能用特写替代关键空间与动作因果。

同一SHOT可占多格，但必须分别是不同可见状态，例如：听见触发、眼神先偏移、下颌收紧并恢复控制。它们仍属于同一个事件，不扩写成新剧情。

## 5. Prompt回填

单格Prompt增加：

- `情绪节拍`
- `视觉焦点`
- `特写理由`
- `表演顺序`
- `针对性负面约束`

通用负面约束：不冻结中性脸、不夸张瞪眼、不机械眨眼、不突然甩头、不强行微笑、不脸部变形、不身份漂移；必要眨眼或明确的大情绪不得被错误禁止。

## 6. 校验

成图反查时额外检查：焦点是否落在提示词指定局部；微表情是否由触发引起；眼神先于头部、呼吸先于迟疑台词等顺序是否合理；特写是否保留人物身份和道具归属；相邻格是否呈现不同状态而非重复脸部构图。
