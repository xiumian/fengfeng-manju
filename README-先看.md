# 9宫｜可调九宫格工作台

这是一个本地静态网页工作台和 Codex 技能，核心功能是将剧本拆成 SEG、编辑九宫格故事板、回填与替换图片、保存工作项目，并交付已确认段落的最终视频提示词。网页本身不连接生图模型。

## 启动

macOS 双击 `9宫.command`；或在终端运行 `./9宫.command`。需要只启动服务而不打开浏览器时运行 `./9宫.command --no-open`。启动终端须保持打开，关闭后服务停止。需要 Python 3 和浏览器；启动器会自动选择空闲本地端口并打印地址。不要通过 `file://` 打开网页。

默认显示浏览器中最近保存的工作项目；第一次使用时显示内置演示。可导入自己的剧本或工作项目 JSON。

## 使用

1. 导入 TXT/Markdown 或粘贴剧本；页面生成 SEG 和九格初稿。支持“分镜编号｜目标时长”及“参考图职责/本镜头目的/开场承接/场景与空间/人物、对白与OS/镜头/动作与时间/声音/结尾接口/一致性与执行限制”的标准分镜格式。自动拆分是起点，仍需人工核对时长、人物、空间与台词。
2. 复制当前 SEG Prompt，在 Codex 中调用生图工具；将成图通过“回填九宫格图”导入。
3. 检查每格；如需局部重生，填写偏差、生成单格 Prompt、导入替换图。修改后原“完成”标记会取消，需要重新检视。
4. 点击“保存项目JSON”保留所有可编辑数据和图片；浏览器也会自动保留最近项目。跨设备或清理浏览器数据前，请手动下载工作项目 JSON。
5. 成图后由用户本人逐段检视。Codex可以报告问题，但不能替用户通过；用户接受当前结果时点击“我已校验，标记完成”。本轮全部 SEG 都由用户确认后，页面才进入第 6 阶段并显示独立的“结果输出”区域。

`结果输出`只包含用户确认完成的最终视频 Prompt、九宫图和逐格对照表，不包含草稿、未经用户确认的内容或工作台编辑功能，也不能作为可编辑项目重新导入。继续编辑请使用“保存项目JSON”导出的文件。

## Codex 调用

全局安装后使用 `$9gong`。显示名称是“9宫”；输入“9宫”或“/9宫”也可表达同一意图，但斜杠是否被客户端识别为专用命令不由这个文件控制。

## 样本与边界

当前工作台负责文件和提示词编排；图片由生图工具生成，并由用户核验。已移除指定历史案例，通用规则和工作台保留。
