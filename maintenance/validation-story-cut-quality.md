# 剧情因果与切镜质量｜文字对照

- 授权：主人在提交两天使用反馈、确认讨论方向后要求“把这方面的内容做下修改”。
- 基线：ccb7cca6；本轮保留原模板、段尾交接镜、原有镜长与时间节点接口。方法由创作准备、摄影、编译和验证执行，不新增工序、JSON字段或投喂清单。
- 下面是按反馈构造的原创文字样例，不是主人的项目素材，也不是模拟实测画面。

## 同一底稿的改前、改后

固定事实：乙发现待发木箱封条断了，说“封条断了，先别盖章。”负责出库的甲据此决定停发，推回发货单；下一场甲把原箱送到复验台，发货单没有盖章。本段预算共10秒；同一句台词始终只说一次。

**缺口版（反例）**：0—2.4秒拍乙面对甲说完；2.4—4.2秒切甲正面近景，写“神色变了”；4.2—6.8秒切回乙和原位置的木箱，封条与单子都看不清。6.8—10秒直接到复验台，甲已开始办理复验。四段时间连得上，却没展示甲依据什么改决定；切回也没新增信息，最后一场有行动却没有可读的行动依据。

**改后文字方案（本轮人工对照稿）**

- **0—2.4秒｜发货台**：桌侧固定中近景，甲的章印悬在发货单上方；乙把箱沿转向两人，指尖停在翘起的断口旁，甲视线落到断口。乙在箱子还在转动时开口：“封条断了，先别盖章。”
- **2.4—6.8秒｜停发**：在乙说到“先别”时，切至桌同侧较低的斜近景，画面从断口转到甲持章的手和纸面。乙的后半句延续为同场画外对白，不重说。甲收回悬着的手，放下章，把仍无章印的单子推回桌面靠乙的一侧，指了指复验台标牌；乙把单子插进箱侧透明单夹，甲拉住推车扶手。本镜交代他不照原计划盖章，不让他在听见警告前动手撤单。
- **6.8—10秒｜复验台**：切到清晰标识的独立复验台，机位沿台边小幅侧跟。甲推着同一只断封条木箱到台边停住，将透明单夹中未盖章的发货单递给值台人，木箱停在推车上待验。

**人工逐项对照**：

| 项目 | 改后正文证据与判断 |
| --- | --- |
| 第一处切点 | 前镜已见断口和悬章，后一镜改看是否真的停发，证据是“收回悬着的手……把仍无章印的单子推回”；如果用固定同框也能看清断口与撤单，可保留原镜。缩景别本身不是收益。 |
| 因果与场间 | “甲视线落到断口”是他获得信息；“放下章……推回”显示弃原方案；“推着同一只断封条木箱到台边停住”显示他执行替代方案，断口、未盖章单据与对白不冲突。 |
| 时间 | 第一次辨认断口安排在发货台，停发动作留在乙说到关键提醒之后，复验不与撤单挤在同一拍。箱沿转动与乙开口可并行。2.4秒只是本例剪辑意图，可依自然语速落到相应词，不是用数字强迫发声。 |
| 故意改坏再判 | 若第一刀只是重拍断口且状态没变，判无收益；若下一场拿到盖章单却无出处，判前后场道具状态冲突；若0.5秒里同时要求首次看清断口、撤单和送抵复验台，判容量不成立。 |
| 限制 | 原创文字对照只演示怎样判断。有实际采用素材时另核其入出点、画内状态与台词；此处无素材、未做模型独立生成或成片验收。 |
